# 步驟 02：歷史研究結構與 MECE 方法

日期：2026-07-26  
狀態：已確認

## 結構決定

`Audio Deepfake Detection` 由兩個不同性質的部分形成：

- **Audio Deepfake**：被研究的現象與偽造能力。
- **Detection**：對該現象進行辨識、驗證與評估的任務。

歷史分支因此採用兩條平行時間線，再研究它們的共同演化：

```text
Audio Deepfake 的發展
        ×
Detection 的發展
        ↓
新的偽造能力 → 舊偵測假設失效 → Detection 回應
```

## MECE 的使用方式

- 不強迫歷史年代互斥，因為不同技術與任務會同時存在。
- 使用 MECE 檢查每個時間點需要回答的問題，避免遺漏觀察面向。
- 以時間／轉折為列，以分析維度為欄：

| 時間／轉折 | 偽造能力 | 威脅情境 | Detection 證據 | Detection 輸出 | 評估方式 |
|---|---|---|---|---|---|
