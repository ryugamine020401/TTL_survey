# 步驟 09：2000–2017 TTS 過渡世代查證

日期：2026-07-27  
狀態：已查證；補入 2013 Neural Statistical Parametric 橋接世代  
上一步：`08-TTS世代轉折與單篇代表論文.md`

## 本步問題

2000 年 HMM-based TTS 到 2017 年 Tacotron 之間，是否大多只是 HMM 改良？中間有沒有足以獨立標示的技術突破？

## 結論

**不是十七年都停留在 HMM，也不是中間沒有突破。**

較精確的演進是：

```text
2000–2012
HMM-based Statistical Parametric TTS

2013–2016
DNN／RNN-based Statistical Parametric TTS
（橋接世代）

2017 起
Neural End-to-End TTS
```

2013 年應增加一個「Neural Statistical Parametric」橋接節點，代表 acoustic model 從 HMM／decision tree 轉向 DNN，之後再演進到 RNN／LSTM。

它之所以只是橋接、而不是 Tacotron 所代表的完整 end-to-end 世代，是因為整體 pipeline 仍然是：

```text
人工設計 linguistic features
→ DNN／RNN 預測 acoustic parameters
→ vocoder 產生波形
```

## 第一階段：2000–2012 — HMM Statistical Parametric

### 核心生成方式

HMM 同時或分別建模 spectrum、F0、duration，從文字條件下的模型分布產生聲學參數，再交給 vocoder。

### 這段期間並非沒有進展

- **2002：HTS toolkit 公開。** 2009 年 HTS 論文指出，HMM-based synthesis 在先前數年逐漸流行，HTS 自 2002 年起作為開源研究工具。
- **2005：Global Variance。** Toda 與 Tokuda 針對 HMM 生成軌跡過度平滑、聲音模糊的問題，引入 global variance，原論文聽測顯示自然度有大幅改善。
- **Speaker／language adaptation。** HMM 參數容易轉換、調適與插值，使多說話者、多語和小資料適應成為此世代的重要優勢。

來源：

- [Recent Development of the HMM-based Speech Synthesis System, 2009](https://www.research.ed.ac.uk/en/publications/a01bb759-bbbc-46b4-b4ab-10dd3e699ca1/)
- [Toda & Tokuda, Global Variance, Interspeech 2005](https://www.isca-archive.org/interspeech_2005/toda05b_interspeech.html)
- [Zen et al., Speaker and Language Factorization, 2012](https://research.google/pubs/statistical-parametric-speech-synthesis-based-on-speaker-and-language-factorization/)

### 為什麼仍屬同一世代

這些方法改善品質、控制與適應能力，但沒有改變核心生成鏈：

```text
HMM → acoustic parameters → vocoder
```

因此它們是重要突破，但屬於 HMM statistical-parametric 世代內部的成熟，而不是新的生成典範。

## 第二階段：2013–2016 — Neural Statistical Parametric 橋接世代

### 唯一代表論文

Heiga Zen, Andrew Senior, Mike Schuster, **_Statistical Parametric Speech Synthesis Using Deep Neural Networks_**, ICASSP 2013.  
原始出版頁：[Google Research](https://research.google/pubs/statistical-parametric-speech-synthesis-using-deep-neural-networks/)

### 上一階段的限制

傳統 HMM 系統通常用 decision-tree clustered context-dependent HMM，難以有效表達文字語境與聲學實現之間複雜、非線性的關係。

### 2013 年發生的轉變

Zen et al. 改用 DNN 學習 text-derived linguistic features 到 acoustic features 的映射。原論文報告，在相近參數量下，DNN-based 系統優於 HMM-based 系統。

生成鏈從：

```text
linguistic features
→ decision-tree clustered HMM
→ acoustic parameters
→ vocoder
```

改成：

```text
linguistic features
→ DNN
→ acoustic parameters
→ vocoder
```

### 為什麼值得獨立標示

這是 acoustic model 的建模典範轉換：

- 從 HMM 與 decision tree 轉為深度神經網路；
- 從較強的統計結構假設轉為非線性 representation learning；
- 為後續 RNN／LSTM 的時間序列建模與 neural end-to-end TTS 鋪路。

### 2014–2015 的延續

- **2014 BLSTM TTS：** Fan et al. 使用 BLSTM 捕捉長距離時間相依；原論文報告優於 HMM 與 feed-forward DNN，且輸出軌跡足夠平滑，不需 dynamic constraints。
- **2015 streaming LSTM：** Zen 與 Sak 使用 unidirectional LSTM-RNN，以 frame-synchronous 方式低延遲輸出 acoustic features。

來源：

- [Fan et al., BLSTM TTS, Interspeech 2014](https://www.isca-archive.org/interspeech_2014/fan14_interspeech.html)
- [Zen & Sak, Low-latency LSTM Speech Synthesis, ICASSP 2015](https://research.google/pubs/unidirectional-long-short-term-memory-recurrent-neural-network-with-recurrent-output-layer-for-low-latency-speech-synthesis/)

### 為什麼還不是 End-to-End

DNN／RNN 只取代了 acoustic model。系統仍需要：

- 人工設計的 linguistic features；
- 獨立 duration／acoustic 處理；
- 預先定義的 acoustic parameters；
- 傳統 vocoder。

所以 2013 的突破很重要，但尚未做到：

```text
原始文字 → 單一模型自行學習對齊與聲學表示
```

## 第三個轉折：2016–2017 — Neural Waveform 到 End-to-End

### 2016 WaveNet：重要前驅

WaveNet 直接以神經網路自回歸建模 raw waveform，原始研究顯示自然度超越當時的 concatenative 與 parametric TTS。

它改變了 pipeline 的最後一段：

```text
傳統 vocoder
→ neural waveform generation
```

但在 conditional TTS 設定下仍需要 linguistic／phonetic features，因此不代表完整的 text-to-speech pipeline 已端到端。

來源：[WaveNet, 2016](https://deepmind.google/blog/wavenet-a-generative-model-for-raw-audio/)

### 2017 Tacotron：完整世代分界

Tacotron 直接從字元預測 spectrogram，讓模型自行學習文字與聲音之間的對齊。

因此核心鏈才真正變成：

```text
characters
→ sequence-to-sequence attention model
→ spectrogram
```

這就是為什麼主時間軸仍用 [Tacotron 2017](https://research.google/pubs/tacotron-towards-end-to-end-speech-synthesis/) 代表 Neural End-to-End 世代，而把 WaveNet 2016 視為關鍵 enabling technology。

## 修正後的 TTS 世代

| 起點 | 世代 | 唯一代表論文 | 核心轉變 |
|---|---|---|---|
| 1980 | Rule／Formant | Klatt (1980) | 人工規則控制聲學參數 |
| 1996 | Unit Selection | Hunt & Black (1996) | 搜尋並重組真人錄音 |
| 2000 | HMM Statistical Parametric | Tokuda et al. (2000) | 由機率模型產生聲學參數 |
| **2013** | **Neural Statistical Parametric（橋接）** | **Zen et al. (2013)** | **以 DNN 取代 HMM／decision-tree acoustic mapping** |
| 2017 | Neural End-to-End | Tacotron (2017) | 字元到聲學表示的端到端學習 |
| 2019 | Parallel／Non-AR | FastSpeech (2019) | 明確時長與平行生成 |
| 2023 | Codec LM／Zero-shot | VALL-E (2023) | codec-token LM 與 acoustic prompt |

## 最重要的區分

```text
2000 HMM：
機率序列模型預測 acoustic parameters

2013 DNN／RNN：
神經網路預測 acoustic parameters
但仍保留 statistical-parametric pipeline

2017 Tacotron：
從文字直接學習對齊與 spectrogram
開始移除人工設計的中間 pipeline
```

## 證據狀態

- **Verified：** 2013 DNN 系統在原論文設定下優於相近參數量的 HMM 系統。
- **Verified：** 2014 BLSTM 與 2015 LSTM 延續 neural statistical-parametric 路線，改善時間相依與低延遲。
- **Verified：** WaveNet 改變 waveform generation；Tacotron 改變文字到聲學表示的完整 mapping。
- **Inference：** 將 2013–2016 稱為「橋接世代」，以兼顧 acoustic model 的重大轉變與整體 pipeline 的延續性。
