# 步驟 04：年份主線與技術分期

日期：2026-07-26  
狀態：已確認  
修正：細化步驟 03

## 決定

為了讓不熟悉領域的人能依序理解，`Audio Deepfake` 發展史採用：

```text
年份提供閱讀順序
技術轉折決定年代邊界
代表論文作為各階段的閱讀入口
```

因此，年份與技術不是互斥的兩種分類方式。年份是敘事骨架，技術演進是分期依據。

## 每個歷史階段的固定格式

```text
時間範圍：
當時的主流技術：
代表性論文：
相較前一階段的新能力：
尚未解決的限制：
對 Detection 造成的影響：
```

## 「代表性」的查證標準

不直接宣稱某方法或論文「最流行」。只有在下列證據支持時，才稱為當時的主流或代表性工作：

- 原始論文提出重要技術轉折；
- 後續研究、正式 challenge 或資料集持續採用；
- 多個可靠來源將其視為該技術家族的代表；
- 出版狀態與年份可以確認。

每個階段可以保留不只一篇論文，避免把同時發展的技術錯誤壓縮成單一路線。
