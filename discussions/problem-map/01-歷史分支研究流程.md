# 步驟 01：歷史分支研究流程

日期：2026-07-26  
狀態：研究中

## 已確認的問題

> 音訊偽造與其偵測問題，如何共同演變成今天的 Deepfake Audio Detection？

## 為什麼先研究歷史

歷史分支不是單純排列年份，而是追蹤：

```text
生成能力改變
→ 威脅方式改變
→ 舊防禦假設失效
→ 研究任務與評估方式改變
```

這可以幫助我們判斷：目前看見的困難是新問題，還是舊問題換了名稱。

## 查證流程

### 1. 同時追蹤三條時間線

1. **生成能力**：TTS、voice conversion、neural vocoder、zero-shot voice cloning。
2. **威脅與用途**：攻擊 speaker verification、偽造媒體、通訊詐騙、部分音訊修改。
3. **防禦與評估**：countermeasure、共同 benchmark、deepfake detection、跨分布與 adversarial evaluation。

### 2. 每個歷史節點記錄五件事

```text
時間：
新出現的能力或威脅：
先前研究依賴的假設：
哪個證據顯示假設需要改變：
它造成的新研究問題：
```

### 3. 歷史分期成立條件

只有當「生成能力、威脅場景、防禦目標或評估方法」至少有兩項同時發生可驗證變化，才建立一個新時期。單一模型或單一資料集不自動構成歷史轉折。

### 4. 證據優先順序

1. 原始論文與正式 proceedings。
2. 官方 challenge 計畫、資料與結果。
3. 作者或研究機構的官方頁面。
4. Survey 只用來找線索，不用來單獨確立歷史結論。

## 第一批已查證的歷史錨點

| 時間 | 已查證事件 | 對問題定義的意義 |
|---|---|---|
| 2013 | Interspeech 論文已討論 ASV 對 replay、speech synthesis、voice conversion 的脆弱性，並要求共同資料、指標與正式評估。 | 問題主要被定義為「保護 speaker verification」。 |
| 2015 | 第一屆 ASVspoof 提供共同 corpus、protocol、metric，並測試已知與未知的 synthesis／voice-conversion attacks。 | 從零散方法比較轉向標準化 countermeasure evaluation。 |
| 2016–2017 | WaveNet 與 Tacotron 分別推進 raw-waveform neural generation 與 end-to-end TTS。 | 生成端的自然度與模型結構開始快速改變。 |
| 2019 | ASVspoof 2019 同時區分 logical access 與 physical access，並引入神經聲學／waveform generation 與 t-DCF。 | 評估開始區分攻擊進入系統的方式，並把 detector 與 ASV 後果連結。 |
| 2021 | ASVspoof 2021 新增不依附 speaker verification 的 Speech Deepfake task，並加入 channel、codec 與 unmatched evaluation 條件。 | 問題開始明確從 ASV security 擴張到一般 fake-audio detection。 |
| 2022 | ADD 2022 納入低品質、部分偽造與生成者對偵測者的對抗任務。 | 研究單位不再只有完整 utterance 的二元真假。 |
| 2023 | VALL-E 展示以短 speaker prompt 進行 zero-shot personalised TTS。 | 生成端開始降低模仿未知說話者所需的資料門檻。 |
| 2024 | ASVspoof 5 將 standalone deepfake detection 與 spoofing-robust ASV 分軌，並加入 crowdsourced、非錄音室資料與 adversarial attacks。 | 評估進一步面向資料多樣性與針對 detector 的攻擊。 |
| 2024–2026 | 新 benchmark 持續強調跨生成器、跨來源、跨語言與 in-the-wild generalization。 | 目前問題逐漸從 in-domain accuracy 轉向分布外可靠性。 |

## 初步推論，尚未定案

目前證據支持兩個可能的歷史轉折：

1. **ASV spoofing countermeasure → application-agnostic deepfake detection**。
2. **封閉 benchmark 的平均效能 → 真實通道、未見生成器與 adaptive attacker 下的可靠性**。

這兩個轉折仍需補查反例與更早文獻，現在不能直接稱為研究缺口。
