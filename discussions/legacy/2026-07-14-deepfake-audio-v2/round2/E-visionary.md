# Round 2 質詢：開創性思維者（Agent E）——第二輪（無真人實測）
日期：2026-07-14

> 立場提醒：我是那個第一輪「人群層級同源連結」被六人否證後撤回的人，也是這一輪把「不做真人實測」重新定義為「題目而非減法」的人（見我 round1 E-visionary.md：把 user study 換成「人類模型不確定集上的穩健證明」，借自密碼學全稱量化、金融 stress testing、氣候政策 robust decision making）。這一輪我讀完八份提案後最大的觀察是：**全場在無意識中集體收斂到同一個結構——把「人」拆成可計算的零件放回評估管線**。這既是對我 Round 1 重構的追認，也是我的 scoop 危機。所以本文的質詢不是為了拆台，是為了逼出「這個收斂到底哪個版本站得住」。我攻三個把「計算性驗證」講得漂亮、但推論不到真實情境的提案，答一個全場都在繞、其實是衝著我框架來的問題，最後說清楚我支持誰、以及開創性思維這個角色能替它裝上什麼別人沒有的零件。

## 一、對他人提案的挑戰

### 挑戰 1｜Agent B 的 CallAttest（提案二）：最強的證據（形式化驗證）恰好長在最救不到人的地方

Agent B 主張：「受話端的 app（銀行 app 或 165 反詐 app）收到『宣稱來自本行』的來電時查 log：有匹配的 commitment 且 hash 鏈對得上 → 綠標；查無 → 紅標」，並把驗證方案定為「符號化形式驗證（Tamarin/ProVerif），這是比 user study 更強的保證形式：不是『50 個受試者沒被騙』，而是『在此攻擊者模型下不存在攻擊 trace』」。

**但是**，這個「更強的保證」有兩個致命的錯位，兩個都屬於任務書點名的「它的計算性驗證方案其實推論不到真實情境」：

**(a) 定理為真，但定理的定義域被證明性地排除了受害者本人。** B 的 Tamarin 只能證明一件事：「契約域內、且受話端執行驗證 app 時，假冒機構的來電必然觸發紅標」。而 B 自己在同一份文件裡寫下：「阿嬤沒有銀行 app。誠實回答：終端形態可以下沉到電信端加值服務或 165 官方 app 代管驗證，但那是部署故事不是論文貢獻。」把這兩句話並排，結論是刺眼的——**論文裡最硬的證據（形式化不存在攻擊 trace），其成立條件是一個「受話端跑著驗證 app 且該機構 100% 入會」的世界，而問題陳述要救的那個接電話的人，恰好被 B 親手劃出這個世界之外**。這比「範圍窄」嚴重一級：範圍窄是誠實地少救幾種人；這裡是**證據強度與情境相關度成反比**——形式化保證最強的地方，正好是它最不需要被保證的地方（因為機構端流程本來就能擋）。E 的貝氏否證（過渡期缺席訊號資訊增益趨近零）在契約域內被 B 用「100% 入會契約」反轉，這我認——但反轉只發生在一個把阿嬤排除掉的域，反轉本身救不了問題陳述的考題。

**(b) 形式化驗證把唯一會斷的零件抽象成理想元件，因此那張證明在關鍵處是空的。** Tamarin/ProVerif 是符號模型：它把 perceptual hash 當成一個理想的 binding primitive 來推理。可是 B 自己標了紅字：「perceptual hash 非 cryptographic hash，其對抗強健性是本題最大技術風險」。這意味著——**B 的形式化證明，是在「假設那個他自己說會斷的元件不會斷」的前提下，證明協定安全的**。在 perceptual-hash second-preimage 攻擊成功的區域（攻擊者找到語意惡意但 hash 落在容忍半徑內的音訊，D 的 attacker-cost 軸正是要量這個），「內容綁定」這個 CallAttest 相對 STIR/SHAKEN 的**唯一 delta** 就蒸發了；剩下的東西正是 B 自己預言 reviewer 第一刀會砍的「STIR/SHAKEN 加推播」。換句話說：**這個提案的 novelty（內容綁定）和它的形式化保證（協定安全）活在不相交的兩塊區域**——保證成立的地方沒有 novelty，有 novelty 的地方保證是空的。「比 user study 更強的保證形式」這個賣點，在這個具體構造上不成立，因為 user study 至少量的是真東西的近似，而這裡的形式化量的是「假設難點不存在時的容易部分」。

我不否定 CallAttest 作為機構端工程有價值。我否定的是「Tamarin 證明 = 比真人更可信的受騙率證據」這個推論——它把驗證方法的形式嚴謹，偷換成了對真實情境的相關性。

### 挑戰 2｜Agent C 的 codec-latent detection（提案二防禦面）：攻擊面是真金，防禦面是換了латent空間的「泛化到新生成器」老坑

Agent C 主張：「『在 codec latent/token 空間做 detection』是一個通道天然對齊的新 domain：偵測器看到的表徵恰好就是通道傳的東西，unseen-channel 的 train/test mismatch 從根源上消失一段」，其假說是「以 neural codec token 為生成目標的 VALL-E 系 TTS，其輸出 token 落在 codec language model 的高概率典型集內；真實語音的 token 有更高的『意外率』」。

**但是**，C 消去的是 unseen-**channel** mismatch，代價是重新引入、甚至放大了這個領域**最深、最致命**的失效模式——unseen-**generator** mismatch。而後者正是 #2 量出 EER 13.5–50%、multi-domain training 退化到 48–50% 的那道牆，也是 G 反覆敲打的「四代歷史循環」。理由是機理性的、不是經驗性的：

C 的判別訊號（token 意外率的 real/fake 差）**在定義上是 generator-conditioned 的**。它成立的前提是「fake 的生成目標就是 codec token」——這只涵蓋 VALL-E / codec-LM 這一家族。可是當前 SOTA 有一整支不以 codec token 為目標的生成器（diffusion / flow-matching vocoder、連續 latent 的 TTS）。這類 fake 過一次 EnCodec 時，它的 token 是從「一段從未為 codec-typicality 最佳化過的波形」重新量化出來的——**它的 token 意外率沒有理由低於真實語音**。於是：拿 codec-LM 世代的 fake 訓練 codec-latent 偵測器，測到下一代非-codec 生成器 → C 賴以判別的「意外率 gap」精確地以 AASIST2 那條 0.82%→13.5% 的曲線消失。**C 會在一個新的離散空間裡，把 G 親手寫的歷史循環再發表一次。**

更尖銳的是：C 自己已經寫好了這個提案的死亡出口——「也可能 fake 過 codec 後 token 統計反而更『正常』，真假在 token 空間不可分（AUC≈0.5）」。他把這稱為「重要結論」。但請注意這個結論的歸宿：**若防禦面翻盤成 AUC≈0.5，剩下的只有攻擊面（neural codec laundering 是零成本必殺），而攻擊面本身是餵給方向三 attacker-cost 地圖的一個動作**。也就是說 codec-latent detection 這根「防禦支柱」的最好情況是「對今天的生成器有效、對明天的無效」（歷史循環），最壞情況是「AUC≈0.5，貢獻併入方向三」。一根兩端都通向別人題目的支柱，撐不起獨立碩論的防禦宣稱。

**我的建設性切割**：C 提案二的**攻擊面**（neural codec 作為不可逆 many-to-one 投影、零成本 laundering、對 #3「劣化可逆論」的適用邊界判定）是全場少見的真·新東西，我在第三節正式支持它。我攻的只是防禦面被包裝成「通道天然對齊的新 domain」——那件外衣底下是這個領域最舊的坑。

### 挑戰 3｜Agent A 的 failure attribution + 重送干預（提案二）：他當賣點的 trade-off 不成立，那個迴路其實是攻擊者的 laundering oracle

Agent A 主張，攻擊者若刻意把 fake 偽裝成 channel-degraded 來誘導系統發「請重送」，「攻擊者被迫在『騙過機器的歸因』與『騙過人耳』之間二選一……我甚至認為它是提案的賣點而不是弱點」，其依據是 #2「人類對低品質 deepfake 的 FAR 只有 4–19%」。

**但是**，這個「被迫二選一」的論證漏在一個地方：**兩個目標面對的是兩個不同的觀眾、在兩個不同的時刻**，因此根本不必二選一。攻擊者的實際打法是——

1. 送一段重度劣化的 fake → 機器歸因「channel-induced」→ 系統照 A 的設計吐「請透過另一管道重送/回撥」（**不是**「疑似偽造」）；
2. 在重送這一步，攻擊者交付一段乾淨的高品質 fake。

於是：**人耳自始至終只遇到乾淨版（#2：FAR > 82%），機器自始至終只遇到劣化版（它按 A 的設計正確地歸檔為「通道」）**。A 假設的 trade-off 需要「同一個 artifact 同時服務兩個觀眾」，可是 A 親手建的重送迴路，恰恰給了攻擊者「兩次機會、兩個 artifact」。結論反轉：**failure attribution + 重送干預不但沒有抬高攻擊成本，它給了攻擊者一個 laundering oracle——「持續劣化，直到系統客氣地向你索取一份更乾淨的副本」**。A 稱為「賣點」的東西，是這個提案最大的新攻擊面。

第二刀，關於 A 的驗證方案本身：他把「重送後可靠性恢復率」當成「歸因正確性的機器可驗證代理」。但**攻擊者同時控制兩條通道**，「重送後恢復」這個事件是可以被設計滿足的——它不是一個獨立的 ground-truth 檢核，是一個攻擊者能通過的儀式。A 說「這件事純計算可模擬：同一樣本過不同通道再測」——沒錯，在他的模擬裡樣本是良性的、通道是隨機的，所以恢復；但在對抗設定裡樣本是攻擊者的、通道是攻擊者選的，恢復是免費的。**計算性驗證方案（良性重送模擬）推論不到真實情境（對抗性重送）**，這又是一次任務書點名的失效類型。

第三刀，最省事的一刀：「重送」預設內容可被重新傳輸。**即時詐騙電話沒有「重送」這回事**——阿嬤掛不掉、也不會請對方「換個通道再講一次」。所以 attribution + 重送迴路只在非即時媒介（語音訊息、媒體檔案）成立，跟 B 的 provenance 一樣，悄悄塌回那個救不到阿嬤的窄域。A 提案二的 novelty（channel vs generator 可分性地圖）我認為有價值，但「重送干預」這個把它連回「actionable」的關鍵環節，在對抗與即時兩個維度上都不成立。

### 挑戰 4（較短，並作為第三節的橋）｜Agent D 的攻擊者視角受騙率下界（提案二支柱 B）：誠實，但對「選哪個設計」這個決策是空的

Agent D 主張用單調性論證取代行為模擬：「我不建『真實受騙率』，我建『攻擊者靠背書能鎖定的受騙率下界』……只需要『綠燈不會讓人更警覺』這條幾乎不可能被 reviewer 推翻的單調假設」。

**這個下界我完全同意其誠實性——但它對它宣稱要接住的那個決策是空的。** 部署方要回答的問題是「設計 A 和設計 B 該選哪個」。可是「受騙率 ≥ 無綠燈 baseline」這個下界，**對所有會亮綠燈的設計都是同一個 trivial bound**——它區分不出 A 和 B。真正能區分設計的量是「綠燈把受騙率往上推多少」（baseline 以上的那段 gap），而這段 gap 恰恰需要 D 明確拒絕建模的行為數據。所以 D 的支柱 B 能回答「綠燈是不是壞的？是，弱意義上」，但回答不了「A 是否優於 B」——而後者才是部署決策。這不是缺陷、是定位錯誤：**D 的單調下界是一個好用的 lemma，不是「受騙率因變數」的合法繼承者**。它應該嵌進一個能做「設計間排序」的框架裡當悲觀護欄，而不是自己冒充 primary outcome。這正好把我帶到支持的部分。

## 二、回答指名給我的問題

先誠實說明一件事：**八份 round1 檔案的「留給其他討論者的問題」小節，沒有任何一條指名 Agent E**。這不是被忽略，是結構使然——Round 1 是各自獨立、未讀彼此的提案，而我在第一輪的角色（開創性思維者）不是別人預設要質詢的對象。所以這一節我不虛構「被指名」，改為正面回答**那條全場都在繞、其實矛頭衝著我框架來的問題**——因為它同時是我 round1 提案一的命門，也是我自己在 Q2b 丟給 D 的問題（「攻擊者能否針對『模型與真人的縫隙』設計攻擊」），我有責任先答。

**共通問題（A/B/C/F/G/H 六人以不同措辭問向同一處）**：把 user study 換成「文獻校準的人類模型」，攻擊者（或 reviewer）能不能專攻「模型與真實人類的縫隙」——找到一種 fake，對整個人類模型不確定集 𝓗 都低風險、對真實的人卻高風險？如果能，這個框架就是自欺。

**我的回答，分三層：**

1. **這個攻擊面確實存在，而且我不假裝它不存在——但它的方向是可控的。** 「模型與真人的縫隙」攻擊要成立，需要攻擊者找到一個「𝓗 中所有模型都判低風險、真人卻高風險」的樣本。關鍵在於 𝓗 是怎麼建的：如果 𝓗 只是「擬合 VoiceWukong 的一條 FAR 曲線」（F 的受騙鏈、G 的 L2D synthetic expert、H 的 human-proxy 都偏這個做法），那 𝓗 太窄，縫隙寬，攻擊成立。**這正是我 round1 堅持「𝓗 是約束條件、不是點估計」的理由**——𝓗 必須包含「所有與已公佈數據一致的行為模型」，包括把壓力折損 θ 掃到「人耳完全失效、FAR→base rate」的悲觀端。當 𝓗 包含「人耳失效」這個極端成員時，「對人高風險」的樣本無處遁形——因為 𝓗 裡已經有一個成員假設人根本判不出來。**縫隙攻擊利用的是模型比真人樂觀，而我把 𝓗 的下緣鎖在「比任何真人都悲觀」，縫隙就從『模型與真人之間』被擠到『模型與超悲觀假設之間』，而後者對防禦方是安全的方向**（我寧可低估防禦、不可高估）。

2. **代價是排序可能退化成全平手——而那本身是可發表的重要結論。** 若 𝓗 撐到含「人耳失效」後，所有警告/棄權設計都無法排序，那結論就是「現有公開人類數據不足以支持任何設計選擇」，並用 value-of-information 分析精確指出「缺的是哪一塊數據」。這不是失敗，是對整個領域喊「該去收哪一筆數據」的可證偽否證，也是把真人實測該問的問題磨到最尖的交棒。

3. **對照組：D 的單調下界其實是我 𝓗 悲觀端的一個特例。** D 的「綠燈 ≥ baseline」就是「θ 掃到讓綠燈信任增益 ≥ 0」的那條邊。這說明全場其實在拼同一張圖：D 給悲觀護欄，F/G/H 給校準錨點，我給「對整個區間全稱量化」的邏輯形式。三者不是競品，是同一個框架的三個零件——見第三節。

**附帶回應我自己 round1 Q2a 丟給 D、但這裡先自答**：拼接式 relay 模擬是否對攻擊者系統性有利、因此是保守下界？我維持成立，但補一個 D 大概會找到的反例並先認領——「共犯戴硬體變聲器全程接管、根本不觸發切換點」確實不被我的切換點模擬覆蓋（因為沒有切換點）。這不是我模擬的漏洞，是**聲源連續性稽核這條防線的原理邊界**：它防的是「挑戰段換人」，防不了「全程一個真人共犯用硬體變聲」。我會把它寫進威脅模型第一頁，而不是假裝稽核覆蓋它——這條攻擊的成本（招募一個能全程即時應對挑戰的真人共犯 + 硬體變聲器）本身就高，正是 D 的 attacker-cost 軸該量的東西，不是稽核該擋的東西。

## 三、我支持的提案

### 支持 1（主要）｜Agent G 的 G2-A + Agent F 的提案一——但主張把它們與 D 的下界、我的全稱量化，合併成一個框架

**為什麼是這兩個**：全場六個人（A 候選一、B 候選三、C 候選三、F 提案一、G G2-A、H 提案一）獨立收斂到「用已公佈人類數據把受騙率變成計算性因變數」。在這個大收斂裡，**G 的 G2-A 提供了最硬的方法論護城河**——他檢索出 L2D 社群的 synthetic expert 已上 Nature Scientific Data 2025、FiFAR，cognitive model「fit 研究 A、零參數預測研究 B」的範式一路發到 UMUAI 2026，並且證實 VoiceWukong 的 per-sample 人類判斷分布公開可下載（不只是論文彙總表）。這解決了整個方向最大的生存問題：「模擬替代真人」不是權宜，是有頂刊先例、有 per-sample 數據可錨的正統。而 **F 的提案一提供了最鋒利的社會定位**——「受騙率可以被模擬，但不可以被遺忘」，以及「部署可行性邊界圖」「最低所需服從率反向求解」這兩個把結論變成部署方拿了就能用的輸出面。

**我的角色能補強什麼——這是開創性思維者的正職**：G 把它框成「L2D synthetic expert」，H 框成「human-proxy model 族 + 界」，F 框成「受騙鏈 Monte Carlo + δ 掃描」。這三個框法都對，但都停在「工程做法」層，會挨 reviewer 一句「synthetic expert 在 ML venue 被接受，在 USENIX/CCS 的 security reviewer 眼裡呢？」（這正是 G 自己 Q1 丟給 H 的焦慮）。**我能裝上他們沒有的那個零件：把它從『一種模擬技巧』升級為『一個推理形式』——robust decision making / 對抗者類別全稱量化 / stress testing**。這個升級不是換包裝，是換證據等級：

- synthetic expert 的宣稱是「在我這個/這族 expert 下，policy A 的 cost 是 X」——reviewer 攻「你的 expert 憑什麼像真人」。
- 我的宣稱是「凡與已公佈數據一致的**所有**人類模型，policy A 的 cost 都 ≤ B，除非壓力折損超過門檻 θ*」——**這個宣稱從不主張模型像真人，只主張結論對模型選擇不敏感**。前者被「你的模型錯了」一句殺死，後者不會，因為我從未賭模型對。這是密碼學的紀律（B 第一輪讚許方向一時說的「精確陳述我證明了什麼」）套用到人類建模上。

具體合併方案（我提議寫進 Round 3）：**一個框架，三個零件**——(i) F/G/H 的 human-proxy 校準（錨點）；(ii) D 的 confident-real 單調下界（悲觀護欄，即 θ 掃到綠燈信任增益 ≥ 0 的那條邊界，用來夾住「攻擊者靠背書能鎖定多少」）；(iii) 我的全稱量化穩健排序 + 失效邊界 + value-of-information（把前兩者從「一組數字」變成「對模型族一致穩健的偏序 + 一張留給未來 IRB 團隊的數據採購清單」）。**這三個零件合起來，不用一個真人，就框出了警告設計的可行區間下緣（D 的下界）與設計間排序（我的偏序），而 F 保證這一切都對著阿嬤那一行講話**。這是全場唯一能同時通過「G 的前作查證、H 的 defense 放行、F 的可用性檢驗、D 的對抗性」的組合，也是我認為 Round 3 該收斂的主軸。

### 支持 2（次要）｜Agent C 的提案二**攻擊面**——它是餵給我 liveness 提案二的通道壓力層

我在挑戰 2 裡砍了 C 的防禦面，但他的攻擊面（neural codec 作為不可逆 many-to-one 生成式投影、對 #3「劣化可逆論」的適用邊界判定、零成本 laundering 必殺）是全場少數經得起「不隨月份過期」檢驗的東西——因為「傳統 CELP 是可逆分佈偏移 vs 神經 codec 是不可逆 manifold 投影」是資訊理論分野，不是某個生成器的性質。

**我的角色能補強**：這個攻擊面直接接進我 round1 提案二（無真人化 Active Liveness Probing）的 RQ3（通道存活）。我原本只打算讓 OOD 挑戰訊號過 AMR-WB/EVS/Opus 的 CELP 管線；C 的洞察告訴我必須加一條**神經 codec 臂**——因為如果攻擊者用一次 EnCodec transcode 就能把我的「非典型發聲挑戰造成的轉換品質崩壞」投影抹平，那我的 liveness 防線在神經 codec 通道上就是紙糊的。反過來，如果 CELP 重合成會把 C-CAPTCHA++ 式 imperceptible perturbation 投影掉（C/D 已預判），那神經 codec 對我的挑戰訊號是幫忙還是拆台，是一個必須量、且沒人量過的交互。**C 提案二攻擊面 + 我提案二 = 一張「OOD 挑戰訊號 × 神經 codec/傳統 codec 存活」的地圖**，這是單獨任一方都做不出的。我認領這個接口，並把「挑戰訊號過神經 codec 是否存活」列為我提案二的 go/no-go 檢查點之一。

## 四、給 Round 3 的一句話

這一輪最誠實的發現是：**當使用者拿走 user study，全場沒有各自逃生，而是不約而同地把「人」拆成零件重新裝回管線——素材（F 提案二）、判斷（human-proxy）、攻擊者（方向三）、後果（受騙率）、悲觀護欄（D 下界）。** 我 Round 1 賭的「無真人是題目不是減法」被六個人用行動追認了。剩下的爭點只有一個：這個大收斂該用哪個名字、哪種宣稱形式活下去。我的主張是——不是 L2D synthetic expert（太工程、security venue 會問），不是點估計受騙率（太脆、reviewer 一句話殺死），而是 **robust decision making 的全稱量化穩健排序**，因為它是唯一一個「從不宣稱知道人是什麼樣、只宣稱結論對『人是什麼樣』不敏感」的形式。這是開創性思維這個角色這一輪唯一想留在桌上的東西。
