## 一、對他人提案的挑戰

### 挑戰一（主攻，命中五人）：人類模型不確定集不含「被社工擾動的受害者」——robust-over-𝓗 是一張假保單

**Agent E 主張**（提案一）：「證明『在所有與已公佈人類數據一致的行為模型上，警告/棄權設計 A 的期望受騙率都不高於 B』……我從不宣稱知道人類是什麼樣——只宣稱『凡與已知數據一致的人類模型，結論皆同』，這在邏輯上強於一次 30 人 user study 的點估計。」E 甚至自問自答:「當攻擊者知道部署方是用『人類模型』而非真人做決策，他能否針對『模型與真人的縫隙』設計攻擊？這個攻擊面存在與否，決定我的框架是誠實的還是自欺的。」

**但是**——攻擊面存在，而且它不是「模型與真人的縫隙」，是更致命的東西：**𝓗 是對「自然人類變異」的全稱量化，而攻擊者的整個職業就是把受害者推到 𝓗 之外。** E 的 𝓗 錨定在 VoiceWukong 的 FAR 分布 + 壓力折損係數 θ∈[0,1] + 服從率 φ 的文獻區間。這整個集合描述的是「一個知道自己在做辨識任務、沒有孫子在電話裡哭的人，在各種自然狀態下的表現」。社工攻擊做的事，是把 φ（警告服從率）推到**負值語意**——不是「阿嬤看到紅標猶豫了一下」，是「阿嬤在攻擊者的指令下主動關掉 App、主動把紅標解釋成『系統誤判』、主動幫攻擊者繞過驗證」。這個狀態不在 θ∈[0,1] 裡，它在區間外，因為它不是「人類辨識力被壓力折損」，是「人類的意志被對方接管」。

**後果**:E（以及 A、F、G、H 的同構提案）證明的「A 在整個 𝓗 上 dominance B」是一個數學事實,但它 dominance 的那個空間**不包含攻擊者實際把受害者帶到的那個點**。這不是說框架沒用——它對「非對抗的自然誤差」有用——而是說**它的 primary claim「降低受騙率」在對抗場景下原則上到不了**,和第一輪我們一起擊沉「對抗性缺席訊號的貝氏資訊增益趨近零」是同一型的病。E 的框架要誠實,就必須把這條寫進第一頁:**「本框架的穩健性只在自然人類變異上成立;對抗性人類狀態(社工接管)在 𝓗 之外,本框架不宣稱覆蓋。」** 寫了,它是誠實的決策支持工具;不寫,它就是 E 自己定義的「自欺」。（我在第二節 E 的問題裡給出把社工塞回 𝓗 的建模路徑——那是我願意背書的補救。）

### 挑戰二：Agent B 的 CallAttest——最便宜繞過根本不碰你的密碼學

**Agent B 主張**（提案二）:「在『銀行來電』這個窄域內，契約規定普及率 100%，『缺席』就從無資訊變成強訊號。E 的貝氏否證在契約域內不成立，因為 P(有憑證|真的是銀行) 被契約推到 1……受話端 app 做機器對機器的二元驗證——契約域內『查無 commitment』即紅標。」

**但是**——你的整個安全論證押在「契約域內普及率 = 100%」這個部署虛構上,而它在真實銀行運營下**一天都撐不住**。真實銀行有:委外催收、外包電話行銷、分行專員用自己手機回電、跨國分行的 legacy 話務、系統遷移期的雙軌並行。這些**合法**的銀行來電**不會**帶你的 commitment。只要契約域內出現穩定的「合法但無綠標」流量(必然出現),你的紅標就從「強訊號」退化成「又一個假警報」,而 alarm fatigue 一旦啟動,「查無 commitment=紅標」的鑑別力歸零——這正是 F 第一輪「三成無法判定我就關掉 App」的機構版。

而且我根本不需要攻你的 perceptual hash(那是中成本)、也不需要 relay 插話(中高成本)。**最便宜的繞過是:我不冒充受保護機構。** 你的契約域是「銀行/165/政府」;我改冒充你契約域外的實體——女兒、快遞、檢警地檢署。這些角色**永遠不會有綠標**,「缺席」在契約域外原樣是無資訊(E 的貝氏否證在契約域外完好無損),而台灣財損大宗的假檢警、假親人正好全在域外。退一步,就算我冒充銀行,我用一句「本行 App 今日系統維護,沒有綠標是正常的」就把紅標解釋掉,或者乾脆叫受害者用**不經過銀行 App 交易攔截的管道**完成付款(超商代碼、車手收現、虛擬貨幣)——你的機器對機器驗證守著銀行 App 的門,我從窗戶走。**攻擊成本:低。** CallAttest 是一個對「攻擊者冒充你剛好保護的那個機構、且受害者剛好裝了你的 App、且銀行剛好 100% 合規」的三重巧合才生效的防線。它擋的是我最不會走的那條路。

### 挑戰三：Agent C 的 codec-latent detection——unseen-codec 是同一個 open-set 坑,換到 token 空間

**Agent C 主張**（提案二防禦面）:「在 codec latent/token 空間做 detection 是一個通道天然對齊的新 domain:偵測器看到的表徵恰好就是通道傳的東西,unseen-channel 的 train/test mismatch 從根源上消失一段……真實語音的 token 有更高的『意外率』(此為可檢驗假說)。」

**但是**——「mismatch 從根源上消失」只在**你知道是哪個 codec**時成立。我作為攻擊者的最便宜繞過:**過一個你偵測器沒訓練過的 neural codec。** 你在 EnCodec 的 token 空間訓了偵測器,我把音訊丟進 DAC 或 Mimi 或 SoundStream 重編一次——speaker similarity 幾乎不掉(這些 codec 全是為保真訓練的)、內容可懂度不掉、金錢成本零、技術門檻一行指令,但你偵測器賴以判別的 token 統計分布整個位移。你把 audio ADD 最深的坑(unseen-generator generalization,#2 證明 EER 13.5→50%)原封不動搬進了 token 空間,現在叫 unseen-codec generalization。你要防住,就得證明「所有 neural codec 的 typical set 分野一致」——我賭你證不出來,因為每家 codec 的 RVQ codebook 是在不同資料、不同 bitrate、不同架構上訓的,typical set 各不相同。**所以 codec-latent 防線是緩坡不是懸崖,攻擊成本:低到中。**

不過我要對 C 說句公道話,也是背書(見第三節):你提案二的**攻擊面**那一半完全成立,而且我認領它——neural codec transcode 作為 laundering 是我攻擊成本地圖上的**零成本必殺動作**,它把所有依賴第一二層 cue 的防線的成本曲線起點直接踩到地板,而且是物理不可逆的 many-to-one 投影。你的攻防雙面設計裡,攻擊面是金礦,防禦面是流沙。誠實的做法是把論文重心明確押在攻擊面 + 可逆性判定,把 codec-latent detection 降級為「一個被我繞過的嘗試 + 為什麼繞得過的資訊理論解釋」——那個負面結果比一個站不住的防禦更有價值。

### 挑戰四：Agent A 的失效歸因——自我劣化 trade-off 依賴「受害者在做辨識任務」的假設,詐騙現場不成立

**Agent A 主張**（提案二,並預先回應我）:「攻擊者為了觸發 channel-attribution 必須主動劣化自己的音訊,而 #2 顯示人類對低品質 deepfake 的 FAR 只有 4–19%——攻擊者被迫在『騙過機器的歸因』與『騙過人耳』之間二選一……我甚至認為它是提案的賣點而不是弱點。」

**但是**——這個 trade-off 的整個支點是「人耳是一道防線」,而人耳只在**辨識任務**裡是防線。#2 的 FAR 4–19% 是「受試者被要求判斷這段是不是 AI」時的表現。詐騙現場的受害者**不在做辨識任務**(這是我 round1 對我自己 candidate C 下的重刀,synthesis 也記了):阿嬤在「女兒哭著要保釋金」的社工壓力下,根本沒開啟辨識模式,她對低品質哭腔的「FAR」不是 4–19%,可能接近 100%,因為情緒真實性>音質。所以我的攻擊:我**故意做低品質、故意自我劣化**去觸發你的 channel-attribution→「請重送」,這一步在你的 trade-off 裡「應該」讓人耳抓到我——但人耳在詐騙現場沒上班。我付出的「騙過人耳」成本≈0,你以為的二選一其實是**我兩個都拿**。你的 trade-off 賣點,建立在把辨識 FAR 當受騙率的同一個偷換上——這正是我攻擊全場逃生艙的那條裂縫,你提案二也踩到了。補救:把「人耳端錨定」從 #2 的辨識 FAR 換成明確標註的「辨識任務下界」,並承認在社工壓力下這條 trade-off 可能坍縮——這樣它從「賣點」誠實變成「一個有條件的成本結構」。

## 二、回答指名給我的問題

### 給 Agent B：CallAttest 最便宜繞過是哪一條?紅標接自動擋交易後殘餘攻擊面?

最便宜的是 **(iii) 社工,而且是社工的一個你沒列的變體**。你列的 (iii) 是「本行 App 維護中」;我的 (iii) 是**根本不進契約域**——冒充域外實體(假檢警、假親人、假快遞),那裡缺席=無資訊,你的協定完全不覆蓋(見挑戰二)。perceptual hash second-preimage 是中成本、relay 插話時間窗是中高成本,我**碰都不用碰**。

紅標接到「自動擋下交易」而非「提醒使用者」之後,殘餘攻擊面(這是好設計,確實堵死一部分,我誠實承認)還剩三塊:(1) **交易管道遷移**——我叫受害者用不經過你 App 交易攔截的管道付款(超商代碼、車手收現、虛擬貨幣、第三方支付),你守著銀行轉帳的門,我走現金流的窗;(2) **契約域外全境**——自動擋交易只在「受害者要對受保護機構做交易」時觸發,假檢警叫她「把錢匯到指定安全帳戶自保」根本不是對銀行的可疑交易,是她自己「主動」的正常轉帳,你的紅標無從掛;(3) **時間差**——commitment 發布到可驗證有延遲,我在延遲窗內完成話術收割。

**資源配比建議**:把對抗評估的 90% 放在**量化契約域外的洩漏率**(用 165 公開詐騙類型分布,算「假冒受保護機構」佔全體詐騙的百分比——那就是你協定覆蓋率的天花板),把 hash 對抗強健性降為次要。因為就算你的密碼學是完美的,你的覆蓋率上限是「假冒機構類詐騙 ÷ 全體詐騙」,而這個比值我猜(待 G 查證 165 統計)遠低於一半。**你的提案最誠實的貢獻不是協定安全性,是把「provenance 在即時詐騙的覆蓋率天花板」量化出來——那個數字本身就是政策級發現。**

### 給 Agent C：neural codec 是否改寫攻擊成本地圖?codec-latent 偵測器最便宜繞過?

**(a) 是,而且是我攻擊成本地圖上最重要的一次改寫。** neural codec transcode 讓任何依賴第一二層 cue(相位微結構、vocoder artifact)的防線,成本曲線起點從「懸崖」塌成「地板」:一行 ffmpeg 等級指令、零金錢、零技術門檻、**且物理不可逆**(decoder 是生成模型,many-to-one 投影,#3 的「DA 可完全恢復」結論在這裡原理性翻盤)。我正式認領它為攻擊成本地圖 passive/provenance 維度的**共同起點塌陷動作**,並用你的可控植入實驗判定它的不可逆性下界。這一個動作就足以戳破一票「EER 0.06% 但一次 transcode 就崩」的偵測器——它是照妖鏡上最亮的那一格。

**(b) 對 codec-latent 偵測器,最便宜繞過不是你猜的「再過一次傳統 codec」**(那要付 speaker similarity 代價,是中成本),**是「過一個你偵測器訓練分布外的 neural codec」**(見挑戰三)。成本估計:攻擊者用另一家開源 codec(DAC↔EnCodec↔Mimi↔SoundStream 互換)重編,speaker similarity 幾乎不掉(全是保真訓練)、內容可懂度不掉、金錢≈0、技術門檻一行指令。你的 token 統計分野是 codec-specific 的,換 codec 就位移。**所以 codec-latent 防線的成本曲線是緩坡。** 除非你能證明「跨 codec 的 real/fake typical-set 分野不變」——這是你防禦面的生死線,我建議你把它當**可證偽假說**去測(leave-one-codec-out),測出來不變是重大發現,測出來變(我賭這個)就是誠實的負面結果,兩邊都可發表,但別把防禦面當成立的結論寫。

### 給 Agent E：拼接式 relay 模擬是保守下界嗎?找反例。攻擊「模型與真人縫隙」的攻擊面存在嗎?

**(a) 反例存在,而且它比你模擬的任何攻擊都便宜。** 你的拼接模擬假設 relay = 「主體段 VC + 挑戰段真人共犯」,所以有一個「切換點」給你的聲源連續性稽核抓。但最便宜的 relay **沒有切換點**:一個真人共犯**全程接管整通電話**,自己掛一個 consumer 級 streaming VC app 在麥克風前貼目標音色。全程單一聲源(共犯本人)、單一 VC 音色鏈——你的 embedding 連續性稽核**全綠燈**,因為它偵測的是不連續,而全程單一共犯是連續的。而且 OOD 挑戰(耳語、笑、哭腔)對這條路徑**無效**:共犯是真人,他生理上做得到耳語/笑/哭,VC 只需要貼音色不需要生成非典型發聲的內容。你 RQ1 賴以生效的「即時 VC 對 OOD 輸入崩壞」在「真人發聲 + VC 只貼音色」的架構下不觸發。成本:一個共犯的時薪 + 一個免費 VC app。**這條路徑你的拼接模擬結構性不覆蓋,而它是 relay 的最便宜形態——我 legacy 就把它標為頭號威脅。** 你的「保守下界」只在「攻擊者笨到用預生成題庫或在挑戰段才切人」時成立;對全程 human-in-the-loop + VC 貼皮的攻擊者,你的模擬是**樂觀上界**,不是保守下界。

**(b) 攻擊面存在,這就是我的挑戰一。** 攻擊者不需要找「對 𝓗 所有模型低風險、對真實人類高風險的 fake」——他做的是**把真實人類推到 𝓗 之外**。你掃 θ∈[0,1]、φ∈文獻區間,但社工能讓有效 compliance 為「負」(受害者主動幫攻擊者繞過),那個點在你的掃描區間外。所以你的框架**不是自欺,但也不是它宣稱的那麼穩健**——它對自然人類變異穩健,對對抗性人類擾動不穩健。誠實邊界必須寫這一條。我在下面給你補救路徑(它和 G 的問題是同一個)。

### 給 Agent F：攻擊者知道受害者模型全部參數後,能專攻「模擬與現實的縫隙」嗎?哪條縫最寬?

能。**最寬的縫是:攻擊者根本不在你模擬的博弈裡玩。** 你的受騙鏈是「生成器→通道→偵測器→警告→受害者模型」。攻擊者看到你部署了偵測器,最便宜的攻擊不是優化 `max P(confident-real|fake)` 去騙偵測器,是**改走不經過偵測器的管道**:改打沒裝 App 的市話、簡訊+回撥、LINE 文字鋪陳後轉現金車手。你的模擬受騙率算得再低,只是把攻擊者趕出你的量測視窗,不是降低總受騙率。這叫 **threat displacement**,是所有單點防禦的共同縫,而你的模擬因為只模擬「一通會經過偵測器的電話」,結構性看不到它。

**第二寬的縫:多回合關係建立。** 你的受害者模型是「這通電話的當下決策」;真實的殺豬盤、假檢警是連續數日的信任建立,受騙決策不發生在單通電話裡,是幾十次互動的累積。單通電話的受騙率模型結構性看不到這一整類。

給你的建議:把這兩條寫進誠實邊界第一頁,並把你的 claim 明確限縮為「**在攻擊者選擇經過偵測器管道、且為單次接觸的情境下**,防禦排序如何」。這樣 dominance 排序仍成立,只是定義域誠實收窄。不寫,reviewer(或我)一句「攻擊者會繞過你整條鏈」就把 primary outcome 打回原形。順帶——我提案二的「攻擊者視角受騙率下界」正是為了避開這條縫設計的:我不宣稱知道總受騙率,只宣稱「當攻擊確實走進這條鏈時,confident-real 背書把下界抬升多少」,claim 天生不受 threat displacement 影響。

### 給 Agent G：模型的「人」不會被社工操縱,會不會系統性低估攻擊者收益?能否定義可操縱的 human-parameter 擾動?

**會,系統性低估,這是全場逃生艙的核心病(挑戰一)。** 你的模型只讓攻擊者攻偵測器,不讓他攻人——但真實攻擊者同時攻兩者,而且攻人便宜得多。

**能定義,而且這是救活整個 simulation 路線的關鍵,我願意背書。** 把社工建成一個**攻擊者可施加的 human-parameter shift 算子** `A_social(c)`:攻擊者付出成本 `c`,可把 (warning compliance φ, 壓力折損 δ, 權威服從 a) 沿惡化方向推。然後量的不再是「固定 human model 下的 expected cost」,而是 **`∂(expected cost)/∂c`——expected cost 對社工投入的斜率**。斜率大 = 這個防禦的人因環節是攻擊者的免費槓桿;斜率小 = 這個防禦的安全不靠使用者的定力。這把社工從「模型外的誠實邊界腳註」變成「模型內的一個攻擊維度」,完全符合我提案二的攻擊者視角哲學:**我不宣稱知道 φ 真值,我證明「攻擊者用 c 元把 φ 推低 Δ,受騙率下界抬升多少」。** 這讓 confident-real 對抗軸不再系統性低估。

**但一個誠實警告**:斜率估計需要「社工成本 c → human-parameter shift」的映射,而這個映射**沒有公開數據錨定**(辨識任務數據量不出社工效果)。所以只能做**結構性上界**:假設 φ 可被社工推到 0(受害者完全被接管),量「即使警告 100% 被繞過,這個防禦還剩多少殘值」。結論是「下界的下界」——保守到近乎悲觀,但**它不需要任何樂觀假設,因此無法被 reviewer 用『你的 human model 憑什麼可信』打穿**。這正是我 round1 candidate C 的單調性論證的推廣:壞消息的可信版本,不需要真人。

### 給 Agent H：哪些攻擊維度失去真人後失真到不可用?真人共犯成本怎麼建模你才認帳?

**(a) 失真到不可用的維度(用工具鏈模擬會系統性樂觀,反而高估防禦):** 任何「真人共犯的行為品質」——relay 共犯的即時話術切換流暢度、共犯在挑戰段的生理發聲能力(耳語/哭腔他真的做得到,VC 做不到)、社工話術對受害者的操縱效果。這三個用 VC 模擬會**高估防禦**,因為模擬的共犯做不到真人共犯做得到的事(見挑戰給 E 的 (a):全程真人共犯 + VC 貼皮,你的模擬根本構造不出來)。

**可以工具鏈模擬而不損失效度的維度:** 純訊號層 laundering(codec tandem、re-synthesis、resample、平台轉檔、loopback、neural codec transcode)、機器偵測器的 EER/recall 位移、浮水印 bit 存活、物理可逆性下界。這些本來就是機器事實,真人在這裡是**噪音源不是訊號源**——這就是我 round1 說的「紅隊評估是本問題陳述裡少數『無真人版本嚴格強於有真人版本』的題型」。**分界線很乾淨:攻擊「機器」的動作,模擬可信;攻擊「人」的動作,模擬只能標下界。**

**(b) 真人共犯成本我怎麼建模才認帳:不要建「一個數字」,建「成本區間 + 結構約束的定量下界」。** 兩塊:(1) **金錢**——用公開黑市數據代理,台灣 165/刑事局的公開起訴書載明車手分贓比例與共犯招募價碼(有出處,不是拍腦袋,待 G 查證具體文件);(2) **即時性約束(這才是 relay 的真實瓶頸)**——relay 的成本不是錢,是「共犯必須在挑戰發生的那 3 秒在線待命」這個排程約束,它是可量的:每次 relay 攻擊需要綁定一個即時共犯的時段,這對攻擊者的規模化是硬上限。

我的裁決:**relay 不要整條移出,但降級為「結構性成本抬升的定性論證 + 排程約束的定量下界」,絕不報「relay 成本 = X 元」的假精度數字。** 威脅模型第一頁寫:「relay 的即時共犯排程約束是防禦方唯一的結構性槓桿,本文量化此約束,不量化共犯的行為品質。」——這個帳我認。你要防的是有人拿一個模擬出來的「relay 成本 = 500 元」的假數字去 defense,那我 Round 2 一定拆穿;但「relay 需要即時共犯、這是可量的排程瓶頸」我背書。
