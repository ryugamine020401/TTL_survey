# 最終統整 v2：五個無真人實測的碩士論文方向
日期：2026-07-14

> 主持人統整。本文閱讀了 00-problem-statement（本輪硬性限制）、survey/README（8 篇文獻與 Research Gap 地圖）、legacy 03-synthesis（第一輪五方向，作為對照），以及本輪 round1–round3 共 24 份討論紀錄後寫成。全程引用具體發言與文獻編號（#1–#8 對應 survey；G2R2-S、G3-S 為 Agent G 的檢索編號）。凡標「猜測」者為未經實測的推論。本輪的硬性前提：**所有實驗必須是計算性/技術性的，絕不做任何真人實測**（可引用文獻已公佈的人類數據做建模）。

## 一、與第一輪的差異：「不做真人實測」對五個舊方向的衝擊與本輪的回應

第一輪（legacy）收斂出五個方向。本輪的硬性限制「不做真人實測」對它們的殺傷力**分佈極不均勻**——Agent D 一句話定調：「這是一把只砍防守方、幾乎不砍攻擊方的刀，因為防禦的價值命題是『救不救得了人』（人的行為），攻擊的價值命題是『系統會不會給我背書、我要付多少』（機器事實）。」逐一盤點：

| 舊方向（legacy） | 「不做真人」的衝擊 | 本輪如何回應 |
|---|---|---|
| **一、誠實棄權 + 警告 UX + 受騙率量測** | **被打中心臟**。它在第一輪拿首選的唯一決定性理由（H：「全場唯一能指著數據說『受騙率從 X 降到 Y』」）建立在 30–50 人 user study 上，本輪整段違規 | **換心臟，不換題目**。受騙率的 primary outcome 由「實測點估計」改為「文獻校準人類模型族上的穩健偏序 + 失效邊界 + 單調下界」（Agent E 的 robust decision making 形式 + D 的 confident-real 單調下界）。演化成本輪**方向一** |
| **二、真實通道存活 benchmark** | **幾乎零衝擊，甚至淨加分**。rig 是設備對設備、播放公開語料，本無真人；砍掉「團隊錄音」改用公開語料後，連 IRB 送件都消失。但被 G 的兩顆前作魚雷（2509.26471 Presentation、RTCFake）侵蝕了「首個真實通道」錨點 | **重錨 + 升級**。novelty 撤守到「蜂巢電信網 × watermark/provenance bit 存活【零前作】× Article 50 × 繁中」，科學主軸從「量落差」升級為「分解落差 + 蒸餾模擬器」。演化成本輪**方向二** |
| **三、Adaptive-Laundering 攻擊成本地圖** | **完全零衝擊，相對地位上升**。純機器攻防，一個真人都不需要 | 用本輪新論證加固：B 的「列舉式動作空間＝雙標」修正為「攻擊成本上界」；C 的 neural codec 資訊摧毀圖譜提供「零成本必殺動作」。演化成本輪**方向三** |
| **四、Active Liveness Probing** | **中傷後在本輪被擊沉為獨立方向**。relay 共犯語料不能自錄；且被 D 的「全程真人共犯 + VC 貼皮無切換點」反例、G 的前作、H 的後段排名三重打擊 | **降格**。E 搶救了 RQ1（OOD 挑戰對 VC 的貼皮崩壞量測），但整體降為方向三攻擊成本地圖的一個攻擊維度子模組，不再獨立成篇 |
| **五、Provenance 可達性地圖** | **CallAttest 被擊沉，索引構造收窄**。CallAttest 撞上 AuthentiCall（USENIX 2017）致命前作；perceptual hash 的「不可能三角」（C/A）；覆蓋率反累退（H） | **收斂到政策/量測**。B 全面撤回 CallAttest，把殘值（watermark bit 存活 + Article 50 審計 + 覆蓋率天花板 + soft-binding 容量判定）重鑄，部分併入方向二、部分獨立成本輪**方向五** |

**一句話總結第一輪→第二輪的地形變化**（Agent F 的觀察最準）：「受影響最小的三個方向（二、三、五）恰好是我判定表裡『救不了』『少害她』『不是為阿嬤寫的』那三個。如果大家順著『哪個最不受新規則影響』選題，這一輪的結論就會自動漂向離真實的人最遠的地方。」——本輪辯論的核心張力，就是**如何在不碰真人的前提下，仍讓「受騙率/救人」這個因變數留在桌上**。方向一是對這個張力的正面回答。

## 二、討論歷程回顧

### Round 1：八人獨立提案，五股力量浮現

八位討論者各交兩個提案，收斂出五股力量：

1. **選擇性預測 / 誠實棄權叢集**（A1、E1、F1、G2-A、H1 五案撞題）：接受偵測器在 unseen generator 上必然劣化（#2：EER 13.5–50%），改讓模型「可靠地棄權」，並用 VoiceWukong 已公佈的 300+ 人數據（人類對低品質 deepfake FAR 4–19%、高品質 >82%）做 human-proxy 模擬取代 user study。**F 在 Round 2 一眼看穿五案同源**：「A、E、G、H 加我，是同一個提案的五個變體，差異只在最後一層的宣稱形式。」
2. **真實通道存活審計叢集**（C1、G2-B、H2）：現有 robustness 研究全是離線模擬 codec，沒人把音訊灌過真實電信通道；C1 升級為「分解落差 + 蒸餾模擬器」。
3. **紅隊攻擊成本地圖**（D1、D2）：把 laundering 從「防禦者視角的隨機後處理」翻成「攻擊者視角的最佳化搜尋」，附物理可逆性下界。
4. **訊號前瞻**（C2）：neural codec 的 decoder 是生成模型，音訊過一次就「全部都是合成波形」，real/fake 定義崩解——攻防雙面。
5. **crypto/政策**（B1 索引式 soft binding + Article 50、B2 CallAttest 帶外認證）。

**Round 1 的關鍵方法論情報（Agent G 檢索）**：用「文獻校準模型」取代真人不是權宜之計——L2D 社群的合成專家已上 Nature Scientific Data 2025、FiFAR；認知模型「fit 研究 A、零參數預測研究 B」發到 UMUAI 2026；IMF WP 2025/085 用情境校準模擬做金融壓力測試。**反例是 LLM-simulated users**（arXiv 2601.17087、2605.10659 實測判為不可靠），全場一致裁定不採用（#2 的 Qwen2-Audio 對 deepfake F1=0 是現成反駁）。

### Round 2：三把關角色的系統性攻擊，兩顆致命前作魚雷

**Agent D（紅隊）的主攻命中五人**：「人類模型不確定集 𝓗 是對『自然人類變異』的全稱量化，而攻擊者的整個職業就是把受害者推到 𝓗 之外——社工把警告服從率 φ 推到負值語意（受害者主動幫攻擊者繞過），那個點不在 θ∈[0,1] 裡。robust-over-𝓗 是一張假保單。」這一刀命中 A1/E1/F1/G2-A/H1 全部五案。但 D 同時給了補救：把社工建成攻擊者可施加的算子 `A_social(c)`，量 `∂(expected cost)/∂c` 斜率，只做「下界的下界」（φ→0 殘值）。

**Agent G（史官）的兩顆前作魚雷**：
- **AuthentiCall（USENIX Security 2017）**逐條做完了 CallAttest 宣稱的全部 delta（內容認證 + 帶外低頻寬通道 + 形式化驗證 + OTT 單邊部署）——B 的 CallAttest 致命傷。
- **Codecfake（IEEE TASLP 2024，100 萬筆 + CSAM 對策）**+ source-tracing 群已佔領 codec-latent 偵測——C2 防禦面「新 domain」宣稱不成立。
- 另用五篇短句/情緒 ADD 前作收窄 F2、用「首個真實通道」被 Presentation/RTCFake 侵蝕自我修正 G2-B。

**Agent C（訊號）的通道層系統性攻擊**：「本輪多數計算性驗證方案掃了人（δ、φ、ρ）、掃了攻擊者，卻把『偵測器過通道後的 recall』當固定輸入，而那個輸入來自模擬 codec，帶著未被掃描的樂觀偏差 γ（Deepfake-Eval-2024：audio AUC 掉 48%）。通道樂觀偏差必須成為與 δ 平起平坐的掃描維度。」

**Agent B（密碼學）的紀律靶心**：「本輪最大的系統性風險是用『攻擊者最佳化』『單調性下界』『不確定集穩健』這些聽起來很密碼學的詞，替一條其實斷掉的推論鏈鍍金。」B 拆了 D 的「三種綠燈焊成一個 scalar」、A 的「重送迴路無 source binding」、C 的「codec-latent 是舊牆換座標」。B 另指出全場「對人類模型做全稱量化，對攻擊者只做列舉量化」的不對稱。

**Agent A 的技術補刀**：E 的 𝓗 只約束邊際 FAR，沒把「人機錯誤相關性 ρ」放進不確定集——而 ρ 才決定「defer 給人有沒有用」。

**Agent F（民眾）的判定公理**：「無真人實測之下，沒有任何論文能自證『救得了阿嬤』；能自證的上限是『若部署鏈存在，則此設計在全部悲觀假設下仍不越幫越忙，且優於候選方案』。」F 並重手打了自己人 F1：不該把「受騙率」放進標題。

**Agent H（教授）立三條紅線**：反冒充（primary outcome 必須誠實地叫它自己，不准把期望損害偏序叫受騙率）、反自由度（模型參數要嘛有真人數據錨、要嘛全區間掃描 + dominance，不得用 LLM 模擬受試者）、反滑坡到無關（不做真人不是躲回純技術指標的藉口）。並加立「真實情境影響力」為第六評分欄。

### Round 3：大規模合流與誠實的自我降級

Round 3 是本輪最誠實的一輪，關鍵動作是**幾乎所有人主動降級自己的提案並合流**：

- **Agent B 舉更深的白旗**：「CallAttest 被全場從前作、訊號物理、形式化定義域、覆蓋率、社會累退性五個方向同時擊沉，我全部接受。」正式撤回 CallAttest，把殘骸（D 與 F 共同認證的「覆蓋率天花板」）重鑄成政策模組，併入真實通道審計群。
- **Agent C 接受提案二防禦面判死**：「codec-latent 偵測就是把舊牆換座標的自我欺騙，全場替我照出來了。」只保留攻擊面（可逆性邊界判定）併回提案一。
- **Agent A 對「重送干預」全面投降**：五人（H/E/B/F/D）從五個角度指出它是「攻擊者的 laundering oracle」，A 把它從部署防線降為「評估探針」。
- **Agent D 撤回兩個提案的獨立性**：「紅隊對自己不狠，就沒資格對別人狠。」D1 改輸出「攻擊成本上界」（接受 B 的雙標指控），D2 下界只保留相對陳述（baseline 永遠留白，接受 A 的「偷換」指控），兩者降為方向一的對抗評估層。
- **Agent E 把重砲變成窗戶**：把「𝓗 錨在品質軸、推論不到壓力軸」的致命攻擊，轉化為「適用域分治」——Regime I（品質主導：上班族/選民）做正向偏序，Regime II（壓力主導：阿嬤）只做結構性殘值下界，**兩者之間的邊界 θ\* 本身成為論文的中心產出**。
- **Agent F 認賠標題與 F1 獨立地位**，換來「人以四個掃描維度、一張情境格、一個聽力濾波器、一份負領土地圖、一張三秒考卷的形式，留在每一條管線裡」。
- **Agent G、H 主動讓出 lead**：兩人都把自己的提案併入合流版，G 認領「前作防雷 + 方法論判例牆 + venue 策略」，H 認領「三條紅線 + 對稱重放設計把關」。

**三個把關角色（D 紅隊、F 民眾、H 教授）的最終共識：**

| 方向 | D（紅隊）判定 | F（民眾）阿嬤那行判定 | H（教授）判定 |
|------|------|------|------|
| 一、誠實棄權穩健排序 | **推薦一**（「唯一不給攻擊者背書的防禦……它沒有在擋不住的地方發出確定的綠燈」） | 上班族「可以」、阿嬤「有條件」（唯一有「可以」的方向） | **co-首選**（建模型學生） |
| 二、真實通道審計 | **推薦二**（「我的攻擊武器庫 + Article 50 政策否證」） | 有條件（上游證據基礎、監理桌面唯一實測審計） | **co-首選**（工程型學生） |
| 三、攻擊成本地圖 | 主提案降為對抗評估層（「照妖鏡、品管關，不是防線」） | 少害她（品管關） | 次要（嵌進方向一當對抗層，不當主軸） |
| 四、詐騙現場考卷（F2） | 支持並要求灌進通道 rig | 間接（考卷不是防線，但所有方向以它為前提） | **暗馬**（撞題最少、生態效度獨佔） |
| 五、Provenance/政策 | 覆蓋率天花板是「政策級發現」 | 救不了阿嬤、服務上班族/選民/查核 | 不推薦為主軸（真實情境影響力墊底） |

三個把關角色最強的共識：**方向一是全場唯一「把因變數朝那個接電話的人延伸、且不依賴任何未兌現長期賭注（憑證普及、延遲軟肋、平台配合）」的方向**，且它被 A、D、E、F、H 五個角色在最終推薦中列為推薦一或 co-首選。而**方向二是全場唯一「不需要辯護『你的模擬可不可信』」的實測地基**，被 C、G 列為首推。這兩個方向被 Agent C/G/H 用「γ 掃描維度」硬耦合成一條證據鏈的量測端與消費端。

## 三、五個論文方向（依推薦順序）

> 五個方向全部完全不含真人實測。方向一、二為 co-首選（依學生特質分流）；方向三、四、五為可獨立成篇、亦可作為方向一/二的模組。

---

### 方向一（首選）：分布與社工雙重偏移下的誠實棄權決策框架

**1. 暫定題目**
中：《不賭人是什麼樣——分布與社工雙重偏移下語音深偽偵測的校準棄權 benchmark、confident-real 對抗評估與適用域分治穩健排序》
英：*Robust Abstention Decisions for Audio Deepfake Detection under Distribution and Social-Engineering Shift: A Calibrated Selective-Prediction Benchmark, Confident-Real Adversarial Evaluation, and Regime-Partitioned Ordering*

**2. 核心研究問題**
給定一個在 unseen generator 上必然劣化（#2：EER 13.5–50%）的偵測器，如何讓它在不可靠時「可靠地棄權」而非「自信地錯」，並在完全不做 user study 的前提下，用文獻校準的人類模型族證明「哪種棄權/警告 policy 較優」，同時把攻擊者對人的社工操縱納入計算框架？

**3. 創新點與對應的 research gap**
- 對應 survey Gap 地圖第 1 點（被動偵測的極限）與 #8「可信的使用者體驗為優先方向卻無人做」。經 Agent G 兩輪檢索復查，「shift-aware selective-prediction ADD benchmark」收編 FADEL（evidential DL，ICASSP 2025）為 baseline 後**仍無前作**。
- 五個獨有貢獻：(a) 第一個 shift-aware 選擇性預測 ADD benchmark（六種棄權機制 × 四格 shift 的 risk-coverage 與 ECE）；(b) Agent A 的 **density-vs-discriminative failure-mode 假說**——在 AUC≈0.5 failure mode 下，只建模 bona fide 的 density-based 分數與依賴 fake 端邊界的 discriminative-derived 分數（含 evidential）是否分道揚鑣，這是五年 one-class 賽道沒人問過的問題；(c) Agent D 逼出的 **confident-real 對抗評估軸** `max P(confident-real|fake)` 首次形式化 + Agent B 的**無綠燈原則 formal invariant**（「輸出狀態空間中不存在對 fake 輸出正向信任訊號的狀態」）；(d) Agent E 的**適用域分治穩健排序**——把 robust decision making / 對抗者類別全稱量化引進 ADD usable security（G 認證「本輪最好的 novelty 論證，不隨生成器版本過期」）；(e) 第一個把「攻擊者對人類模型的社工操縱」以 Agent D 的 `A_social(c)` 算子納入計算框架（G3-S1 先例：arXiv 2509.21436、2602.04003）。

**4. 攻防紀錄摘要**
- **被 D 主攻後反而變強**：D 的「robust-over-𝓗 是假保單」命中五案，但 D 自己給了補救（`A_social(c)` 算子）。E 在 Round 3 把這一擊轉化為「適用域分治」的中心產出——「當重砲打進你的房間，開創性是證明那些彈孔其實是窗戶」。
- **A 對 E 補刀、也約束自己**：ρ（人機錯誤相關性）必須進不確定集，且 G 查證 VoiceWukong per-sample 數據公開可得（Zenodo），使 ρ 從「全靠掃描」升級為「部分可估」。
- **C 的 γ 硬約束**：dominance 排序必須在 δ（壓力）× φ（服從率）× ρ × **γ（通道樂觀偏差）** 四維全區間不翻轉才可宣稱，γ 上界消費方向二的實測落差。
- **F 的四條驗收標準**：claim 紀律（悲觀端掃到底）、考卷真實性（接方向四素材）、負領土地圖（印出「阿嬤×高壓那格誰都別部署」）、可證偽交棒（pilot 可推翻的數值預測）。
- **H 的三條紅線 + 措辭**：primary outcome 絕不叫「受騙率」；守得住的措辭是「在所有與 VoiceWukong 數據一致的人類代理模型下，policy A 期望損害不高於 B；此排序在四維掃描區間內不翻轉；翻轉區標為『需 pilot 裁決區』」。
- **D 的最終背書**（紅隊罕見推薦防禦）：「這是全場唯一一個對我的零成本繞過輸出的不是虛假安全感的方向……它沒有在擋不住的地方發綠燈，我就沒有背書可偷。」

**5. 實驗規劃（全部計算性）**
- **資料集**：ASVspoof 2019/2021 LA+DF、In-the-Wild、MLAAD（皆可下載）；VoiceWukong 可得部分 + per-sample 人類數據（Zenodo 學術申請制，月 0 送件）；unseen-channel 軸用 **RTCFake（HuggingFace 現成真實通道測試集）** + 方向二實測落差；閉源商用樣本用 ElevenLabs 等 API 小規模自建（純 API 呼叫，無人類受試）；輸入素材接**方向四的詐騙現場條件素材**（短句 × 情緒 × 繁中話術）。
- **Baseline**：AASIST、wav2vec2-XLS-R backend、RawNet2 三套現成偵測器；棄權 baseline = MSP、temperature scaling、deep ensemble、MC-dropout、energy score、Mahalanobis-on-SSL、**FADEL evidential（第 7 種）**。
- **方法步驟**：(i) 建 2×3 shift 矩陣 {in-domain, unseen-generator} × {乾淨, 可逆通道(CELP+RTCFake), 不可逆通道(neural codec transcode)}，量 baseline ECE / reliability diagram / risk-coverage，輸出負領土地圖——**此階段即保底半篇 benchmark，零 IRB 依賴**；(ii) 七種棄權機制對決，驗證 density-vs-discriminative failure-mode 假說（距離量測在投影掉 speaker-identity 後的自然性殘差子空間）；(iii) confident-real 對抗評估，攻擊動作空間 = 列舉式 laundering（neural codec transcode 為起點）∪ 白盒 adaptive 攻擊 ∪ 序列式 oracle 攻擊，量各棄權機制「進入 confident-real 區的最低成本上界」與功能性代價拐點（speaker similarity / WER）；(iv) human-proxy 模擬翻譯層——**適用域分治**：Regime I（品質主導）做四維 dominance 偏序、Regime II（壓力主導）只做 `A_social(c)` 的 φ→0 結構性殘值下界、輸出 **θ\* 邊界 + value-of-information 分析**；(v) 年齡聽力濾波器（以年齡別聽力常模把「68 歲的耳朵聽到的音訊」做成純計算訊號變換；ISO 常模編號待查證）。
- **評估指標（全場公約）**：固定 FPR ≤1% 下的 recall-coverage、shift 下 ECE、risk-coverage、`max P(confident-real|fake)` 攻擊成本上界、多 base rate expected cost、Regime I 的 dominance 偏序、Regime II 的殘值下界。**禁用裸 EER 為主指標。**
- **消融**：棄權訊號種類 × shift 類型的交互；density vs discriminative 在 AUC≈0.5 格的命運分岔；棄權措辭（硬警示 vs 軟措辭）作為攻擊面；ρ、θ、φ、γ 各維度對排序穩健性的邊際貢獻。

**6. 計算性驗證如何令人信服地推論到真實情境（回應 F 的把關）**
- **主承載宣稱是 D 的單調下界**（「綠燈受騙率 ≥ 自由符號 p₀，綠燈單調抬高 Δ」），唯一假設「綠燈不讓人更警覺」與品質/壓力/素材都無關——這使 primary claim 對「推論不到詐騙現場」這一擊**結構性免疫**。p₀ 永遠留白，絕不代入辨識 FAR（避開 A 指出的偷換）。
- **品質軸模擬明確定位為輔助層**，結論一律 dominance 形式（對 human model 點誤差 robust），且錨定於 300+ 人實測分布 + L2D/認知模型判例牆（Nature Sci Data 2025、UMUAI 2026、IMF WP 2025/085），不用 LLM 模擬受試者。
- **不做因果宣稱**（迴避《The Illusion of Intervention》arXiv 2605.20767）；產出是「通過計算篩選的最優 policy 候選 + 可證偽 pilot 預測」，明列為後續 IRB 研究假設。
- **F 的定位（寫進第一頁）**：本框架量的是「攻擊確實走進偵測器管道、且為單次接觸」情境下的期望損害排序，不是總受騙率；threat displacement 與多回合信任建立在框架外；阿嬤那格只自證「若部署鏈存在則不越幫越忙」，不自證「救得了」。

**7. 一年時程表**
- 月 0：送 Zenodo VoiceWukong per-sample 存取申請（時程殺手，提前拆）。
- 月 1–4（第一季）：復現三偵測器 + 建 2×3 shift 矩陣 + baseline calibration/risk-coverage + 負領土地圖——**保底半篇 benchmark，不依賴任何申請**。
- 月 5–7（第二季）：七種棄權機制對決 + density-vs-discriminative failure-mode 假說驗證。
- 月 8–10（第三季）：confident-real 對抗評估（含 neural codec transcode 起點動作、無綠燈 formal invariant 靶）+ 失效歸因診斷章（channel vs generator 可分性地圖，重送降為評估探針）。
- 月 10–12（第四季）：human-proxy 適用域分治模擬 + θ\* 邊界 + 四維敏感度掃描 + 寫作。

**8. 真實情境部署路徑與社會福祉貢獻**
主場景為 LINE 語音訊息詐騙（上班族情境，F 判定表唯一的「可以」）與消費端防詐 App。產出「偵測器需多低 FPR、警告需怎麼下、alarm budget 多少」的部署操作點準則表——F 的關鍵洞察：「部署方（平台、銀行）不缺 A/B test 能力，缺的是值得開一次 pilot 的門檻證據；這本論文要做的是把『開 pilot 的提案』武裝到牙齒。」核心社會福祉貢獻是**無綠燈原則**（系統只有「警示」與「沉默」兩態，沉默不是背書）防止偵測器製造新的虛假安全感——這是全場唯一直接對抗問題陳述「侵蝕信任」的機制。發表：主體投 INTERSPEECH/ICASSP，confident-real 對抗軸拆 security workshop（**絕不往 SOUPS/USENIX 送模擬受騙率**，G/H 一致）。

**9. 風險與備案**
最大風險：所有棄權訊號在 AUC≈0.5 failure mode 下全數失效（含 A 的 real-manifold 距離）。備案：論文轉向「嚴謹量化此失效 + calibration benchmark + confident-real 攻擊面 taxonomy」——參照 VoiceWukong 先例，高品質負面結果可發表，且月 1–4 的 benchmark 已保底半篇。次要風險：Regime I 的排序全平手（𝓗 太寬）。備案：那本身是「公開數據不足以支持任何設計選擇」的政策級否證 + value-of-information 採購清單；並用 #2 人機互補結構保證至少一對 policy 在整個 Regime I 穩健可排（H 要求的保底非平庸排序）。誠實邊界：對「攻擊者叫受害者忽略警告」的社工接管無直接防禦（在 𝓗 之外），防禦鏈最後一環是機構端部署。

### 方向二（co-首選）：真實電信通道多防線存活審計

**1. 暫定題目**
中：《電信網是最後一哩——真實蜂巢電信通道上偵測、浮水印與溯源訊號存活的多防線審計、模擬樂觀偏差分解與通道模擬器蒸餾》
英：*The Last Mile is Cellular: A Multi-Defense Audit of Detection, Watermarking, and Provenance Survival over Real Telecom Channels, with Optimism-Bias Decomposition and Channel-Simulator Distillation*

**2. 核心研究問題**
現有 audio deepfake 通道 robustness 研究全部建立在離線模擬 codec 上（#3）；模擬相對真實電信/平台通道的「樂觀偏差」有多大、**來自哪一層**？各防線（偵測器、浮水印、C2PA 溯源）在真實案發通道上的「不可達區」邊界在哪？EU AI Act Article 50 強制的 machine-readable 標記，在詐騙實際發生的通道上到底可不可讀？

**3. 創新點與對應的 research gap**
- 對應 Gap 地圖第 1 點殘留 gap。Agent G 兩輪檢索**親手推翻自己第一輪的認證**：「首個真實通道」被 arXiv 2509.26471（Presentation，Delgado＝ASVspoof 組織者）與 RTCFake（IP-RTC 平台通道）侵蝕。重錨後經復查**仍成立的四個子空白**：(i) 公開蜂巢電信網通道資料集（VoLTE AMR-WB/EVS、跨電信商、PSTN interop，前作全在 IP 網/lab presentation）；(ii) **watermark/provenance bit-level 電信存活【零前作，護城河】**（AudioMarkBench 只做模擬擾動、通道前作完全沒碰 watermark、產業無動機自審）；(iii) Article 50 可讀性審計（2026-08-02 生效，零前作，若 bit 全滅即政策級否證）；(iv) 繁中/165 情境。
- 科學靈魂（C1 貢獻，回答 H 紅線「靈魂須是揭露樂觀偏差、不是收資料」）：不只量落差，用受控消融**指認樂觀來自哪一層**——實網 burst 丟包（非 i.i.d.）、jitter buffer、端點 always-on DSP（AGC/降噪/回聲消除，這些在所有離線模擬中集體缺席）——再封裝成校準過的**開源通道模擬器**，讓後續研究免架 rig。

**4. 攻防紀錄摘要**
- **H 的質疑通行證**：主 claim 必須是「量化並分解模擬樂觀偏差」，不是「我收了很多資料」。C1 的「落差分解 + 模擬器蒸餾」被 G/H/D/F 一致認為比「量落差」高一個科學層級。
- **法律路徑**（G 的 T2 查證）：通保法 §29 第 3 款，rig 兩端皆研究團隊自有設備、播放公開語料，走全場最安全路徑。
- **H 的對稱重放設計把關**：砍掉「團隊錄音」改公開語料重放會注入重放 artifact 污染 real 類；修正為 real/fake 走完全相同重放路徑（artifact 成共有常數項）、主 claim 為差分量、另設 C0' 重放對照臂。
- **D 的素材洞**：bona fide 全用朗讀語料量到的是「朗讀句過電話」不是「詐騙過電話」，要求灌進**方向四的詐騙現場條件素材**（雙贏，也讓 γ 上界是「詐騙過電話」的 γ）。
- **B 認領兩個模組**：watermark/provenance bit 存活軸 + Article 50 審計 + soft-binding 容量判定（見方向五）。
- **時間窗警報**（G）：Delgado 團隊與產業已進場，「再放一年就沒了」，MVP 必須前置到月 6。

**5. 實驗規劃（全部計算性、原生無真人）**
- **資料集**：自建。bona fide 全用公開資料集（ASVspoof/In-the-Wild/MLAAD real 類 + 公開繁中語料）+ TTS 生成 fake（3–5 家含閉源 API）+ **方向四詐騙現場素材**；連知情同意都不需要。通道矩陣按真實詐騙分佈加權：VoLTE（AMR-WB/EVS）≥ LINE 語音訊息 > LINE 通話 > Messenger > 社群轉檔；納入「LINE 文字鋪陳→轉電話收割」混合通道；每通記錄協商 codec、實測 PLR/jitter。
- **Baseline**：#3 模擬通道訓練的公開模型（AASIST、wav2vec2 系）；比較對象是文獻方法而非商用系統（避開混淆變因）。採 RTCFake 的 offline/online 精確配對方法論（站在前作肩上）。
- **三軸量測**：(1) 偵測器劣化——真實 vs 模擬的 fixed-FPR recall 落差（三層階梯：模擬→RTC 平台→蜂巢電信網）；(2) cue 存活圖譜——SSL layer × channel 的 probing AUC 熱圖 + **可控植入實驗**（植入已知參數 artifact 過通道量恢復率，給 bit 存活一個 ground-truth 錨，避免不可靠的高維互資訊估計），檢驗「相位先死、高頻次之、韻律最韌」層級假說 + **傳統 CELP（可逆分佈偏移）vs 神經 codec（不可逆 many-to-one 投影）的可逆性邊界判定**；(3) **watermark/provenance bit-level 存活**（AudioSeal/SynthID 的 I(embedded;recovered) 掃描 + C2PA manifest 容器存活，回答 Article 50）。
- **評估指標**：fixed FPR ≤1% recall、模擬 vs 真實落差係數（= 方向一的 γ 上界）、bit-level 存活率、可逆/不可逆邊界。
- **落差分解與模擬器蒸餾**：逐項把 burst 丟包模型、jitter buffer、AGC、降噪、實測 codec 模式序列加回模擬管線，量落差收斂曲線；封裝為開源模擬器，用 held-out 真通道以雙指標（偵測器性能差 + 特徵空間分佈距離）驗證保真度。
- **消融**：channel-conditioned detection vs #3 已知分佈 DA vs #2 證明有害的 multi-domain training；unseen-generator × unseen-channel 雙軸交叉。

**6. 計算性驗證如何令人信服地推論到真實情境**
本方向**原生就是全計算性的，不存在被抽走的驗證環節**——通道與訊號存活是資訊物理事實，Agent D：「真人在這裡是噪音源不是訊號源。」結論可信的關鍵在混淆變因控制：固定 UE、標註協商參數、offline/online 精確配對、對稱重放分離 artifact。它是**全場所有模擬式提案（方向一的 γ、B 的容量預算、D 的成本地圖）的共同地基與誠實度校準器**——F 判定它在「純計算驗證能否說服採用方」一欄拿全場最高：「實測審計是唯一能直接放上監理機關桌面的證據形式。」

**7. 一年時程表**
- 月 0：法律意見（通保法 §29）+ 工具鏈復現 + 與 RTCFake/Presentation 協定對齊（確保三層階梯可比）。
- 月 1：rig 定案（兩台自有 SIP/手機端點 + 自動撥放錄音 + 記錄協商 codec/PLR/jitter）。
- 月 2–6：**MVP 通道錄製（單電信商 VoLTE + LINE 語音訊息兩型態）→ 保底可發表單元**；雙素材臂（公開朗讀 + 方向四詐騙素材）；同步跑離線模擬配對對照；C0' 重放對照臂。
- 月 6–9：三軸量測（偵測器落差 + cue 存活/可逆性 + watermark bit 存活）+ stretch 通道。
- 月 9–11：落差分解 + 開源模擬器蒸餾 + held-out 驗證。
- 月 11–12：資料集/模擬器開源 + Article 50 審計章 + 寫作。

**8. 真實情境部署路徑與社會福祉貢獻**
不直接擋詐騙，而是決定「電信端/平台端該部署什麼、165 該信什麼」的上游證據基礎（F：「阿嬤那一行所有上游決策的證據基礎」）。獨立公開審計填補「產業系統全閉源、零第三方評測」的消費者知情權空白。繁中/台灣 165 情境的第一份公開資源。watermark 存活軸的負面結果（若全滅）即對 EU AI Act Article 50「machine-readable 標記」政策路線的政策級否證——法規要求的標記在詐騙實際通道上不可讀，有政策發表價值。開源模擬器讓整個社群免架 rig 就能逼近真通道評估。

**9. 風險與備案**
最大風險：真實通道錄製的工程工時與時間窗（Delgado 團隊 + 產業已進場）。備案：MVP 分階段設計，月 6 前完成單電信商兩通道即為保底可發表單元；stretch 全砍仍是首個蜂巢電信網公開資料集 + watermark 存活軸（零前作護城河，產業無動機自審）。若落差測出「模擬其實夠好」（H0），也是替社群省下真實收集成本的可發表否證。平台 ToS（LINE/Messenger 自動化收發）殘留灰色地帶，緩解為控制速率、半自動人工操作。

### 方向三：Adaptive-Laundering 攻擊成本地圖 × 物理可逆性 × 神經 codec 資訊摧毀

**1. 暫定題目**
中：《攻擊者付的絕不超過多少——被動偵測、溯源與活體三類防線的 Adaptive-Laundering 攻擊成本上界地圖與物理可逆性下界》
英：*What Does the Attacker Pay at Most? An Adversarial-Laundering Attacker-Cost Upper-Bound Map across Passive Detection, Provenance, and Liveness, with Physical-Reversibility Lower Bounds*

**2. 核心研究問題**
對每個候選防線，不問「平均 robustness」，而問攻擊者視角：讓它跌破可用門檻，**已知動作空間內最便宜的路徑**是什麼（攻擊成本上界）？哪些步驟踩到「不可逆資訊摧毀」的物理下界（做了永久失效）？曲線是「懸崖」（防守方有戲）還是「緩坡」（防守方在裸奔）？

**3. 創新點與對應的 research gap**
- 對應 Gap 地圖第 1、2 點。現有 benchmark（#2 的 38 變體、#3 的 C0–C5）把 laundering 當「防禦者視角的隨機後處理」；本方向把它形式化為**攻擊者最佳化的 adversarial laundering search**——「攻擊成本」這個評估軸在 audio ADD 文獻中不存在（H 確認）。
- Agent B 逼出的關鍵修正（避免 legacy 的「原樣重提」）：輸出從「攻擊成本點估計」改為「**攻擊成本上界**」（已知動作空間內最便宜繞過，真實成本 ≤ 此值，動作空間開放可擴充）——這回應了 B 的「列舉式動作空間＝紅隊雙標」指控，讓評估協定邏輯上乾淨。
- Agent C 的物理可逆性下界是**不可爭議的錨**（資訊理論事實、不隨月份過期）：主觀成本代理只作輔助排序，骨幹是「相位 cue 過 CELP 重合成的互資訊 I(cue;輸出) 掉多少」。**neural codec 資訊摧毀圖譜**（C2 攻擊面殘值，G 確認 Codecfake 前作後收窄為「傳統 CELP 可逆分佈偏移 vs 神經 codec 不可逆 many-to-one 投影的可逆性邊界判定」）給地圖一個「一行 ffmpeg、零金錢、物理不可逆」的零成本必殺動作。

**4. 攻防紀錄摘要**
- **E 的「成本會過期」批評**被 D/C 反駁：「過期的是主觀數字，上界方向性與物理下界不過期。」
- **B 的雙標指控**（D1/D2 用列舉式動作空間）被 D 完全接受，修正為「攻擊成本上界」框架。
- **它與方向一深度耦合**：D1/D2 在 Round 3 主動降級為方向一的對抗評估層（第二/三環證據鏈）——方向一做正向排序（救人），D1/D2 做對抗驗證（證明棄權機制不被零成本繞過、不製造新虛假安全感）。H：「這是它比其他方向更適合作為對抗層的原因，但驗證嚴謹與救到人是兩個正交軸，不扶正為主軸。」

**5. 實驗規劃（全部計算性）**
- **資料集**：現成生成器（開源 + 閉源 API）+ 現成 codec/VC 工具（EnCodec/DAC/SpeechTokenizer + AMR-WB/EVS/Opus）+ 現成 SOTA 偵測器 checkpoint；不訓練任何大模型。可接方向二的真實通道武器庫。
- **Baseline**：#2 的「平均劣化」量測（對照，證明「攻擊者最佳化的最壞情況」比平均嚴重）。
- **方法步驟**：(i) 定義攻擊者動作空間（換 generator、re-synthesis laundering、codec tandem、**neural codec transcode 為起點**、平台真實轉檔、loopback re-injection、resample/time-stretch/replay、metadata washing），每個動作標成本代理 + C 的物理可逆性二元標註；(ii) 對 3–5 個公開偵測器（含方向一的 selective-prediction 偵測器、A 的 real-manifold 殘差距離棄權訊號）跑貪婪/beam search 找最便宜繞過**上界**；(iii) 三類防線維度——被動偵測（對 A 的距離型棄權訊號畫懸崖/緩坡曲線）、provenance（metadata washing 存活率，攻擊面 taxonomy 而非單一 scalar；構造由方向五做，此處只做攻擊評估）、liveness（E2 的 OOD 挑戰 × relay 成本 + 即時共犯排程約束）；(iv) 可控植入實驗做物理不可逆性下界正式標註。

- **消融**：哪些防禦設計選擇讓曲線變陡（反向產出：C「依賴第三層存活特徵的偵測器攻擊成本曲線最陡，因為攻擊者要洗掉它就得破壞『聽得像目標語者』的功能性約束」）；成本代理定義的敏感度分析。

**6. 計算性驗證如何令人信服地推論到真實情境**
Agent D：「紅隊評估是本問題陳述裡少數『無真人版本嚴格強於有真人版本』的題型——攻擊成本地圖的因變數是偵測器在對抗 laundering 下的失效，這本來就是機器事實，真人在這裡沒有位置、只會引入受試者變異噪音。」不可爭議的錨是物理可逆性下界（資訊理論事實，可計算、可複現、不需人、不過期）。輸出改為「上界」後方向性單調安全：一個防禦連已知動作的最便宜路徑都擋不住，就是確定被繞過的。

**7. 一年時程表**

- 月 4–7：對被動偵測維度跑 beam search、畫攻擊成本上界曲線（含對 A 的距離型棄權訊號的懸崖/緩坡）。
- 月 8–10：provenance 與 liveness 維度 + 真實通道武器庫（接方向二）。
- 月 11–12：跨三類防線的 attacker-cost map 整合、寫作。

**8. 真實情境部署路徑與社會福祉貢獻**
給部署方（銀行、電信、165）的「照妖鏡」：阻止機構部署「EER 0.06% 但一次 neural codec transcode 就崩到 40%」的偵測器（D：「虛假的安全感比沒有防禦更危險」）。F 判定：對阿嬤是「少害她」而非「救她」——它是其他所有「宣稱能保護民眾」方案的共同品管關與驗收標準，也是方向一驗收「棄權不被繞過」的必要對抗評估層。一個可重複、可擴充的紅隊評估協定，成為後續防禦研究的標準壓力測試。

**9. 風險與備案**
最大風險：成本代理指標的可辯護性（reviewer 必攻「如何把金錢/技術/時間量成可比 scalar」）。備案：以 C 的物理可逆性（資訊理論事實）作為不可爭議的錨，主觀成本代理只作輔助排序；輸出「上界」而非點估計，方向性單調安全。若某防線測不出清晰懸崖，「緩坡」本身也是可發表結論（且是對部署方的直接警告）。作為獨立碩論的風險：純評估型貢獻答辯時「你的正面貢獻是什麼」可能難堪——備案是強調 C 的物理可逆性下界是正面設計指導，或直接作為方向一的對抗評估層而非獨立主軸。

### 方向四：詐騙現場條件評估效度審計（繁中）

**1. 暫定題目**
中：《到達耳朵的那三秒——以公開詐騙話術重建現場條件（話術語意 × 短句長 × 情緒韻律 × 通道）的語音深偽偵測評估效度審計》
英：*The Three Seconds That Reach the Ear: Auditing Audio Deepfake Detection Validity under Scam-Scene Conditions (Scam-Script Semantics × Short Utterance × Emotional Prosody × Channel)*

**2. 核心研究問題**
現行 ADD 評估的素材（長句、朗讀式、中性韻律、錄音棚出身）與詐騙現場實際到達受害者耳朵的音訊（3–5 秒、哭腔/急迫命令、詐騙話術文本、通訊通道）之間存在系統性錯配。這四個軸的**交互落差**有多大？現行 benchmark 對詐騙場景系統性樂觀多少？

**3. 創新點與對應的 research gap**
- 對應 Gap 地圖第 1 點殘留 gap。Agent G 查證出五篇單軸前作（短句：AASIST2 short utterance arXiv 2309.08279、《First Greeting "Hi!"》arXiv 2601.19573、Fake-Mamba arXiv 2508.09294 報告 <3 秒 EER 9.44%；情緒：HuLA arXiv 2509.21676、Phoneme-Level across Emotional Conditions arXiv 2605.03079），故 novelty 從「第三個樂觀偏差軸」**收窄為**：(a) **詐騙話術的語言內容作為變因**（前作全用朗讀/通用文本，沒人把「話術語意/語用是否讓 TTS 露餡」當自變數）；(b) **四軸交互**（前作全是單軸，交互項無人量過）；(c) **繁中/台灣情境雙重真空**。
- F 的關鍵洞察：「這五篇前作是 F2 的除險器，不是墓碑——它們各自證明了單軸主效應存在，我的實驗風險從『效應存不存在』降為『交互項多大』，一個碩士生做『前作已保證主效應、只剩交互項待量』的題目，比做『主效應都還是猜測』的題目安全一整級。」

**4. 攻防紀錄摘要**
- **H 的暗馬定位**：「全場撞題最少、天然免疫無真人爭議、直接補 #2（生成器軸）、#3（通道軸）、方向二（真實通道軸）都沒碰的正交空白（素材生態效度）。」

- **F 的不可讓渡條件**：F2 必須是「全場的共用考卷」而非「孤立資料集」——素材必須同時接進方向一的模擬鏈輸入層 + 方向二的通道 rig。若被排成孤立 dataset paper，F 撤回支持。

**5. 實驗規劃（全部計算性，天然無真人）**
- **資料集**：165 公開話術腳本（公開資料，無 IRB）去識別化改寫 → 3–5 家開源 + 閉源 TTS/VC 生成 → 情緒分層（中性/哭腔/急迫）× 句長分層（3s/5s/10s+）→ 疊加通道（#3 模擬管線或接方向二真實通道）。每樣本標註機器算的品質協變量（speaker similarity + UTMOS 類 MOS 代理，非人工聽測）確保比較是品質配對的。

- **方法步驟**：(i) feasibility spike——閉源 TTS 對話術文本的 guardrail 實測、情緒可控 TTS 選型、負責任發布協定；(ii) 主實驗——四象限（標準素材 vs 現場素材 × 乾淨 vs 通道後）的 fixed-FPR recall 落差矩陣；(iii) 歸因消融——話術語意、句長、情緒、通道四因子的獨立與交互效應，情緒效應與生成品質協變量解耦。
- **評估指標**：fixed FPR ≤1% recall 落差、四因子交互效應量、品質配對後的淨落差。
- **消融**：話術語意 vs 中性文本的落差差、短句 × 情緒的交互、通道對交互效應的調節。

**6. 計算性驗證如何令人信服地推論到真實情境**
F：「user study 被禁之後，『素材像不像真實現場』就是我們離真實情境最近的、完全計算性的抓手——與其量『人在現場的反應』（做不了），先保證『機器被測在現場的條件』（做得了）。這是 ecological validity（生態效度）。」本方向 claim 的是機器指標在現場條件下的落差，人類從頭到尾不出現；但它回答的是「評估效度」這個人的問題。品質協變量控制回答「這是偵測器爛還是生成器爛」的混淆質疑；四因子消融回答「落差來自哪裡」；全部可重跑、可審計。

**7. 一年時程表**
- 月 0–1：feasibility spike（閉源 TTS guardrail、情緒 TTS 選型、負責任發布協定）。
- 月 1–4：語料構建（165 腳本 × 生成器 × 情緒 × 句長，標註品質協變量）。
- 月 4–7：主實驗（四象限 fixed-FPR recall 落差矩陣）。
- 月 7–9：四因子歸因消融 + 情緒/品質解耦。
- 月 9–12：與方向一模擬鏈 / 方向二真實通道 rig 對接、負責任發布、寫作。

**8. 真實情境部署路徑與社會福祉貢獻**
第一個詐騙現場條件（話術 × 韻律 × 句長 × 通道）的 ADD 測試集，繁中/台灣情境第一份素材級公開資源（負責任發布）。「素材真實性樂觀偏差」的量化——若落差大，是對整個領域評估慣例的效度警告；若落差小（H0），也是「現行 benchmark 對詐騙場景夠代表」的可發表否證，替社群省掉一個焦慮。F：「以後任何廠商宣稱『我的偵測器能防詐』，都必須先過這份『到達耳朵的那三秒』的考卷，而不是拿十秒朗讀句的成績單來唬人。」它是方向一模擬與方向二 benchmark 的共用考卷（基礎設施級複用）。

**9. 風險與備案**
最大風險：閉源 TTS 對詐騙話術文本的 guardrail 可能拒絕生成（月 0 feasibility spike 為 go/no-go）。備案：話術腳本去識別化改寫（guardrail 主要在 voice cloning 而非文本朗讀）。次要風險：情緒 TTS 品質參差成為混淆變因——以品質協變量配對控制。發布風險：詐騙語音語料庫可能武裝攻擊者——需負責任發布協定（守門下載、只發 checksum 與生成配方、AudioMarkBench 等有前例）。作為獨立題目的風險：純 benchmark 貢獻份量——備案是綁定方向一/二成為其素材層，或強調四軸交互 × 繁中話術的獨佔 novelty。

### 方向五（較高風險，crypto/政策角度）：Provenance 可達性地圖 + Article 50 可讀性審計 + 覆蓋率天花板

**1. 暫定題目**
中：《Provenance 到得了哪裡——真實通道多層訊號存活、索引式 soft binding 容量判定、EU AI Act Article 50 可讀性審計與即時詐騙覆蓋率天花板》
英：*How Far Does Provenance Reach? Multi-Layer Signal Survival, Index-Based Soft-Binding Capacity, an EU AI Act Article 50 Readability Audit, and a Coverage Ceiling for Real-Time Voice Scams*

**2. 核心研究問題**
量出 provenance 與 watermark 在真實通訊管線上「活到哪裡、死在哪裡」的邊界；給出一個能在邊界內工作的低容量密碼學構造（索引不 payload）並判定其容量生死；EU AI Act Article 50 強制的 machine-readable 標記在詐騙實際發生的通道上到底可不可讀；**provenance/認證這整條技術路線在真實詐騙生態裡的覆蓋率天花板是多少？**

**3. 創新點與對應的 research gap**
- 對應 Gap 地圖第 2、3 點。C2PA 規格（#4）明載 soft binding 為 manifest 復原機制但未給 audio 構造；#7 證明 watermark 與 manifest 若不互綁會被去同步；#6 列出 C2PA 五大缺陷。
- 三個經本輪淬煉後的貢獻：(a) **索引不 payload 構造**——波形內只承載 k-bit transparency-log 索引 + ECC，繞開「電話通道可靠 payload 逼近 0 bit」死結；C 的容量判定（傳統 CELP 無丟包 ~十幾到數十 bit，加 PLR 掉到個位數，**neural codec 通道逼近 0——構造的不可達區**）使 k 的生死取決於方向二的實測數字，不再是猜測；(b) **Article 50 可讀性審計**（2026-08-02 生效，零前作，若電話級通道全滅即政策級否證）；(c) **覆蓋率天花板地圖**（Agent D 與 F 共同認證的 CallAttest 唯一誠實殘值）——用 165/刑事局公開詐騙類型分佈 ×各類受害者的驗證端滲透率，算出「provenance 就算完美，最多能碰到多少百分比受害者」，D：「那個數字本身就是政策級發現」，B 猜（待 165 統計確認）遠低於一半。
- **本輪的重大自我修正**：Agent B 全面撤回 CallAttest——G 的 AuthentiCall（USENIX 2017）逐條做完其 delta 是致命傷；C/A 的 perceptual hash「不可能三角」（codec-robust 與內容綁定粒度在電話通道上帕累托互斥）；H 的反累退（provenance 優先保護已武裝的人）。**索引式構造服務的是「真話自證」（真實錄音在流通後仍可驗證），不是「假話攔截」**——這是誠實的定義域收窄。

**4. 攻防紀錄摘要**
- Agent B 是全場立場移動最大的角色：Round 3「CallAttest 被全場從前作、訊號物理、形式化定義域、覆蓋率、社會累退性五個方向同時擊沉，我全部接受」。
- **與方向二的分工**（legacy 沿用）：方向二 = 通道量測/模擬器/可逆性判定，方向五 = 構造/政策/稽核協定。B 的實測容量 k 直接吃方向二量出的通道存活數字。
- **B 認領的形式化模組**：把「無綠燈原則」寫成機器可檢查的 safety invariant（只針對 detector 一種訊號、不硬扯 provenance，避開 D「三種綠燈焊成一個 scalar」的可通約性問題）——此模組貢獻給方向一。
- 誠實邊界（B 親自寫進第一頁）：對阿嬤的即時詐騙電話「救不了」；provenance 定義域是「非即時的語音訊息/媒體檔案/關鍵權威來源」。

**5. 實驗規劃（全部計算性）**
- **資料集**：與方向二共享真實通道基礎設施（B 認領 watermark bit 存活軸）；C2PA 簽署樣本用 c2patool/c2pa-rs（WAV/MP3 可用，Opus 需 feasibility spike）；AudioSeal/SynthID 開源 + latent watermark 作對照組。bona fide 全用公開語料。
- **Baseline**：AudioMarkBench（NeurIPS 2024）、Özer et al.（Interspeech 2025）的重錄協定作對照，劃清界線（它們做模擬擾動/重錄，本方向做真實電信通道 bit 存活）。
- **方法步驟**：(i) 真實電信通道矩陣上量 C2PA manifest 容器存活 + 傳統 vs latent watermark 的 bit-level I(embedded;recovered)（接方向二基礎設施 + C 的可控植入實驗做 ground-truth 錨）；(ii) 依實測容量 k 設計索引式編碼（ECC 選型、錯誤率-索引空間 trade-off）+ transparency-log 原型 + 端到端 demo（簽署→平台轉檔→無 metadata 復原並驗證）；(iii) Article 50 審計（法規要求 vs 實測可讀邊界對照表）；(iv) 覆蓋率天花板地圖（按「機構類型 × 驗證端滲透率」分格，採用率改為「公開 app 普及率的區間 + 敏感度掃描」，不再是自造數字）。
- **評估指標**：bit-level 存活率、索引式 vs payload 構造在低容量通道的有效資訊量、#6 五目標對照表、覆蓋率天花板百分比。
- **消融**：索引 vs payload 在低容量通道的有效資訊量；latent vs 傳統 watermark 在 neural codec 通道的存活差；覆蓋率天花板對滲透率假設的敏感度。

**6. 計算性驗證如何令人信服地推論到真實情境**
B：「所有 claims 本質上是資訊理論與密碼學性質——bit 存活率、綁定安全性、覆蓋率天花板。這些性質的成立與否從來不取決於人類感受；人類環節（使用者看到驗證結果會不會信）誠實排除在 claims 之外。這是密碼學的紀律——精確陳述我證明了什麼、沒證明什麼。」覆蓋率天花板用公開統計的 base-rate 建模（問題陳述明文允許引用已公佈數據），採用率改為公開 app 普及率區間 + 敏感度掃描（回應 F 對「自造數字」的批評）。

**7. 一年時程表**
- 月 0：法律 + 工具鏈 feasibility spike（任一元件不可用即啟動備案）。
- 月 1–3：量測基線（真實通道 watermark/manifest 存活，接方向二）——保底可發表產出。
- 月 4–6：依容量設計索引式編碼 + transparency-log 原型。
- 月 7–9：端到端 demo + Article 50 審計。
- 月 10–12：覆蓋率天花板地圖 + C2PA audio profile 建議 + 寫作。

**8. 真實情境部署路徑與社會福祉貢獻**
不救阿嬤的即時電話（B 舉白旗），但救上班族（LINE 語音訊息在 provenance 可達域內，機構簽章契約）與選民（查核組織的來源驗證工具、真錄音被誣陷時的自證清白）。拆解「有簽章＝真」的話術（#6 指出這正是民眾最易受騙處）。給標準與立法者第一份 Article 50 可讀性審計與 C2PA audio profile 修補建議。**覆蓋率天花板是給金管會與 165 的政策級發現**：量化 provenance 這條技術路線在真實詐騙生態裡的可達域上限——與其讓別人拿這條縫打防禦社群，不如自己把縫的寬度量出來。

**9. 風險與備案**
最大風險：audio C2PA 工具鏈成熟度（Opus soft binding 參考實作不成熟）+ neural codec 通道讓索引容量歸零。備案：manifest 層降級為「依 v2.4 spec 自行實作最小驗證」，論文重心移向 watermark bit 存活量測 + Article 50 審計 + 覆蓋率天花板（後兩者零前作、零工具鏈依賴）。與方向二高度共享基礎設施——若同實驗室同時做兩題須明確分工（方向二 = 量測/benchmark，方向五 = 構造/政策/稽核）。作為獨立碩論的最大風險：真實情境影響力墊底（救不了阿嬤）——備案是把主軸押在 Article 50 政策審計 + 覆蓋率天花板這兩個「政府繞不開」的政策級貢獻，或作為方向二的政策模組而非獨立主軸。

**主持人對 H 評分的調整說明：**
- **方向一 novelty 由叢集平均 3.5 上修為 4**：採納 Agent E 的宣稱形式升級（robust decision making 全稱量化）+ 適用域分治（Round 3 新增，把 D/G/F 三發重砲轉為中心產出）+ A 的 density-vs-discriminative failure-mode 假說，這三者是本輪新增、H 排名表未完全反映的 novelty。
- **†方向一「無真人說服力」維持 H 原 4**（未上修至滿分）：反映它最後的「so what」層仍靠 human-proxy；但已由「主承載退到 D 單調下界（對品質/壓力軸免疫）」補強，故不下修。

## 五、給作者的建議

**如果只能選一個，選方向一：分布與社工雙重偏移下的誠實棄權決策框架。**

**為什麼**：它是這場八人、三輪、二十四份文件的辯論裡，被 A、D、E、F、H 五個角色在最終推薦中列為推薦一或 co-首選的方向，而且三個把關角色的判定罕見地一致——**紅隊 D 主動推薦一個防禦方案**（「全場唯一不給攻擊者背書的防禦，它沒有在擋不住的地方發出確定的綠燈」）、**民眾 F 判定它是阿嬤那一行最接近『可以』、上班族情境直接『可以』的唯一方向**、**教授 H 列為 co-首選**（「唯一把因變數朝那個接電話的人延伸、且不依賴任何未兌現長期賭注的方向」）。它同時滿足問題陳述的全部硬性要求：直接朝「降低受騙機率」延伸（無綠燈原則不製造虛假安全感）、對社會福祉有貢獻（產出部署操作點準則與可證偽 pilot 靶）、一年做得完（元件全現成、不訓大模型、月 1–4 有不依賴任何申請的保底半篇 benchmark）、且**完全計算性**（受騙率宣稱主承載退到 D 的單調下界，對「推論不到詐騙現場」這一擊結構性免疫）。它也對這個領域最深的兩堵牆免疫：不與生成器軍備競賽（貢獻是評估框架與人機分工原則，不隨版本過期，通過 G 的四代歷史循環檢驗），不依賴任何未兌現的長期賭注（憑證普及、延遲軟肋、平台配合）。最關鍵的是——它把本輪辯論的全部精華（E 的邏輯形式、G 的判例牆、F 的素材與情境格、D 的對抗層、A 的技術內核、B 的形式化紀律、C 的 γ 維度）吸收成一條可執行的紅藍對抗證據鏈，而不散架。Agent F：「一個方向能同時吃下八個角色的補強而不散架，這件事本身就是它該當主軸的證據。」

**第一步先做什麼**：**月 0 立刻送 Zenodo VoiceWukong per-sample 存取申請**（唯一的時程殺手），同時並行啟動月 1–4 的「shift-aware calibration benchmark」——復現 AASIST / wav2vec2-XLS-R / RawNet2 三個偵測器，在 2×3 shift 矩陣上量 baseline 的 ECE 與 risk-coverage 曲線，並印出「負領土地圖」。這一步的產出本身就是一篇可獨立發表的 benchmark（保底半篇論文，不依賴任何申請），也是後續所有棄權機制比較與 confident-real 對抗評估的地基。把 Agent D 送的那句話刻在評估協定第一行：**對抗評估的主目標函數是 `max P(confident-real | fake)`，不是 risk-coverage curve**——攻擊者要的不是讓系統棄權，是讓系統自信地替他背書。並把 Agent H 的紅線刻在標題上：**primary outcome 永遠不叫「受騙率」，叫「文獻校準人類模型族上的期望損害穩健偏序」。**

**若行有餘力做第二題或有第二位學生**：選**方向二（真實通道多防線審計）**——它產出方向一必需的 γ（模擬樂觀偏差係數）真實上界與 unseen-channel 測試素材，兩者被 Agent C/G/H 用 γ 掃描維度硬耦合成一條證據鏈的量測端與消費端（方向一是消費端、方向二是量測端）。分工建議：建模/方法論型學生做方向一，工程/實測型學生做方向二。方向三（攻擊成本地圖）則是方向一驗收「棄權不被繞過」的必要對抗評估層，可作為方向一的一章或第三位學生的獨立題目。方向四（詐騙現場考卷）是方向一與方向二的共用素材層，工作量最輕、撞題最少，適合作為方向一的素材章或快速切入點。方向五（provenance/政策）風險最高、真實情境影響力墊底，僅建議 crypto 背景強、對政策發表有興趣的學生，或作為方向二的政策模組。
