# Round 1 提案：訊號處理研究者（Agent C）——第二輪（無真人實測）
日期：2026-07-14

> 立場回顧：第一輪我與 G 合流提出「真實通道存活性 benchmark」（成為 03-synthesis 的方向二），我的「通道一致性檢查」下游模組被 loopback 攻擊判死（我已撤回，沿用該共識），我的「存活圖譜」與「物理可逆性標註」被收編進方向三。本輪我站在這些既定結論之上發言。全文採用第一輪評估公約：禁用裸 EER，主指標為 fixed FPR ≤1% 下的 recall、ECE、risk-coverage、多 base rate expected cost。

---

## 1. 新限制對我的視角意味著什麼

「不做真人實測」對五個方向的衝擊，我逐一從訊號處理者的角度盤點。先講結論：**這條限制對我的主場（通道、codec、laundering）幾乎是零衝擊，甚至是淨加分**——訊號在通道上死不死，從來不需要問人，量測儀器和偵測器就是證人。但它對方向一的殺傷是結構性的。

### 方向一（誠實棄權 + 警告 UX + 受騙率）：核心驗證被抽掉一半

方向一的完整因果鏈是「偵測器準確率 × 警告設計 × 使用者壓力 → 實際受騙率」，其中 primary outcome「受騙率」靠月 8–9 的 30–50 人 user study 量測。新限制直接抽掉最後一環：

- **存活的部分**（前半條鏈，全部計算性）：shift 評估矩陣、ECE / risk-coverage、六種棄權機制比較、A 的 real-manifold 距離假說檢驗、D 的 `max P(confident-real|fake)` 對抗評估。這些是月 1–7 的工作，原本就標為「不依賴 IRB 的保底半篇」，現在升格為全篇主體。
- **可模擬替代的部分**：deferral policy 可用 #2 VoiceWukong 公佈的 300+ 人數據建 human-response model（人類對低品質 deepfake FAR 4–19%、高品質 FAR >82%），這在原規劃裡本來就是 IRB 延誤時的備案。
- **死掉的部分**：警告 UX 的行為量測——alarm fatigue 閾值、誤報後信任衰減曲線、「一鍵回撥」是否真的觸發查證行為、壓力下警告是否被忽略。這些是行為科學問題，**沒有任何計算性 proxy 能宣稱等價**。#2 的人類數據是「lab 條件、無時間壓力、無警告介面」的聽測 FAR，拿它模擬「壓力下看到警告的反應」是把 distribution shift 問題原封不動搬到 human model 上——我們在音訊上打了一整輪的 shift 之仗，不能假裝同樣的問題在行為數據上不存在。
- **判定**：方向一沒死，但「受騙率」不能再當 primary outcome 宣稱，必須誠實降級為「模擬受騙率（在 #2 人類模型假設下）」，論文重心移回 selective prediction benchmark + confident-real 對抗軸。這件事該由 A 和 H 來重新定價，我在第 4 節向他們提問。

### 方向二（真實通道 benchmark）：幾乎零衝擊，反而受益

- 通道量測本質是**設備對設備**：rig 兩端皆研究團隊自有設備，播放語料、錄回輸出，全程無人類受試。通保法 §29 路徑（G 的 T2 查證）沿用。
- 唯一要動的一處：原規劃素材含「團隊錄音（簽知情同意）」。最保守解讀下，自行錄製人聲並標註仍屬「自行收集人類資料」，何況「簽知情同意」這個動作本身就暗示它踩在 IRB 的邊界上。**我主張全部改用公開資料集語料**（bona fide 取自 ASVspoof / In-the-Wild / Common Voice 等的 held-out 子集），這不但合規，方法學上還更乾淨——素材固定、公開、可重現，benchmark 的比較軸「同一素材過模擬通道 vs 真通道」的配對設計完全不受影響。
- 淨受益：**月 0 的 IRB 送件（H 點名的頭號時程殺手）整條消失**。第一輪 H 給方向二可行性 2.5–3 分的扣分項少了一項。

### 方向三（攻擊成本地圖）：零衝擊

全部是模型對模型的攻防。唯一小傷：成本代理指標中「人力/社工抽回量」不能自行實測，只能引用文獻與市場工資做代理建模——但第一輪 D 的規劃本來就是這樣做的，無變化。我認領的「物理可逆性標註」是資訊理論量測，與人無關。

### 方向四（Active Liveness Probing）：中度衝擊，語料層被打穿一個洞

- RQ1 需要「真人錄回應」作為挑戰-回應的 bona fide 對照組（耳語、笑聲、哭腔等非典型發聲），RQ2 的切換點語料需要「真人共犯」段。新限制下不能自錄。
- 部分可救：公開非典型發聲語料存在——wTIMIT / CHAINS（耳語）、VocalSound（笑、咳、嘆息）、AudioSet 的 laughter 子集（此為我對資源的認知，具體可用性需 G 查證授權條款）。切換點語料可用公開多語者語料拼接模擬共犯接手。
- 但效度打折：這些語料不是「對挑戰指令的即時回應」，缺了挑戰-回應的時間耦合結構；若未來要宣稱「連續性稽核抓得到共犯切換」，拼接模擬的切換點與真實接手的切換點在訊號層是否同分佈，是個要誠實標註的假設。方向四本來就是全場最高風險，這一刀讓它更接近「純攻防重測」而遠離「防禦設計」。

### 方向五（Provenance 可達性）：零衝擊

簽章、浮水印、transparency log、稽核協定全是密碼學與訊號量測。B 的誠實邊界（救不了阿嬤的即時電話）與新限制無關，維持原判。

**小結**：新限制重排了五個方向的相對成本。方向二、三、五毫髮無傷，方向二還白賺一項可行性；方向一失去它「全場唯一直接量測受騙率」的王牌——而那正是它在第一輪被七個角色共推為首選的理由。這個王牌失效後，首選之位是否易主，是本輪辯論真正的爭點。

## 2. 思辨過程：五個候選，殺掉三個

以下是我的思考獨白，按出現順序記錄，包括被我自己殺掉的。

### 候選 1：方向二的無真人版直接繼承——「真實通道存活 benchmark」

最順理成章的一步：我第一輪的主提案，新限制下唯一要改的是素材來源（前述）。G 的 R5/T3 查證確認它是 2026-07 唯一無前作的空白，這個查證還沒過期。

**自我質疑**：
- (a) *H 的舊批評還在*：「資料集只是配菜」，靈魂必須是「揭露模擬樂觀偏差」。如果我只是把音訊灌過電話再量一次 EER 落差，那是體力活不是科學。落差量出來之後呢？「模擬比真實樂觀 X%」是一個數字，不是一個理解。
- (b) *素材改公開語料後的新隱憂*：公開資料集的 bona fide 錄音條件（棚錄、有聲書）與詐騙現場的通話語音本就有 domain 差。但仔細想，這對 benchmark 的核心比較軸無害——我量的是「同一素材、模擬 vs 真通道」的**配對落差**，素材是控制變因；它傷的只是「絕對 EER 數字外推到實戰」的宣稱，這個宣稱本來就不該做。
- (c) *工程風險未變*：rig 建置、電信商方案、LINE ToS 灰色地帶，全部還在。

**裁決**：不淘汰，但不能原樣端出——必須回答 (a)。修正方向：把「量落差」升級為「**分解落差 + 修好模擬器**」，見正式提案一。

### 候選 2：存活特徵圖譜升級為主軸——「通道劣化的物理可逆性理論」

我第一輪的邊緣提案。用 probing classifier 與資訊量測，對每一層 detection cue（相位微結構、高頻頻譜細節、vocoder artifact、韻律/時長統計）在每種通道下量存活率，並判定該劣化是「可逆分佈偏移」（DA 可補）還是「不可逆資訊摧毀」（做了永久失效）。#3 的關鍵發現——通道模擬 DA 幾乎完全消除劣化——暗示傳統 codec 的劣化多屬可逆偏移；但這個結論在 tandem 串接、重錄、神經 codec 下是否還成立，沒人量過。

**自我質疑**：
- (a) *量測工具的可靠性*：高維音訊上的 mutual information estimation 是出了名的不可靠（估計器 variance 大、上下界鬆）。用 probing AUC 當 proxy 比較誠實，但 probing 量的是「該表徵下線性可讀的資訊」，不是資訊本身——probe 讀不到不代表資訊死了。緩解：加一組**可控植入實驗**——在音訊中植入已知參數的合成 artifact（特定頻帶 notch、相位擾動、已知 vocoder 指紋），過通道後量恢復率，這樣 ground truth 是我自己定的，量測就有了錨。
- (b) *定位衝突*：物理可逆性標註在第一輪已被收編為方向三的一個組件。把組件膨脹成論文，H 會問：「這比方向三多了什麼？」誠實的回答是：方向三問「攻擊者要付多少」，這裡問「為什麼有些劣化付再多也修不回來」——一個是成本經濟學，一個是資訊物理學。理論上可分，但一年內做完一套嚴謹的可逆性判定框架 + 覆蓋足夠多通道，工作量不小，而且**它自己不產出任何防禦或量測基礎設施**，純分析。
- (c) *碩論體裁風險*：純分析性論文對碩士生是高風險體裁——如果可控實驗的結論是「都可逆」或「都不可逆」，論文就只剩一張表。

**裁決**：不作為獨立提案。**拆解併入**：可控植入實驗與可逆性判定作為提案一的診斷軸、提案二的核心方法。它是我的方法論武器，不是我的題目。

### 候選 3：方向一的無真人改造——「human-response model 模擬受騙率」

用 #2 的 300+ 人數據建 human model，模擬 deferral policy 下的受騙率。這是方向一在新限制下的官方逃生門。

**自我質疑**：
- (a) *這不是我的主場*——calibration、selective prediction、policy 模擬是 A 和 H 的地盤，我插手只會做出二流版本。
- (b) *更根本的：我不信這個逃生門有宣稱的那麼寬*。#2 的人類數據是 lab 聽測（受試者知道自己在做辨識任務、無時間壓力、無情緒操縱），拿它外推「詐騙電話壓力下的受騙率」，中間隔著一個沒有任何數據能校準的 behavior shift。模擬可以做，但結論的可信度上界是「在『lab 聽測行為 ≈ 實戰行為』這個無法驗證的假設下」。作為訊號處理者，我對「用錯誤分佈的數據做模擬然後宣稱外推」有職業性過敏——這正是 #3 揭露的模擬樂觀偏差的行為版。
- **裁決**：淘汰（作為我的提案）。但把質疑本身作為問題丟給 A/H——如果連他們都救不回「受騙率」這個 outcome，方向一就該讓出首選。

### 候選 4：神經 codec——「re-synthesis 通道是 detection 的終結者還是新指紋來源？」

這是本輪我真正的新想法，來自一個第一輪沒人展開的觀察。傳統 codec（AMR-WB、EVS 的 ACELP、Opus 的 SILK/CELT）是「分析-合成」：它們扭曲訊號，但波形與輸入之間仍有逐幀的參數對應。**神經 codec（EnCodec、SoundStream/Lyra v2、DAC）在本質上不同：decoder 是一個生成模型，輸出的每一個 sample 都是「生成」出來的**。音訊過一次神經 codec，等於被強制投影到該 codec 的生成 manifold 上——出來的東西「全部都是合成音訊」，只是內容忠於輸入。

這對 ADD 是雙面刃，兩面都沒被系統性研究過：

- **攻擊面**：neural codec transcoding 可能是接近零成本、零技術門檻的終極 laundering——fake 的 vocoder artifact 被 decoder 的 manifold 投影抹掉，bona fide 也被抹上同一層生成指紋，兩個 class 在第一、二層 cue 上被「等化」。若成立，#3 的樂觀結論（DA 可完全恢復）在神經 codec 通道上會翻盤，因為那是不可逆的 many-to-one 投影，不是可逆偏移。而且這不是假想威脅：neural codec 正在進入真實通訊鏈（Lyra 系已用於低頻寬視訊通話場景；主流平台採用與否屬**猜測**，需查證），就算平台不用，攻擊者自己 transcode 一次只要一行 ffmpeg 等級的指令。
- **防禦面**：投影不是均勻的。RVQ codebook 是在真實語音上訓練的，真實語音的 token 序列與 TTS 輸出的 token 序列在 codec 的離散空間裡統計性質可能不同——尤其 2023 後主流 zero-shot TTS（VALL-E 系）**本身就以 neural codec token 為生成目標**，其輸出 token 落在 codec language model 的高概率典型集內；真實語音的 token 有更高的「意外率」（此為可檢驗假說，目前是**猜測**）。若成立，「在 codec latent/token 空間做 detection」是一個通道天然對齊的新 domain：偵測器看到的表徵恰好就是通道傳的東西，unseen-channel 的 train/test mismatch 從根源上消失一段。

**自我質疑**：
- (a) *前作風險*：vocoder re-synthesis 作為攻擊，零星工作可能存在（#2 的 replay/resampling 變體不算，但 2025–26 可能有人做過 neural codec laundering；我記憶中無系統性前作，**標明猜測**，這是我留給 G 的頭號查證請求）。即使有零星前作，「可逆性判定 + latent-space detection + 攻防雙面」的組合仍可辯護，但「首個」宣稱要等 G 的查證才能下筆。
- (b) *防禦假說可能反轉*：也可能 fake 過 codec 後 token 統計反而更「正常」，真假在 token 空間不可分（AUC≈0.5）。但這個負面結果本身就是重要結論：它證明 neural codec 通道是 detection 的資訊理論死區，直接支撐「EU AI Act 式標記/偵測義務在 neural codec 管線上不可執行」的政策論證，並給方向三的攻擊成本地圖一個「成本趨近於零的必殺動作」。攻防兩面對沖了「賭錯邊」的風險——這正是 benchmark 型研究的優勢。
- (c) *「等化」假說可能太強*：CELP 系傳統 codec 也會摧毀相位，AASIST 們照樣在 C1 只掉 5.3%（#3）。也許 neural codec 的投影同樣「留了一手」。很好——那就量出來，「神經 codec 沒有想像中致命」也是對部署方有價值的結論。
- (d) *一年可行性*：這是它最漂亮的地方——EnCodec/DAC/SpeechTokenizer 全開源、偵測器 checkpoint 全現成、資料集全公開、**全程離線、不需 rig、不需 IRB、不碰 ToS**。在新限制下它是五個候選裡摩擦力最小的。

**裁決**：存活，成為正式提案二。

### 候選 5：模擬-真實落差的「分解與蒸餾」——修好模擬器

候選 1 的科學靈魂補完。如果真通道與模擬的落差存在（Deepfake-Eval-2024 的 audio AUC 掉 48% 給了強先驗），下一個問題必然是「**差在哪一層**」。真實通話鏈 = codec 實網協商行為（bitrate switching、DTX）+ 網路動態（burst 丟包而非 i.i.d.、jitter buffer、PLC 實作差異）+ **端點 DSP（手機的 AGC、noise suppression、echo cancellation——這些 always-on 的前處理在所有離線模擬中集體缺席）**+ 換能器。用受控消融把成分逐項加回模擬管線，看落差收斂多少，就能指認「模擬缺的那一塊」；把指認結果做成校準過的開源通道模擬器，用 held-out 真通道樣本驗證保真度。

**自我質疑**：
- (a) *黑盒分解 ill-posed*：真通道不給你拆。但我不需要完全辨識系統——我用探測訊號（sweep、已知語料）做 system identification 分出線性/非線性/時變成分，再用「逐項加回、量落差收斂」的消融邏輯，這是工程上成熟的做法，結論形式是「加入成分 X 後落差收斂 Y%」，不需要唯一分解。
- (b) *它依賴候選 1 的 rig 先存在*——所以它不是獨立題目，是候選 1 的第二階段。
- **裁決**：併入提案一，作為它區別於「體力活資料集」的科學核心。

**淘汰總結**：候選 2 拆解為方法論組件、候選 3 淘汰並轉為質詢、候選 5 併入候選 1。存活：候選 1+5（提案一）、候選 4（提案二）。

## 3. 正式提案

### 提案一：《模擬騙了我們多少？》真實通訊通道的存活性審計、落差分解與高保真通道模擬器蒸餾（全程免 IRB 版）

**核心 idea**
繼承方向二的真實通道 benchmark，做三個升級：(1) 素材全面改用公開資料集語料，配對設計（同素材 × {離線模擬, 真實通道}），全程設備對設備、零人類受試、零 IRB；(2) 科學主軸從「量落差」升級為「**分解落差**」——用受控消融指認樂觀偏差來自 codec 實網行為、網路動態、還是端點 DSP；(3) 產出「**蒸餾後的高保真開源通道模擬器**」，讓後續研究者不必架 rig 就能逼近真通道評估，把一次性的體力活變成社群的永久基礎設施。

**為什麼有機會成立（引文獻）**
- G 的 R5/T3 三重查證確認「真實電信通道存活」至 2026-07 無前作（03-synthesis 方向二）；Deepfake-Eval-2024（G 檢索 S10）的 audio AUC 掉 48% 給「落差存在」強先驗。
- #3 自承「對未知 codec（社群平台私有轉檔管線）的泛化未驗證」，且其「DA 幾乎完全恢復」結論建立在**已知 codec + i.i.d. 丟包**的模擬上——實網的 burst 丟包、bitrate switching、手機端 always-on DSP 全部不在其管線內，這正是落差的候選來源清單。
- 法律路徑（通保法 §29，G 的 T2）與評估公約（fixed FPR recall）沿用第一輪共識，不重辯。

**技術路線**
1. 月 1–3：rig 定案（兩台自有手機/SIP 端點 + 自動撥放錄音管線，記錄協商 codec/實測 PLR/jitter 為標註）；素材 = 公開 bona fide（ASVspoof/In-the-Wild held-out）+ 自生成 fake（3–5 家開源與閉源 API）。
2. 月 3–6：MVP 通道錄製（單電信商 VoLTE + LINE 語音訊息兩型態）→ 保底可發表單元；同步跑同素材的 #3 式離線模擬作為配對對照。
3. 月 6–9：三軸量測——偵測器劣化落差（fixed-FPR recall）、cue 存活圖譜（probing AUC 熱圖 + 候選 2 的可控植入實驗：植入已知 artifact 量恢復率，判定可逆/不可逆）、浮水印 bit-level 存活（認 B 第一輪認領的軸）。
4. 月 9–11：**落差分解**——逐項把「burst 丟包模型、jitter buffer、AGC、noise suppression、實測 codec 模式序列」加回模擬管線，量落差收斂曲線；把收斂後管線封裝為開源模擬器，用 held-out 真通道樣本驗證（偵測器性能差 + 特徵空間分佈距離雙指標）。
5. 月 11–12：資料集與模擬器開源、寫作。

**計算性驗證方案（替代真人實測的論證）**
本提案的因變數全部是儀器可量的：偵測器 recall、probing AUC、bit 錯誤率、分佈距離。原方向二唯一的人類成分（自錄 bona fide）以公開語料替代——配對設計下素材是控制變因，「模擬 vs 真通道」的落差歸因不受素材 domain 影響；被犧牲的只是「絕對性能外推到詐騙實戰」的宣稱，而那個宣稱在方法學上本來就不該由 benchmark 做。模擬器保真度的驗證同樣計算性：held-out 真通道樣本上的雙指標收斂即為證據。**結論可信度不依賴任何人類行為假設。**

**預期貢獻**
(1) 首個真實電信/平台通道的 ADD+watermark 存活公開資料集（繁中/台灣情境）；(2) 「模擬樂觀偏差」的首次量化**與歸因**——回答 H 的靈魂要求還多走一步；(3) 校準過的開源通道模擬器——把方向二的一次性量測轉為可複用基礎設施；(4) 為方向一提供 unseen-channel 真實素材、為方向三提供真實通道武器庫（第一輪分工不變）。

### 提案二：《全部都是合成音訊之後》神經 codec 通道下 deepfake detection 的資訊摧毀圖譜與 codec-latent 偵測

**核心 idea**
神經 codec（EnCodec、SoundStream/Lyra、DAC）的 decoder 是生成模型：任何音訊過一次，輸出就是 100% 合成波形——「real vs fake」的訊號層定義在這種通道後開始崩解。本提案雙面量化這件事：**攻擊面**——neural codec transcoding 作為零成本 laundering，對 SOTA 偵測器與浮水印的殺傷力，及其與傳統 codec 的本質差異（不可逆 manifold 投影 vs 可逆分佈偏移，用候選 2 的可控植入實驗判定）；**防禦面**——檢驗「codec 離散 token 空間保留 real/fake 可分性」假說，特別是針對以 codec token 為生成目標的 VALL-E 系 TTS：其輸出 token 是否落在 codec 表徵的「典型集」內、真實語音 token 是否有更高意外率，並以此建立 codec-latent 偵測器與 token 統計特徵基線。

**為什麼有機會成立（引文獻）**
- #3 的核心結論「通道劣化是可逆分佈偏移、DA 可完全恢復」**只在傳統參數式 codec 上驗證過**；神經 codec 是 many-to-one 生成式投影，資訊理論性質根本不同——這是 #3 結論適用邊界的直接檢驗，gap 明確。
- #2 證明後處理 manipulation 使 SOTA EER 崩至 13.5–50%，但其 38 個變體不含 neural codec transcoding；#1 指出壓縮 robustness 是 open problem 且訓練資料多為 lossless。
- 主流 zero-shot TTS 以 neural codec token 為中介表徵是公開事實，「fake 的 token 統計更接近 codec 典型集」是由此導出的可檢驗假說（標明：假說本身是猜測，成立與否皆有結論價值）。
- 前作空白狀態待 G 查證（我的頭號查證請求）；即使存在零星 re-synthesis 攻擊工作，「可逆性判定 + 攻防雙面 + latent 偵測」的系統性組合仍有辯護空間。

**技術路線**
1. 月 1–2：工具鏈——EnCodec/DAC/SpeechTokenizer（皆開源）× 多 bitrate；偵測器 AASIST/wav2vec2 系/RawNet2 現成 checkpoint；資料集 ASVspoof 2019/2021、In-the-Wild、MLAAD。
2. 月 2–5：**攻擊面圖譜**——{傳統 codec, 神經 codec, tandem 串接} × {bona fide, 各世代 fake} 的偵測器劣化矩陣（fixed-FPR recall）+ 浮水印（AudioSeal/SynthID 開源版）bit 存活；可控植入實驗判定各通道的可逆/不可逆邊界；對照組：#3 式通道 DA 重訓後能否恢復——若傳統 codec 可恢復而神經 codec 不可，即為「可逆性邊界」的直接證據，#3 結論的適用範圍就被劃出來了。
3. 月 5–9：**防禦面**——token 統計檢驗（codebook usage、token 序列在小型 codec-LM 下的 perplexity、RVQ 殘差能量分佈：real vs 各家 TTS）；訓練 codec-latent 偵測器（輸入為 token/latent 而非波形），與波形域偵測器在 {乾淨, 傳統 codec, 神經 codec, 雙重 transcode} 四條件下對比。
4. 月 9–11：對抗評估（接方向三框架）——攻擊者對 codec-latent 偵測器的最便宜繞過（再過一次傳統 codec？低 bitrate 重量化？token-space 擾動？）的成本曲線。
5. 月 11–12：整合寫作。負面結果出口：若 token 空間不可分（AUC≈0.5），主結論轉為「neural codec 通道是被動偵測的資訊理論死區」，直接輸入方向三成本地圖（零成本必殺動作）與 Article 50 政策論證（machine-readable 標記在 re-synthesis 管線上原理性不可讀）。

**計算性驗證方案（替代真人實測的論證）**
全程模型對模型、離線、公開資料與開源工具，無任何環節曾需要人：攻擊力以偵測器性能劣化量測；可逆性以可控植入 artifact 的恢復率量測（ground truth 由實驗者植入，無標註需求）；防禦假說以 token 統計的分佈檢驗與偵測器 AUC/recall 驗證。**它是五個方向中唯一「新限制下的驗證方案 = 原生驗證方案」的新題目**——不是把真人成分替換掉，而是從第一天起就不需要。結論可信度的唯一依賴是公開資料集與工具鏈的代表性，這是全領域共同承擔的假設。

**預期貢獻**
(1) 首個 neural codec 通道對 ADD/watermark 的系統性攻防量化（若 G 查證確認空白）；(2) #3「劣化可逆論」的適用邊界判定——傳統 codec vs 生成式 codec 的資訊理論分野，此結論不隨生成器版本過期；(3) codec-latent detection 這個新 domain 的第一份基線（或第一份否證）；(4) 對浮水印/標記政策路線的前瞻壓力測試：在 neural codec 成為通訊基礎設施之前回答「標記活不活得過 re-synthesis」。

**兩提案的關係**：提案一是「今天的真實通道」的審計，提案二是「明天的通道」的前瞻攻防，共享方法論（可控植入、可逆性判定、fixed-FPR 公約）但基礎設施獨立（提案二不需要 rig）。若只能選一個且工程資源有限，提案二的摩擦力最小；若實驗室有工程量能，提案一的基礎設施價值更大。
