# Round 1 提案：開創性思維者（Agent E）——第二輪（無真人實測）
日期：2026-07-14

> 立場聲明：我是那個第一輪「人群層級同源連結」被六人否證後撤回的人。這次我不打算重蹈覆轍——每個主張我都會先自己打一遍。但我也要說：這一輪的新限制「不做真人實測」在多數人眼裡是減法，在我眼裡是題目。**「如何用計算方法替代真人實驗」本身就是一個未被解決的方法論問題**，其他領域（金融壓力測試、氣候政策的 robust decision making、密碼學的全稱量化安全證明）早就面對過「無法對真實對象做實驗」的困境並發展出嚴謹的替代方案，而 usable security for deepfake 領域還沒有人系統性地做這件事。

## 1. 新限制對我的視角意味著什麼：五個方向的衝擊盤點

先把帳算清楚。第一輪統整（03-synthesis.md）的五個方向，在「零真人實測」下各自失去什麼、留下什麼：

### 方向一（誠實棄權 + 警告 UX + 受騙率量測）——**被抽掉的是心臟，不是四肢**

這是傷得最重的方向，因為它的全場最強賣點正是 H 的那句「全場唯一能指著數據說『這個設計讓受騙率從 X 降到 Y』的題目」。受騙率的 primary outcome 依賴月 8–9 的 30–50 人 user study——現在整段違規。

但盤點殘餘資產會發現四肢完好無缺：
- 月 1–7 的 shift-aware calibration benchmark（ECE、risk-coverage、六種棄權機制比較）**完全是計算性的**，且統整明言「此階段產出即保底半篇 benchmark 論文，不依賴 IRB」。
- Agent D 送的全場最關鍵對抗軸 `max P(confident-real | fake)` 是純機器攻防，不受影響。
- Agent A 的可檢驗假說（real-manifold 距離型分數在 AUC≈0.5 failure mode 下可能存活）不受影響。
- 最微妙的是：**原方向一的風險備案早已預言了這一輪**——「先用 VoiceWukong 已公佈人類數據做 policy 模擬（不需 IRB），user study 縮為 pilot」。現在只是把備案升格為主線。問題在於：備案升格後，「降低受騙率」的宣稱還撐不撐得住？這正是我提案一要正面回答的問題——我認為撐得住，但**宣稱的邏輯形式必須改變**（從點估計改為穩健排序，詳見提案一）。

### 方向二（真實通道存活 benchmark）——**幾乎不受影響，但有一個角落要清**

rig 通話兩端皆為研究團隊自有設備、播放的是資料集語料，這不是 human subjects research，是設備操作。唯一要清的角落：原實驗規劃的素材含「團隊錄音（簽知情同意）」——這一項在最嚴格解讀下可能觸發倫理審查邊界。替換方案顯而易見：素材全部改用公開資料集的 bona fide 語音（In-the-Wild、VCTK、公開華語語料）+ TTS 生成音訊。損失趨近於零。

### 方向三（Adaptive-Laundering 攻擊成本地圖）——**零影響**

全程是「現成生成器 + 現成 laundering 工具 + 現成偵測器 checkpoint + beam search」，本來就沒有任何真人成分。它在新限制下反而相對升值：當別的方向都要重新設計驗證方案時，它一行都不用改。

### 方向四（Active Liveness Probing，我的重建版）——**中度受傷，但傷口全部可用計算方法縫合**

原規劃有兩處真人成分：(a)「非同步挑戰-回應語料」中的「真人錄回應」；(b) relay 攻擊隱含真人共犯參與錄製。IRB 本來就「不在主線」，但這兩處必須替換。我在提案二會論證：(a) 可用**既有的非典型發聲公開語料**（耳語、情緒語音、笑聲）替代——這些語料早就存在，只是沒有人把它們當成「OOD 挑戰的回應分布」來用；(b) relay 可用**拼接式模擬**（不同語者的真實語音在挑戰段切換 + 重新過通道）替代，而且我會說明為什麼重新過通道這一步是模擬效度的關鍵。

### 方向五（Provenance 可達性地圖）——**零影響**

簽署、轉檔、量存活率、formal methods 安全論證，全是計算性的。與方向二共享的通道基礎設施同樣只需把素材換成公開語料。

### 小結：新限制重畫了地形

| 方向 | 受傷程度 | 被抽掉的東西 |
|------|---------|------------|
| 一 | 重傷（心臟） | 受騙率 primary outcome |
| 二 | 擦傷 | 團隊自錄素材（可換公開語料） |
| 三 | 無傷 | — |
| 四 | 中傷（可縫合） | 真人錄回應語料、真人 relay |
| 五 | 無傷 | — |

地形學結論：**新限制沒有殺死任何方向，但把方向一從「近乎全場一致的首選」打回「宣稱形式待重建」**。誰能重建方向一的宣稱邏輯，誰就重新拿回首選；重建不了，全場排序就要洗牌（方向三會變成新的可行性之王）。我的提案一就是這個重建方案。

## 2. 思辨過程：五個候選想法的生與死

以下是我真實的淘汰過程，包括兩個被我自己殺掉的想法。

### 候選 A：LLM 扮演受害者——「合成受試者」做 user study 的直接替代

**想法**：既然不能招真人，那用 LLM（或 audio-LLM）扮演接電話的受害者，模擬詐騙對話、警告介面出現後的行為反應，直接把 user study「合成化」。社會科學已有人用 LLM 模擬問卷受試者（所謂 silicon sampling）。

**自我質疑（致命）**：
1. VoiceWukong（#2）已經給了我一記耳光：MLLM（Qwen2-Audio）對 deepfake 音訊**完全不具偵測能力（英文 F1=0）**。用一個聽覺能力為零的 agent 去模擬「人類聽到可疑語音後的反應」，是用假體溫計量真發燒。
2. 更深的循環論證：LLM 對「高齡者在倒數計時壓力下的決策」的模擬保真度，本身就需要真人數據來驗證——而我們恰恰不能收真人數據。這是我第一輪 label leakage 教訓的翻版：驗證器的 ground truth 依賴我無法取得的東西。
3. silicon sampling 文獻自己都承認在高風險、高情緒領域的保真度未確立（這句是我對該文獻現狀的判讀，標記為猜測）。

**判決：淘汰**。但它留下一個有價值的問題：合成受試者不可行，是因為它試圖「模擬一個具體的人」。如果我們不模擬具體的人，而是**對「所有與已公佈數據一致的人類模型」做全稱量化**呢？這個念頭直接催生了候選 C。

### 候選 B：詐騙生態系的 agent-based simulation——population 層級的防禦部署最佳化

**想法**：借鑑流行病學的 agent-based modeling 與金融反詐的生態系模擬。攻擊者 agent 從方向三的成本地圖選攻擊配方，防禦方選部署策略（電信端偵測、機構端 liveness、App 端警告），受害者 population 的參數錨定在已公佈統計（165 財損數據、VoiceWukong 人類 FAR 分布），輸出「哪種部署組合最小化 population 期望損失」。

**自我質疑（重傷但未死）**：
1. 參數爆炸：受害者接觸率、警告服從率、攻擊者適應速度……每個未錨定的自由參數都是 reviewer 的一發子彈。「你的模擬是 SimCity 還是科學？」
2. 貢獻歸屬模糊：這是 security 論文還是 operations research 論文？碩士生一年內既要建模擬器又要做敏感度分析，工程量可疑。
3. 但它有一個別人沒有的能力：它是唯一能回答「防線 A+B 的組合效果」的框架——單防線評估（方向一到五都是）永遠答不了組合問題。

**判決：降級保留**。不做主軸，但作為提案一的 stretch layer（第四季選配）：當提案一的人類模型不確定集建好之後，population 模擬只是在它上面多加一層攻擊者流量分配，邊際成本低。**教訓：不要讓最有野心的層當地基。**

### 候選 C：人類模型不確定集——把 user study 換成「對一整類人類模型的穩健證明」

**想法**：這是候選 A 的屍體上長出來的。user study 做的事情是「估計人類行為參數的一個點」；密碼學做安全證明時從不估計攻擊者是誰，而是「對某一類內的所有攻擊者」做全稱量化。那就把人類受試者同樣處理：**定義一個「人類模型不確定集」𝓗——所有與已公佈人類數據（VoiceWukong 300+ 人的品質分層 FAR、#1 的 73% 準確率等）一致的行為模型的集合——然後只宣稱「對 𝓗 中所有模型都成立」的結論**。警告設計 A 優於 B，若且唯若在整個 𝓗 上 A 的期望受騙率都 ≤ B。

這不是我發明的推理形式：氣候政策學界叫它 robust decision making，金融監管叫它 stress testing / scenario analysis，密碼學叫它 security against a class of adversaries。**usable security 領域還沒有人把這個推理形式系統性地帶進來**——因為他們一直可以做 user study，沒有被逼到需要它。我們被逼到了，這就是機會。

**自我質疑**：
1. 「壓力下的行為」在已公佈數據裡沒有直接量測——VoiceWukong 的受試者是坐在電腦前安靜作答，不是被倒數計時逼匯款。𝓗 若不含壓力維度，結論外推到詐騙現場就是越界。**修正**：把壓力建為一個掃描參數 θ（壓力對人類辨識力/服從率的折損係數），θ 的範圍不猜點值、掃全區間，結論以決策邊界形式輸出：「除非壓力折損超過 X%，否則設計 A 穩健優於 B」。這反而比 user study 更誠實——30 人的 user study 也量不準真實詐騙壓力，它只是假裝量準了。
2. 「如果 𝓗 太寬，所有設計都無法排序怎麼辦？」——那本身就是重要結論：「現有公開人類數據不足以支持任何警告設計的排序」是對整個領域喊話「快去收數據」的可發表否證，而且會精確指出**缺的是哪一塊數據**（value-of-information 分析）。
3. 「這不就是方向一的備案（用 VoiceWukong 數據做 policy 模擬）嗎？」——備案是把公佈數據當點估計用；我的版本是把它當**約束條件**用，宣稱形式從「受騙率從 X 降到 Y」變成「排序在整個不確定集上穩健」。前者會被 reviewer 一句「你怎麼知道模型對」殺死，後者不會，因為我從未宣稱模型對，只宣稱結論對模型選擇不敏感。這是質變不是量變。

**判決：晉級為提案一。**

### 候選 D：無真人化的 Active Liveness Probing——用既有語料 + 拼接模擬重建方向四

**想法**：方向四是我 Round 3 親手重建的（OOD 壓力源重定義），我有責任把它的真人成分清乾淨。兩處手術：

(a) **「真人錄挑戰回應」→ 既有非典型發聲公開語料**。OOD 挑戰的本質（我 Round 3 的定義）是：非典型發聲（耳語、笑、哭腔、情緒語音）落在 streaming VC 訓練分布之外，轉換品質會崩，把攻擊者輸出推回被動偵測器的有效區。要驗證這件事**根本不需要現場真人**——耳語語料（wTIMIT 類）、情緒表演語料（CREMA-D、RAVDESS 類）、非語言發聲語料（VocalSound 類的笑/咳嗽）早就公開存在。把它們當 VC 的驅動輸入（fake 側）與 bona fide 對照（real 側），就能量出「每族挑戰讓偵測器 EER 恢復多少、speaker similarity 掉多少」的完整效力圖譜。

(b) **「真人共犯 relay」→ 拼接式模擬 + 通道重過**。relay 的聲學本質是：主體段與挑戰段的聲源不同。用多語者公開語料（VCTK 類）做拼接就能構造：真人 X 主體段 + 真人 Y（共犯）挑戰段，變體含 hard cut / crossfade / 共犯加 VC 貼目標音色 / 共犯 VC + OOD 挑戰（檢驗共犯是否被夾回 RQ1 的崩壞區）。

**自我質疑**：
1. **語料混淆變因（corpus confound）**：如果 real 側的耳語來自語料庫 P、fake 側來自語料庫 Q，偵測器可能學到的是 P vs Q 的錄音條件差異而非 real vs fake。**修正**：配對設計——同一語料的同一句話，原始版 vs 過 streaming VC 版，所有比較都在語料庫內部完成；再全部過同一 codec 正規化。
2. **拼接偽影捷徑（更陰險）**：拼接點的通道不連續性（兩段錄音的房間響應、底噪不同）會讓「聲源連續性稽核」撿到便宜——它偵測到的是我的拼接手法，不是 relay 本身，**給防守方虛假的樂觀**。這是我第一輪學到的最重要教訓的變體（label leakage）。**修正**：拼接後整段重過同一模擬通道（#3 的 codec 管線或方向二的真實通道 rig）——CELP 類 codec 重合成會把兩段的通道特性統一投影到同一空間，殘留的只有聲源本身的差異。這一步不是工程細節，是模擬效度的命脈,我會把「重過通道前 vs 後的稽核性能差」本身當成一個 ablation 報告出來。
3. 「離線拼接能代表即時 relay 嗎？」——不能完全代表（真實 relay 有即時銜接的猶豫、延遲），但注意方向性：離線拼接是**攻擊者的最佳情況**（無縫、可重試、可挑最好的一版）。若稽核在攻擊者最佳情況下都能抬升成本，真實 relay 只會更難。用「對攻擊者有利的保守模擬」立論，結論方向不會被質疑——這是紅隊評估的標準邏輯（D 應該會認可，我點名請他驗證）。
4. 「D-CAPTCHA 前作陰影還在嗎？」——在，但 G 已確認的 gap 沒變：D-CAPTCHA/D-CAPTCHA++ 的攻防全在乾淨/模擬條件下跑，relay 與真實通道存活兩篇都沒碰。我的無真人化改造不僅沒有縮小這個 gap，反而因為全計算化而讓「大規模系統性掃描（挑戰題型 × 攻擊策略 × 通道）」變得可能——真人實驗做 20 個條件就累死了，計算實驗可以做 2000 個。**無真人化在這裡不是妥協，是升級。**

**判決：晉級為提案二。**

### 候選 E（順手檢查後放棄）：防偽領域的「物理不可克隆」思路移植

**想法**：防偽界用 PUF（物理不可克隆函數）——每個晶片的製造隨機性是不可複製的指紋。音訊界的對應物是什麼？麥克風的非線性指紋、聲學環境的房間響應？讓「真實錄音設備」自帶不可克隆的物理指紋。

**自我質疑（速死）**：這就是 device fingerprinting，前作成山（ENF 電網頻率分析、麥克風指紋），而且第一輪已經判過死刑的通道一致性檢查的孿生兄弟——virtual audio cable / loopback 攻擊同樣零成本繞過：攻擊者把 deepfake 播進真麥克風重錄一次，物理指紋就是真的。**判決：淘汰**，寫在這裡是為了記錄「防偽移植」這條路我檢查過了。

## 3. 正式提案

### 提案一：《不做 user study 的 usable security——人類模型不確定集上的警告與棄權策略穩健排序框架》

英文暫題：*Usable Security without User Studies: Robust Ordering of Warning and Deferral Policies over an Uncertainty Set of Human Models Anchored to Published Perception Data*

#### 核心 idea

方向一的無真人版重建，但宣稱邏輯換心臟：不再估計「受騙率從 X 降到 Y」（那需要 user study），改為證明「**在所有與已公佈人類數據一致的行為模型上，警告/棄權設計 A 的期望受騙率都不高於 B**」。推理形式借自三個領域：密碼學的對抗者類別全稱量化、金融監管的 stress testing、氣候政策的 robust decision making。產出不是一個數字，是一張**設計之間的穩健偏序圖**＋每條排序的**失效邊界**（「除非壓力折損人類辨識力超過 X%，此排序成立」）。

#### 為什麼有機會成立（文獻錨點）

- **不確定集有真實數據可錨**：VoiceWukong（#2）公佈了 300+ 人、按 deepfake 品質分層的行為數據——人類對低品質 deepfake FAR 4–19%、對高品質 FAR >82%，且與 12 個偵測器的逐條件機器表現可對齊；#1 另提供人類整體準確率約 73% 的獨立錨點。這兩個錨足以約束「人類辨識力作為音訊品質函數」的模型族形狀（單調性、兩端點），不確定集不是憑空畫的。
- **人機互補結構是排序存在的前提**：#2 證明人類與偵測器的失效區恰好互補（人強於低品質、機強於高品質）——這個結構性事實意味著「怎麼分工」的不同 policy 之間**必然存在非平凡的優劣差**，穩健排序不會退化成全平手。
- **機器側全部沿用方向一已辯護過的資產**：shift 評估矩陣、六種棄權機制、ECE/risk-coverage（全場評估公約）、D 的 `max P(confident-real|fake)` 對抗軸——這些是純計算的，第一輪的攻防紀錄已替它們擋過子彈。
- **#8 明言「可信的使用者體驗」是優先研究方向卻無人做**；本提案給出的正是「在無法做 user study 時，UX 設計決策如何仍有證據可依」的方法論。

#### 技術路線

1. **月 1–4（沿用方向一原地基）**：復現 AASIST / wav2vec2 / RawNet2，建 in-domain / unseen-generator / unseen-channel / 疊加四格 shift 矩陣，量 baseline calibration 與 risk-coverage。保底半篇 benchmark，一字不改。
2. **月 4–6：建人類模型不確定集 𝓗**。以品質代理特徵（MOS 預測器如 NISQA/UTMOS 類——標記：具體工具選型需月 4 做 feasibility spike）為自變數，擬合 P(human 判 fake | 品質, 條件) 的模型族：以 #2 的分層數據為等式約束、單調性為形狀約束，用 Bayesian posterior 或 bootstrap ensemble 刻畫集合；壓力折損 θ、警告服從率 φ 為掃描維度（無數據支持的參數一律掃區間、不取點）。
3. **月 6–9：policy 空間 × 𝓗 的穩健排序**。policy = (棄權機制, 棄權閾值, 警告形式的行為學參數化, deferral 對象)。對每對 policy 在 𝓗 × base rate × θ × φ 的全網格上算 expected cost（沿用全場公約的多 base rate expected cost），輸出穩健偏序圖 + 每條邊的失效邊界 + value-of-information 分析（哪塊缺失的人類數據最能收緊排序——這是留給未來能做 user study 的人的精確採購清單）。
4. **月 9–11：confident-real 對抗軸**。攻擊者最佳化 `max P(confident-real|fake)`（接方向三的攻擊成本框架），檢驗穩健排序在對抗壓力下是否翻轉——「無對抗時 A>B、對抗下 B>A」若出現，是全新等級的發現。
5. **月 11–12：寫作** + stretch：候選 B 的 population 層（165 公開統計做流量權重）。

#### 計算性驗證方案（替代真人實測的核心論證）

- **替代物**：user study → (已公佈人類數據為約束的模型不確定集) + (全稱量化的穩健排序) + (無數據參數的全區間掃描)。
- **為什麼結論仍可信**：(a) 我從不宣稱知道人類是什麼樣——只宣稱「凡與已知數據一致的人類模型，結論皆同」，這在邏輯上**強於**一次 30 人 user study 的點估計（後者的信賴區間在 𝓗 語言裡只是一個很寬的子集）；(b) 每條結論附帶失效邊界，使用者（部署方）自己判斷邊界是否可信；(c) 可證偽性：𝓗、程式碼、排序全公開，未來任何新的人類數據出現，檢查它落不落在 𝓗 內——落在內，結論自動繼承；落在外，精確知道哪條排序作廢。
- **誠實邊界（寫進第一頁）**：本框架量的是「感知—決策鏈的期望受騙率排序」，不是真實受騙率的絕對值；「攻擊者叫受害者忽略警告」的社會工程仍在防禦鏈之外（同方向一原判）。

#### 預期貢獻

1. 第一個把 robust decision making 推理形式引入 ADD usable security 的框架（方法論貢獻，不隨生成器版本過期——通過 G 的四輪歷史循環檢驗）。
2. 方向一全部機器側資產的保全與升級（shift-aware selective prediction benchmark + confident-real 對抗軸照做）。
3. 一張可直接交給部署方的警告/棄權設計穩健偏序圖 + 失效邊界，以及給未來研究者的 value-of-information 數據採購清單。
4. 若排序不可得，「公開人類數據不足以支持任何警告設計選擇」本身是政策級否證。

### 提案二：《無真人化的主動活體探測：以既有非典型發聲語料與拼接式 relay 模擬，對挑戰-回應防線做 2026 世代的計算性紅隊壓力測試》

英文暫題：*Human-Free Active Liveness Probing: Computational Red-Teaming of Challenge-Response Defenses against 2026 Streaming Voice Conversion via Atypical-Vocalization Corpora and Splice-Based Relay Simulation*

#### 核心 idea

方向四（我 Round 3 重建的 OOD 壓力源版）的全計算化。三個替換：真人錄回應 → 既有非典型發聲公開語料（耳語/情緒/非語言發聲）的配對設計；真人共犯 relay → 拼接式模擬（含 VC 貼音色變體）+ **拼接後整段重過通道**以消除拼接偽影捷徑；小規模人工條件 → 大規模全掃描（挑戰題型 × 攻擊策略 × 通道條件的千級組合網格，這是真人實驗在物理上做不到的覆蓋密度）。定位維持 G 指出的唯一活路：**對既有防線（D-CAPTCHA 類）的紅隊壓力測試**，不是新防禦設計。

#### 為什麼有機會成立（文獻錨點）

- **Gap 未被佔領**（G 的 R5 檢索結論沿用）：D-CAPTCHA（AsiaCCS 2023）與 D-CAPTCHA++（IJCNN 2024）的攻防全在乾淨/模擬條件下；relay 成本與真實通道存活（D-CAPTCHA++ 的 imperceptible adversarial perturbation 能否活過 AMR-WB/EVS 重合成——C 判很可能被 CELP 投影掉，D 已確認）兩者皆無前作。
- **OOD 崩壞的機理有依據**：#2 證明偵測器對 artifact 明顯的低品質輸出很行（人類 FAR 4–19% 的那一區，機器同樣有效）；我的 OOD 壓力源假說就是「非典型發聲把 streaming VC 的輸出品質推進這一區」。這是可直接量測的：偵測器 EER 恢復量 + speaker similarity 下降量兩軸（方向四 RQ1 原設計，只是驅動素材換成公開語料）。
- **StreamVC 70.8ms（G 的檢索）證明延遲軟肋已死**，所以判別訊號必須是轉換品質而非延遲——這正好是計算實驗最擅長量的東西。
- **D 的判定沿用**：「全場唯一真的提高攻擊成本的方向」，因為它攻擊即時 arbitrary-content 音色轉換這個生成端真實功能瓶頸。
- 素材可得性：耳語、情緒表演、非語言發聲語料均有公開資源（wTIMIT、CREMA-D、RAVDESS、VocalSound 類——標記：具體語料的授權與品質需月 1 feasibility spike，這是本提案的第一個 go/no-go 檢查點）。

#### 技術路線

1. **月 1–2**：feasibility spike（語料授權/品質、seed-VC 與 StreamVC 類開源 streaming VC 的復現）+ D-CAPTCHA 協定重現。
2. **月 3–5（RQ1 挑戰效力圖譜）**：配對設計——同語料同語句的「原始 bona fide」vs「經 streaming VC 轉換」，按挑戰族（耳語/情緒/笑等非語言/韻律指令）× VC 系統 × 通道條件全掃描，量 (a) 被動偵測器 EER 恢復量、(b) 對目標語者 speaker similarity（ECAPA 類 speaker verification 模型）下降量。語料混淆變因以「語料庫內配對 + 統一 codec 正規化」控制。
3. **月 6–8（RQ2 拼接式 relay 稽核）**：多語者語料構造切換點樣本（真人 X 主體 + 真人 Y 挑戰段），攻擊精緻度階梯：hard cut → crossfade → 共犯 VC 貼音色 → 共犯 VC + OOD 挑戰。**全部樣本拼接後重過同一通道管線**，並報告「重過通道前後的稽核性能差」ablation（量化拼接偽影捷徑的大小，防止虛假樂觀）。聲源連續性稽核 = 挑戰段 vs 主體段 speaker embedding 一致性（我 Round 3 從人群連結廢墟裡救出的內核，現在完全不需要真人）。
4. **月 9–10（RQ3 通道存活）**：D-CAPTCHA++ 的 adversarial 攻擊 + RQ1/RQ2 訊號，過 #3 的 codec 管線（AMR-WB/EVS/Opus）；若方向二的真實通道 rig 存在則接真實通道。
5. **月 11–12**：D 的 attacker-cost curve 整合（每族挑戰 × 每種攻擊策略的成本抬升量）、寫作。保底切割：RQ1 + RQ3 單獨成篇 =「2026 條件下的 D-CAPTCHA 重新評測」。

#### 計算性驗證方案（替代真人實測的核心論證）

- **替代物**：真人挑戰回應 → 公開非典型發聲語料的配對對照；真人共犯 → 拼接模擬（攻擊者最佳情況）。
- **為什麼結論仍可信**：(a) RQ1 量的是生成系統的物理性質（OOD 輸入下的轉換品質崩壞），本來就與受試者無關，真人在原設計裡只是語料來源，不是被試對象——換成公開語料是等價替換；(b) RQ2 的拼接模擬對攻擊者**系統性有利**（無縫、可重試、可挑選），因此「稽核在此條件下仍抬升成本」是保守下界結論，真實 relay 只會更貴——保守方向的模擬不需要保真度證明，這是紅隊評估的標準邏輯；(c) 拼接偽影捷徑以「重過通道」消除並以 ablation 量化殘留，防止 label-leakage 式的虛假效度（我第一輪的教訓內建成協定）。
- **誠實邊界**：真實 relay 的即時銜接失誤（猶豫、搶拍）未被模擬——但漏掉它只會讓我低估防線效果，不會高估；「情緒社工」（攻擊者安撫受害者配合）不在量測範圍（同方向四原判）。

#### 預期貢獻

1. 挑戰-回應防線在 2026 世代 streaming VC + relay + 通道三重壓力下的第一份系統性存活報告（正負結論皆可發表：若 OOD 挑戰全滅，即「回撥/暗號類防詐宣導的技術基礎已過期」的政策級輸入）。
2. 挑戰題型的效力排行榜——給機構端（銀行/165）「該叫對方做什麼」的可操作證據。
3. 「拼接式 relay 模擬 + 通道重過」作為可重用的計算性紅隊協定（方法論貢獻，可被後續任何 liveness 研究沿用）。
4. 聲源連續性稽核的成本抬升量化——我第一輪被擊沉提案的內核，第三次轉世，這次以最謙卑的形式（一個被量測的模組，不是一個被宣稱的防線）。

### 兩提案的關係與取捨建議

提案一是方向一的宣稱邏輯重建（保全全場首選），提案二是方向四的驗證方法升級（把最擁擠領域的 gap 用計算密度重新佔領）。兩者共享全場評估公約與 D 的攻擊成本框架。若只能選一個：**提案一**——它同時回答了「這一輪所有人都要面對的方法論問題」（沒有 user study 時 usable security 怎麼做），這個答案本身的可遷移價值超過任何單一偵測技術。
