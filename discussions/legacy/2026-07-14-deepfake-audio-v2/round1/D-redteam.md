# Round 1 提案：紅隊/攻擊者（Agent D）——第二輪（無真人實測）
日期：2026-07-14

> 我是詐騙集團的技術顧問（研究用途）。我的工作只有一件：對每個防禦方案，找出最便宜的繞過路徑。口頭禪照舊——**攻擊者只要贏一次**。防守方要在所有通道、所有 base rate、所有生成器上都對；我只要在其中一條縫上贏一次，那個接電話的人就輸了。
>
> 本輪限制對我這個角色，是全場最不痛的一個。我的武器庫——adaptive laundering、metadata washing、confident-real 背書攻擊、成本地圖——本來就沒有一件需要真人。所以我的任務不是替自己療傷，而是誠實地告訴大家：**這個限制抽掉的，恰好是別人方向的靈魂，而不是我的。** 下面我會先驗傷，再攻擊自己的候選，最後留兩個我願意背書的方向。

---

## 一、新限制對我的視角意味著什麼

先說結論：**「不做真人實測」是一把只砍防守方、幾乎不砍攻擊方的刀。** 因為防禦的最終價值命題是「救不救得了那個人」，那是人的行為；而攻擊的價值命題是「系統會不會給我背書、我要付多少」，那是機器與資訊理論的事實。逐一驗傷（沿用 legacy 03-synthesis 的五個方向）：

### 方向一（誠實棄權 + 警告 UX + 受騙率）——核心驗證被抽掉，但骨架恰好落在我手上
這是唯一被重創的方向，而且傷在心臟。它在第一輪被七個角色列為推薦一、被 H 列為首選，**唯一的、決定性的理由**是「全場唯一直接量測受騙率」（synthesis 第 57、63、314 行）。primary outcome = 受騙率 = user study。本輪硬性限制第一條就禁掉 user study。

- **不受影響的部分**（本來就是計算性、而且本來就是我的地盤）：shift-aware calibration benchmark、risk-coverage 曲線、6 種棄權機制比較、以及**由我第一輪逼出來的 confident-real 對抗評估軸 `max P(confident-real|fake)`**。這些一根寒毛都沒掉。
- **被抽掉的心臟**：「偵測器準確率 × 警告設計 × 使用者壓力 → 實際受騙率」這條因果鏈的量測端。synthesis 明寫可用 VoiceWukong 的 300+ 人數據做 policy 模擬（第 94、112 行），但那是**建模**不是**量測**。方向一原本的價值主張是「我能指著數據說『這設計讓受騙率從 X 降到 Y』」（H 語，第 316 行）——建模版本頂多能說「在我這組人類行為假設下，X 降到 Y」。**這句話的說服力，跟它假設的可信度綁死。**
- **紅隊觀點**：方向一被抽掉受騙率量測後，剩下的骨架——calibration benchmark + 棄權機制 + confident-real 攻擊面——**幾乎就是我的方向三（攻擊成本地圖）加上 selective prediction 的一層皮**。也就是說，本輪限制把方向一往我這邊推。這不是我搶功，是限制的自然後果：當你不能量人，你就只剩下量攻擊者。

### 方向二（真實通道存活 benchmark）——幾乎不受影響
它本來就是純機器量測（codec、PLR、bit-level survival、probing AUC）。唯一沾到真人的是「團隊自己錄音、簽知情同意」（第 137 行）——但那是自建 bona fide 語料，不是 user study、不涉受試者行為量測。保守起見，這一塊可用公開 bona fide 資料集（VCTK、LibriSpeech）+ TTS 生成音訊完全替代，連知情同意都免。**這個方向本輪毫髮無傷。**

### 方向三（Adaptive-Laundering 攻擊成本地圖）——零影響，相對地位上升
這是我第一輪的方向。beam/greedy laundering search、物理可逆性下界、對現成 checkpoint 跑攻擊——**沒有一步需要真人**。當方向一的心臟被抽掉、地位下降時，方向三的相對地位自然上升。這不是巧合：**紅隊評估天生免疫「不能量人」的限制，因為攻擊者從來不需要問受害者的感受，只需要問系統的漏洞。**

### 方向四（Active Liveness Probing）——輕傷，已預先自保
它第一輪就把 user study 交給了方向一（第 235 行「IRB 不在主線」）。RQ1–RQ3 都是機器攻防。唯一沾真人的是「真人共犯 relay 語料」「真人全程/切換點語料」——但這些可用 streaming VC 生成回應 + 公開語料替代，不需招募受試者做行為實驗。**本輪對它幾乎無感。**

### 方向五（Provenance 可達性地圖）——零影響
純密碼學構造 + 存活量測 + formal methods。連 pixel 都不用問人。**毫髮無傷。**

**驗傷總結**：本輪限制精準地打在方向一的心臟（受騙率量測），其餘四個方向基本免疫。這對整場辯論的意義是——**第一輪「近乎全場一致的首選」，在本輪失去了它唯一勝過其他方向的那張王牌。** 誰來接？我的答案是：不是硬用建模冒充受騙率去續命方向一，而是**改用攻擊者視角、可辯護的計算性上界，去回答方向一想回答的問題**。這是我兩個提案的出發點。

## 二、思辨過程（候選想法與自我攻擊）

作為紅隊，我攻擊自己的候選時，用的標準跟攻擊防禦方案一樣狠：**這個題目，攻擊者（或 reviewer）要在哪裡贏一次就能推翻它？**

### 候選 A：把方向三（攻擊成本地圖）直接扶正為主提案
**想法**：本輪限制既然把方向三的相對地位抬高，那就把它做成主菜——對被動偵測、provenance、liveness 三類防線跑 adaptive-laundering search，畫 attacker-cost curve，每個 laundering 動作標物理可逆性下界。

**自我攻擊**：
1. **「真實情境影響力 2.5」的老問題還在**（synthesis 第 301、308 行）。F 判它「對阿嬤是少害她而非救她」。本輪抽掉受騙率後，如果方向一垮了、方向三只能給部署方當「照妖鏡」，那整場辯論會不會**沒有一個方向能直接回答「救那個接電話的人」**？這是我最擔心的系統性風險。
2. **成本代理指標的可辯護性**（synthesis 第 200 行，reviewer 必攻）——如何把「換 generator 的錢、laundering 的技術門檻、時間」量化成可比較的 scalar？E 第一輪已質疑「成本軸會過期」。
3. **會不會只是第一輪方向三的原樣重提？** 問題陳述第 29 行禁止原樣重提已擊沉提案，但方向三沒被擊沉、是 H 的次選。不過「原樣搬過來」在本輪沒有新論證，等於浪費了本輪限制帶來的新視角。

**修正而非淘汰**：保留方向三為主提案，但**用本輪限制給它注入新論證**——(a) 物理可逆性下界（資訊理論事實）作為對抗「成本會過期」的錨；(b) 明確把它定位成「當受騙率無法量測時，attacker-cost curve 是唯一不需要真人、又能反駁『這防禦有用』宣稱的計算性證據」。這回應了自我攻擊 2、3。自我攻擊 1（救不救得了人）留給提案二解決。→ **升級為正式提案一。**

### 候選 B：confident-real 背書攻擊面獨立成篇
**想法**：`max P(confident-real|fake)` 是我第一輪送出的、synthesis 稱「幫這個方向補上真正對抗評估軸」的貢獻（第 37、86 行）。本輪方向一失去 user study 靈魂後，這個純計算的軸可以獨立。核心洞察：**危險出口不是 abstain（對攻擊者不利），是 confident-real（系統替攻擊者背書）。** 任何給民眾「綠燈/這是真的/安全」訊號的防禦——selective predictor 的 confident-real 格、provenance 的有效簽章、watermark absent 被推論成 real——都有一個 confident-real 攻擊面。

**自我攻擊**：
1. **範圍會不會太窄，只是方向三的一個子集？** 如果只做「讓 selective predictor 吐 confident-real 的最便宜攻擊」，那就是 attacker-cost curve 的一條線，不夠一篇碩論。
2. **「背書攻擊」跟方向一的 confident-real 軸有什麼區別？** 如果沒有新東西，等於把 synthesis 已收編的評估軸換個包裝。

**修正**：把它從「一條攻擊線」擴展成「**統一的虛假安全感審計**」——不只攻 selective predictor，而是攻**所有防禦共有的那個結構**：任何試圖對民眾發出正向信任訊號的系統，其 confident-real 攻擊面的統一形式化與量測。這樣它不是方向三的子集，而是**方向三的對偶**：方向三量「繞過的成本」（攻擊者要付多少），這個量「繞過後系統替我背書的傷害」（攻擊者拿到背書能造成多少傷害）。→ 保留，但需要接上「傷害」的因變數才完整，見候選 C。

### 候選 C：用 VoiceWukong 已公佈人類數據，建「攻擊者最佳化下的 worst-case 受騙率上界」
**想法**：方向一被抽掉的是「受騙率量測」。本輪允許引用文獻已公佈的人類數據（限制第 22 行、VoiceWukong 300+ 人）。那能不能用它把受騙率**建模**回來，補上方向一的因變數？

**自我攻擊（這一段我對自己最狠）**：
1. **VoiceWukong 的人類數據是「辨識任務」，不是「詐騙情境受騙」。** 它量的是人被要求判斷「這段是不是 AI」時的 FAR（低品質 4–19%、高品質 >82%，#2）。詐騙現場的人**不在做辨識任務**——他在「女兒哭著要保釋金」的社工壓力下，根本沒開啟辨識模式。用辨識 FAR 冒充受騙率，是把一個樂觀場景的數字貼到悲觀場景上。作為紅隊，**這正是我會攻擊的那種虛假安全感**——如果我自己的題目就建立在這種偷換上，我沒臉交出去。
2. **建模替代量測會落入 E 第一輪的循環論證陷阱**（synthesis 第 30 行 label leakage 的同型批評）。H 會在 proposal defense 問：「你的 human model 憑什麼可信？」如果我的答案是「我假設人的行為服從 VoiceWukong 的 FAR」，那結論的說服力就等於這個假設的說服力，而這個假設剛被自我攻擊 1 打穿。

**這是關鍵的轉念**：既然我不能誠實地宣稱「建出真實受騙率」，那就**不要宣稱它**。改成攻擊者視角的**單調性論證**——我不需要證明「人會被騙到什麼程度」，我只需要證明「**當系統給出 confident-real 綠燈時，人的 false-accept 率只會 ≥ 無綠燈 baseline**」（綠燈只增加信任、不減少），因此 confident-real 攻擊拿到的，是**受騙率的一個下界保證**（攻擊者至少能達到 baseline，且綠燈把它往上推）。

這個轉念救活了候選 C：**我不建「真實受騙率」，我建「攻擊者靠背書能鎖定的受騙率下界」。** 下界是攻擊者視角、是保守量、是「壞消息的可信版本」——它不需要樂觀假設，只需要「綠燈不會讓人更警覺」這條幾乎不可能被 reviewer 推翻的單調假設。VoiceWukong 的 FAR 在這裡不是被冒充成受騙率，而是作為「無綠燈 baseline」，我證明的是**綠燈只會讓它更糟、糟多少**。→ 與候選 B 合體為正式提案二。

### 候選 D（額外，快速淘汰）：把 #7 的 metadata washing 從影像遷移到 audio provenance
**想法**：#7 用 metadata washing（省略規格允許省略的 assertion 欄位）產出「經認證的假內容」（survey #7）。遷到 audio。
**自我攻擊**：撞 B 的方向五地盤，且 B 第一輪已認領 strip-to-evade/mark-to-frame 攻擊清單（synthesis 第 271 行）。我原樣做就是搶題。**淘汰**——但我把「audio metadata washing 的成本量測」認領為提案一攻擊成本地圖裡 provenance 維度的一個攻擊動作，讓給 B 去做構造、我只做攻擊評估。這是分工，不是撞題。

## 三、正式提案

### 正式提案一：Adaptive-Laundering 攻擊成本地圖 × 物理可逆性下界——三類防線的統一照妖鏡

**1. 核心 idea**
對每個候選防線（被動偵測、provenance、liveness），不問「平均 robustness」，而問攻擊者視角的三個問題：(a) 讓它跌破可用門檻，**最便宜的 laundering 路徑**是什麼、幾步？(b) 這條路徑上哪些步驟踩到**不可逆資訊摧毀**的物理下界（做了就永久失效、補 DA 也救不回）、哪些只是可逆的 distribution shift（補 DA 可抵消）？(c) 這決定攻擊成本曲線是「懸崖」（防守方有戲）還是「緩坡」（防守方在裸奔）。輸出是一張跨三類防線的 **attacker-cost map**，附物理可逆性標註。

**2. 為什麼有機會成立（引文獻）**
- 現有 benchmark 全是**防禦者視角**：VoiceWukong（#2）的 38 個後處理變體、Loughborough（#3）的 C0–C5，都把 laundering 當「隨機後處理 / distribution shift」。**沒有人把它形式化成攻擊者的最佳化搜尋（adversarial laundering search）**。這個「攻擊成本」評估軸在 audio ADD 文獻中不存在（H 第一輪確認，synthesis 第 172 行）。
- 有強先驗撐腰：VoiceWukong 證明「換一次閉源 generator，AASIST2 EER 0.82%→13.5%」（#2）——這已經是「一步 laundering 就崩」的鐵證，但它是**偶然測到的平均值**，不是**攻擊者刻意搜出的最壞路徑**。我要證明的是「攻擊者最佳化的最壞情況比平均更陡」。
- 物理可逆性下界是**資訊理論事實、不隨月份過期**（C 的補強，synthesis 第 173 行）。這回應了「成本數字會過期」的批評——過期的是數字，不是「相位 cue 過 CELP 重合成永久投影掉」這種物理事實。

**3. 技術路線**
- 定義攻擊者**動作空間**：換 generator（開源+閉源 API）、re-synthesis laundering（VC 過一手）、codec tandem（AMR-WB→Opus 串接）、平台真實轉檔、loopback re-injection（virtual audio cable，第一輪判死通道一致性檢查的那招）、resample/time-stretch/replay、以及 provenance 維度的 metadata washing（strip 允許省略的 assertion 欄位，接 #7）。每個動作標三個代理指標（金錢/技術門檻/時間）+ **C 的物理可逆性二元標註**。
- 對 3–5 個現成公開偵測器 checkpoint（AASIST、wav2vec2/XLS-R backend、RawNet2）跑 **greedy / beam search**，找每個防線的最便宜繞過配方。不訓練任何大模型。
- 三類防線維度：被動偵測（cost curve）、provenance（B 確認無憑證即時詐騙攻擊成本 = 0；metadata washing 的存活率）、liveness（對 D-CAPTCHA 類防線量 relay / 社工抽回的成本 + D-CAPTCHA++ adversarial 攻擊過真實 codec 是否存活）。

**4. 計算性驗證方案（本輪核心：用什麼替代真人、為什麼結論仍可信）**
- **完全不需真人**：所有量測都是「攻擊動作 → 偵測器 EER/recall 變化」的機器對機器評估。beam search 的目標函數是偵測器輸出，不是人的判斷。
- **為什麼結論仍可信，甚至比真人實測更可信**：攻擊成本地圖的因變數是**偵測器在對抗 laundering 下的失效**，這本來就是機器事實，真人在這裡沒有位置。真人實測反而會引入受試者變異、樣本量、IRB 時程等噪音。**紅隊評估是本問題陳述裡少數「無真人版本嚴格強於有真人版本」的題型**——因為攻擊者從不需要問受害者。
- **不可爭議的錨**：主觀成本代理只作輔助排序，真正的骨幹是物理可逆性下界（資訊理論事實）。就算 reviewer 攻擊「你的金錢成本估算不準」，物理下界不動——它說的是「這個 cue 過這個通道後，互資訊 I(cue; 通道輸出) 掉到多少」，這是可計算、可複現、不需人的量。

**5. 預期貢獻**
戳破虛假安全感的品管關：阻止機構部署「EER 0.06% 但一步 laundering 就崩到 40%」的偵測器（給民眾虛假安全感比沒防禦更危險）。產出一個**可重複、可擴充的紅隊評估協定**，成為後續所有防禦研究的標準壓力測試——包括驗收提案二、以及提案一之外任何「宣稱能保護民眾」的方案。物理可逆性下界同時是正面設計指導：「依賴第三層存活特徵的偵測器攻擊成本曲線最陡，因為攻擊者要洗掉它就得破壞『聽得像目標語者』這個功能性約束」（C，synthesis 第 173 行）。

### 正式提案二：Confident-Real 背書攻擊——虛假安全感的統一審計 × 攻擊者視角受騙率下界建模

**1. 核心 idea**
本輪抽掉了方向一的受騙率量測心臟。我不硬用建模冒充「真實受騙率」（那正是我會攻擊的偷換），而是換攻擊者視角問一個**可辯護、不需真人**的問題：**任何對民眾發出正向信任訊號（confident-real 綠燈、有效簽章、watermark-absent-so-real）的防禦，其「系統替攻擊者背書」的攻擊面有多大、攻擊者靠背書能鎖定的受騙率下界是多少？**

兩個支柱：
- **(A) 統一的 confident-real 攻擊面審計**：把「危險出口是 confident-real 而非 abstain」（我第一輪的核心論斷，synthesis 第 37 行）形式化成所有正向訊號防禦共有的結構，並對每類防禦量 `max P(confident-real | fake)` 的最便宜攻擊。
- **(B) 攻擊者視角受騙率下界**：用**單調性論證**而非行為模擬——證明「系統給 confident-real 綠燈時，人的 false-accept 率只會 ≥ 無綠燈 baseline」，因此 confident-real 攻擊拿到的是受騙率的**下界保證**。VoiceWukong 的 FAR 在此當「無綠燈 baseline」，我量的是綠燈把它往上推多少。

**2. 為什麼有機會成立（引文獻）**
- confident-real 危險出口是全場公認、synthesis 稱「幫這個方向補上真正對抗評估軸」的貢獻（第 37、82、86 行），但**第一輪只把它當方向一的一個評估軸，沒有人把它獨立形式化成跨防禦的統一結構**。selective predictor 有 confident-real 格、provenance 有「有效簽章 = 真」的話術（#6 明指這正是民眾最易受騙處）、watermark 有「absent = real」的錯誤推論（#6：provenance 對無憑證內容零覆蓋）——三者共享同一個攻擊面。
- 單調性論證的可辯護性極高：它只需要一條假設「綠燈不會讓人更警覺」，這條假設幾乎不可能被 reviewer 推翻（沒有人會論證「系統說這是真的、反而讓人更懷疑」）。這讓下界成為**壞消息的可信版本**——不需要樂觀假設，因此不受「你的 human model 憑什麼可信」攻擊（H 必問，我已在候選 C 自我攻擊過）。
- VoiceWukong 的人機互補數據（人類低品質 FAR 4–19%、高品質 >82%，#2）是現成、已公佈、本輪明確允許引用的人類數據（限制第 22 行）。

**3. 技術路線**
- **支柱 A**：對三類正向訊號防禦定義 confident-real 攻擊。selective predictor：跑 adaptive attack 把 fake 推進「高信心 + 判 real」的格子（接提案一的 laundering search）。provenance：metadata washing 產出有效簽章的假內容（遷 #7）。watermark：strip watermark 讓「absent」被推論成 real。量各自的 `max P(confident-real|fake)` 與最便宜配方。
- **支柱 B**：建**攻擊者視角的傷害模型**。狀態：{系統沉默, 系統警示, 系統綠燈(confident-real)}。把 VoiceWukong FAR 當「系統沉默 baseline」，用單調性推導「綠燈狀態的 false-accept ≥ baseline」，量攻擊者靠支柱 A 把樣本推進綠燈狀態後，鎖定的受騙率下界。**明確標註：這是攻擊者視角的下界，不是真實受騙率的估計。** 敏感度分析掃過「綠燈信任增益」的整段合理範圍，報告下界對假設的穩健性。

**4. 計算性驗證方案（本輪核心）**
- **支柱 A 完全機器對機器**：confident-real 攻擊面的量測是攻擊動作 → 偵測器/驗證器輸出，零真人。
- **支柱 B 用單調性 + 公佈數據替代真人量測，為什麼結論仍可信**：這是本提案最關鍵的設計。真人版本要量「這個警告設計讓受騙率降多少」——那需要 user study。我的攻擊者視角版本**不量降多少，只量攻擊者能鎖定多少下界**。下界只依賴一條單調假設（綠燈 ≥ 沉默），不依賴「人在壓力下的具體行為分布」，因此**繞開了『詐騙現場的人不在做辨識任務』這個把辨識 FAR 冒充受騙率的致命偷換**（我在候選 C 對自己下的重手）。換句話說：我不宣稱知道人會被騙多少，我只證明「當系統替攻擊者背書時，受騙率至少不會比沒有系統時更低，而且綠燈把它往上推」——這句話不需要真人就成立，且它足以推翻任何「加了正向訊號 = 更安全」的防禦宣稱。
- **對防守方的價值**：這正好接住方向一被抽掉的因變數——方向一想證明「好的警告設計降低受騙率」，我從對偶側證明「壞的正向訊號設計抬高受騙率下界」。**兩者合起來，不需要一個真人，就框出了警告設計的可行區間。**

**5. 預期貢獻**
給「加了偵測/簽章/浮水印綠燈 = 更安全」這個全民級話術一個計算性的反證與量化。**產出「無綠燈原則」的形式化證據**：系統只該有「警示」與「沉默」兩態，沉默不是背書、綠燈是攻擊者的背書入口（synthesis 第 109 行的無綠燈原則，本提案給它攻擊面數據）。這是本輪限制下、**唯一能在不碰真人的情況下，把因變數重新連回「受騙」的方向**——用攻擊者視角的保守下界，而不是防守方視角的樂觀建模。
