## 核心推理

### 1. 領域名稱還不是研究問題

**推論（Inference）：** `deepfake audio detection` 是領域標籤。它尚未指定：

- 誰使用判斷結果；
- 要支援什麼決策；
- 要判斷哪一種主張；
- 面對什麼攻擊者與環境；
- 可以取得哪些證據；
- 判斷錯誤會造成什麼損失；
- 結果應在哪些條件下成立。

因此，它本身還不足以作為根研究問題。

### 2. 提議的根問題

**假設（Hypothesis）——問題地圖結構：**

> 面對一段音訊或一次語音互動，哪一位利害關係人必須判斷哪一種主張？他能使用哪些證據？在什麼威脅與分布條件下，判斷必須可靠到什麼程度，才能支援哪一項決策？

這個根問題不預設被動式二元分類一定是正確解法。

### 3. 依賴關係

```text
利害關係人與現實傷害
        → 定義
決策與行動
        → 定義
需要判斷的主張
        → 受到
攻擊者與環境的挑戰
        → 限制
可以取得的證據
        → 限制
推論任務與解法類型
        → 必須通過
有效的評估設計
        → 暴露
剩餘失敗與可能的研究缺口
```

箭頭表示依賴關係。每個子問題都必須說明它為什麼由父問題推出。

### 4. 第一層問題家族

| ID | 問題家族 | 邏輯依據 |
|---|---|---|
| Q1 | 誰使用判斷結果？ | 不同利害關係人的錯誤成本與可用證據不同。 |
| Q2 | 判斷結果支援什麼決策或行動？ | 沒有下游決策，偵測結果就沒有明確的操作意義。 |
| Q3 | 究竟要判斷什麼主張？ | 生成、變聲、剪輯、身分冒充與來源可信不是相同標籤。 |
| Q4 | 威脅模型與分布條件是什麼？ | 攻擊者能力與環境轉移決定哪些證據能夠保留。 |
| Q5 | 可以取得哪些證據？ | 只有波形、說話者參考、互動、浮水印及 provenance 允許的推論不同。 |
| Q6 | 需要什麼輸出？ | 二元標籤、風險分數、拒絕判斷、來源歸因與局部定位支援不同決策。 |
| Q7 | 什麼評估足以證明有用？ | 資料切分與整體指標必須符合宣稱的部署條件與錯誤成本。 |

### 5. 篩選關卡

候選問題路徑只有在通過下列關卡後才繼續：

1. **重要性：** 存在具體的利害關係人、決策與傷害。
2. **可定義性：** 目標主張與 ground truth 可以被操作化。
3. **可識別性：** 在既定威脅模型下，可用證據原則上能支持該主張。
4. **評估有效性：** 實驗與指標確實測試所宣稱的用途。
5. **可行性：** 資料、baseline、算力、時間、授權與倫理符合一年期碩士論文。
6. **剩餘不確定性：** 在明確範圍內，現有證據尚未充分回答該問題。

通過這些關卡，只代表問題值得進一步進行有紀錄的新穎性搜尋，不代表研究缺口已經成立。

## 與現有五個方向的關係

**已驗證（Verified）——專案狀態：** `PROJECT.md` 目前列出：

- selective prediction；
- 通訊通道評估；
- adaptive laundering；
- active liveness；
- provenance／watermarking。

**推論（Inference）：** 這些候選位於問題地圖的不同層次：

- selective prediction 屬於輸出與決策策略；
- 通訊通道屬於環境與 distribution shift；
- laundering 屬於威脅模型；
- liveness 屬於互動式證據；
- provenance 屬於經驗證的來源證據。

因此，必須先把它們放回完整的問題路徑，再進行比較。先前的 selective prediction 方向仍是有價值的既有研究，但不再被當成問題地圖的預設根節點。

## 目前結論

**推論（Inference），高信心：** 第一個實質分支應由「利害關係人與決策」開始，接著才是目標主張、威脅模型與可用證據。如果先按模型架構或資料集切分，會混合問題成因、解法與評估條件，無法形成可辯護的問題地圖。

## 下一個最小步驟

```text
利害關係人 → 決策 → 錯誤後果
```

先保留所有合理路徑；只有在具有明確理由與所需證據時，才能刪除某條路徑。
