## 檔案用途

- `problem-map.mm.md`：持續更新的視覺問題地圖，以精簡節點呈現目前結構。
- `NN-主題.md`：第 `NN` 個推理步驟的完整繁體中文討論紀錄。
- `README.md`：紀錄規則、步驟索引與目前進度。

## VS Code 心智圖預覽

建議安裝 VS Code 擴充套件
[Markmap](https://marketplace.visualstudio.com/items?itemName=gera2ld.markmap-vscode)
（擴充套件 ID：`gera2ld.markmap-vscode`）。

開啟 `problem-map.mm.md` 後，可以：

1. 點擊編輯器右上角的 Markmap 圖示；
2. 在檔案上按右鍵，選擇 `Open as markmap`；或
3. 從命令選擇區執行 `Open as markmap`。

`.mm.md` 是方便辨識心智圖檔案的命名慣例；檔案本質仍是一般 Markdown。Markmap 的樹狀畫面用來瀏覽問題結構，不能取代討論紀錄中的證據與箭頭關係說明。

## 紀錄規則

- 每完成一個推理步驟，就新增一份編號 Markdown。
- 使用繁體中文記錄作者的問題或反駁、推理過程、證據依據、目前結論、未解問題與下一個最小步驟。
- 不靜默改寫先前結論。若需要修正或補充，建立新的編號檔案，並指出它修正哪一步。
- 重要主張標示為 **已驗證（Verified）**、**推論（Inference）**、**假設（Hypothesis）** 或 **未知（Unknown）**。
- 歷史討論只能作為搜尋線索。技術性與新穎性主張必須回到原始論文或權威來源查證。
- 每更新一個步驟，也同步更新 `problem-map.mm.md` 與本索引。
