# D3 削減版：Adaptive-laundering 攻擊成本地圖
日期：2026-07-14

> 削減者裁定摘要：第二輪的方向三把「三類防線（被動偵測 / provenance / liveness）」焊在一個題目裡，而這三類防線要三套完全不同的方法論（laundering 搜尋 / C2PA 密碼學 / streaming VC relay rig）——那是三篇論文。本文把它砍回**一條防線（被動偵測）上的一套攻擊成本框架**，其餘全部切成 future work 或別人的論文。

## 二、砍

對每一個 deliverable 做「拿掉它，論文還成立嗎」測試。**這一節是靈魂，不客氣。**

- **D1 攻擊者動作空間 + 成本代理 → 【留】核心**。這是整篇論文的自變數，拿掉就沒有「攻擊成本」可言。但**收窄動作空間到離線可跑者**（codec tandem、neural codec transcode、resample/stretch、re-synthesis laundering），砍掉需要 rig 的「平台真實轉檔 / loopback re-injection」（那是方向二的地盤）。

- **D2 物理可逆性可控植入實驗 → 【留】核心**。這是全篇**唯一不可爭議的錨**（資訊理論事實，不隨生成器版本過期）。C 的物理可逆性下界是骨幹，主觀成本代理只是輔助排序。它就是 RQ2。**但用分層抽樣子集（20k）而非全集**，成本從 225–360 砍到 ~30。

- **D3 neural codec transcode 前處理 → 【留】核心，但強制降規**。理由：預算表明寫「neural codec transcode 是跑 300M–1B 生成模型，不是 ffmpeg」，全集 × 3 codec × 3 bitrate = 225–360 GPU-h 光轉檔就吃掉四分之一預算，且會被下游每個乘數再乘一次。**決策：ASVspoof21 DF 分層抽樣到 20k**，3 codec × 2 bitrate，成本降到 ~40。一格科學內容都沒少（可逆性是資訊物理性質，20k 分層抽樣的統計力足夠）。

- **D4 被動偵測攻擊成本上界搜尋 → 【留】核心，但強制降規**。這是 RQ1 的本體，不能砍。**但兩個決策把它從 500–1,000 降到 ~180**：(a) 每格評估用 20k 分層抽樣池而非 DF 全集（0.4–0.8/格 vs 2.5–5/格，省 6×）；(b) 搜尋停在 **recipe-level**（一條 laundering 配方套整個抽樣池、單次前向），**不做 per-sample 最佳化**。

- **D5 per-sample 白盒 + 序列式 oracle 攻擊 → 【砍】買不起**。算式：per-sample beam search 內嵌白盒 PGD 或 ≥10,000-query 黑盒 × ≥5,000 樣本 = 500–1,000 GPU-h（預算表紅線 #3，白紙黑字「絕對做不到」）。**退路**：保留**有界白盒 adaptive 攻擊**——固定 PGD-50、5,000 樣本、~10 組（落在預算表對抗評估 200 GPU-h 額度內），只用來**驗證 recipe-level 上界的穩健性**（證明「連白盒都繞不過的動作才算真懸崖」），不做開放式 per-sample 搜尋。序列式 oracle 攻擊整段砍進 future work。

- **D6 provenance 維度（metadata washing taxonomy）→ 【砍】另一篇論文**。理由：它的方法論是 C2PA manifest / watermark bit 的密碼學稽核，與「對偵測器跑 laundering 搜尋」是**兩套完全不同的框架**（違反收斂規則 #2：三 RQ 須由同一方法回答）。synthesis 自己也把構造端指給方向五。**它該併入方向五（Provenance）獨立成篇**，這裡連攻擊評估都不做。

- **D7 liveness 維度（E2 streaming VC + relay 排程）→ 【砍】另一篇論文**。理由：它需要即時 streaming VC 貼皮管線 + relay 共犯排程模擬，是一套獨立的即時系統方法論（E2 本來就是第二輪被擊沉的獨立「方向四 Active Liveness」殘骸硬塞進來的）。與被動偵測的離線 laundering 搜尋**共用不了任何一行程式**。整段砍進 future work / 獨立題目。

- **D8 懸崖/緩坡分類 → 【留】核心**。這是 RQ3，且是給部署方的「照妖鏡」核心產出。它與 D4 共用同一次評估，邊際成本低。**留**。

- **D9 成本代理敏感度分析 → 【留】**。這是答辯必需的防守（reviewer 必攻「金錢/技術/時間怎麼量成 scalar」），且成本低。**留**，但列為支撐消融而非亮點。

- **D10 baseline 平均劣化對照 → 【留】**。證明「攻擊者最佳化的最壞情況」嚴格重於 #2 的平均劣化，是整個框架的立論對照。便宜。**留**。

- **D11 接方向二真實通道武器庫 → 【砍】買不起 + 違反規則 #5**。兩個理由疊加：(a) 依賴方向二的 rig 產出當輸入，違反收斂規則 #5「可獨立完成」；(b) 真實通道轉檔全集 50–100 GPU-h 且工程日曆成本巨大。**砍**，寫進 future work（「把真實通道當額外 laundering 動作」是漂亮的延伸，但不是本篇的必要條件——離線 neural codec transcode 已提供不可逆必殺動作的乾淨版本）。

- **附帶砍：對方向一偵測器的依賴 → 【砍】違反規則 #5**。原 §5(ii) 要「對方向一的 selective-prediction 偵測器 + A 的 real-manifold 殘差距離棄權訊號」跑搜尋。這依賴方向一產出。**改用公開 checkpoint（AASIST / wav2vec2-XLS-R / RawNet2）+ 一個自建的距離型棄權 baseline（Mahalanobis-on-SSL，frozen 特徵）**，完全獨立，不吃任何其他方向。

**砍完盤點**：砍掉 **5 大項**（D5 per-sample 白盒/oracle 搜尋、D6 provenance 維度、D7 liveness 維度、D11 真實通道依賴、對方向一/A 偵測器的依賴），其中 3 項是「另一篇論文」、2 項是「買不起 / 違反獨立性」。留下 **6 項**（D1、D2、D3、D4、D8+D9+D10），但 D1–D4+D8 實質收斂成**一套框架的四個面**，D9/D10 是支撐。三類防線砍到**一類**（被動偵測），這是把 RQ 拉回「同一方法」的關鍵一刀。

## 三、砍完之後：這篇論文

### 1. 一句話問題
對一個被動語音深偽偵測器，攻擊者讓它失效**最便宜要付多少**，其中**多少是防守方永遠追不回的**？

### 2. 暫定題目
- 中：《攻擊者付的絕不超過多少——被動語音深偽偵測的 adaptive-laundering 攻擊成本上界地圖》
- 英：*What Does the Attacker Pay at Most? An Attacker-Cost Upper-Bound Map of Adaptive Laundering against Passive Audio Deepfake Detection*

（單一 deliverable：一張攻擊成本地圖。物理可逆性與懸崖/緩坡都是這張地圖的內部維度，不另立並列 deliverable。）

### 3. 三個 RQ
- **RQ1（攻擊成本上界）**：對每個公開偵測器，在已知離線 laundering 動作空間內，讓固定 FPR 下的 recall 跌破可用門檻的**最便宜配方**（攻擊成本上界）是什麼？
- **RQ2（物理可逆性下界）**：這個上界配方裡，哪些步驟只是**可逆的分佈偏移**（防守方能用 channel-aware DA 追回，如傳統 CELP），哪些踩到**不可逆的資訊摧毀下界**（neural codec transcode 的 many-to-one 投影，永久失效）？
- **RQ3（懸崖/緩坡幾何）**：攻擊成本-recall 曲線是**懸崖**（要昂貴的不可逆動作才崩，防守方有戲）還是**緩坡**（零成本可逆動作即崩，防守方在裸奔）？哪些偵測器設計選擇讓曲線變陡？

### 4. 同一種解決方式：一套 adaptive-laundering 攻擊成本評估協定

**這一套框架是什麼**：固定一組公開偵測器與一個離線 laundering 動作空間；對每個偵測器跑 **recipe-level 貪婪/beam 搜尋**，找出把它打穿的最便宜 laundering 配方；每個動作用**資訊理論可控植入實驗**標一個「物理可逆 / 不可逆」二元下界；把搜尋軌跡畫成攻擊成本-recall 曲線。**輸入永遠是「偵測器 + 動作空間」，輸出永遠是「上界配方 + 可逆性分解 + 曲線幾何」**——三個 RQ 是同一次計算的三種讀法：

- **RQ1 由搜尋的終點回答**：最便宜的打穿配方 = 攻擊成本上界。
- **RQ2 由對同一條配方套用可控植入標註回答**：把上界配方的每一步分成可逆/不可逆兩堆，就是可逆性下界分解。**用的是同一組動作、同一組偵測器、同一個抽樣池，沒有換方法**。
- **RQ3 由同一次搜尋的軌跡形狀回答**：成本-recall 曲線的陡峭度 = 懸崖 vs 緩坡；跨偵測器比較曲線就得到「哪些設計讓它變陡」。

**為什麼砍掉的兩類防線正是為了守住這一條**：provenance（D6）要換成 C2PA 密碼學稽核方法、liveness（D7）要換成 streaming VC relay rig——一旦納入，RQ 之間就換了方法論，直接違反收斂規則 #2。砍掉它們不是損失亮點，而是本框架能自洽的**前提**。

### 5. 貢獻（3 點）
1. **第一個把 audio ADD 的 laundering 從「防禦者視角的隨機後處理」形式化為「攻擊者視角的 recipe-level 最佳化搜尋」**，輸出攻擊成本**上界**（而非平均 robustness）——真實成本 ≤ 此值、動作空間開放可擴充，一個可重複、可擴充的紅隊評估協定。「攻擊成本」這個評估軸在 audio ADD 文獻中此前不存在。
2. **用資訊理論可控植入實驗給每個動作標物理可逆性下界**，把 neural codec transcode 認證為「零金錢、一行指令、物理不可逆」的必殺動作，並把攻擊成本上界**分解為可逆偏移（DA 可追回）與不可逆投影（永久失效）兩層**——這是不隨生成器版本過期的資訊理論錨。
3. **懸崖 vs 緩坡的偵測器幾何地圖**：指認哪些設計選擇讓成本曲線變陡，作為部署方的「照妖鏡」（阻止部署「EER 0.06% 但一次 transcode 崩到 40%」的偵測器）與後續防禦研究的標準壓力測試。

## 四、實驗規劃（收斂版）

**資料集**（全部公開可下載，全程離線免 rig 免 IRB）：
- ASVspoof 2019 LA / 2021 DF（ASVspoof 官網；**DF 集 611,829 筆 → 分層抽樣到 20k 池**，避開預算表紅線 #2）
- In-the-Wild（deepfake-in-the-wild，Zenodo）、MLAAD（多語 TTS，公開）作 unseen-generator 軸
- laundering 工具鏈：EnCodec / DAC / SpeechTokenizer（HuggingFace 開源 neural codec）+ AMR-WB / EVS / Opus / SILK（ffmpeg / 開源 codec）+ resample/time-stretch（librosa/CPU）
- 偵測器 checkpoint：AASIST、wav2vec2-XLS-R backend、RawNet2（皆公開 checkpoint）+ 自建 Mahalanobis-on-SSL 距離型棄權 baseline（frozen 特徵，不依賴任何其他方向）

**Baseline**：#2 VoiceWukong / #3 ADD-C 的**平均劣化**量測（C0–C5 平均 EER），作為對照，證明「攻擊者最佳化的最壞情況」嚴格重於平均。

**方法步驟**：
(i) 定義離線 laundering 動作空間（re-synthesis laundering、codec tandem、neural codec transcode、resample/time-stretch/replay、metadata washing），每動作標成本代理（金錢 / 技術門檻 / RTF 時間三軸 → 序數排序，不強行焊成單一 scalar）。
(ii) 物理可逆性可控植入實驗：植入已知參數 artifact（相位 / 高頻 / 韻律）→ 過每個動作 → 量恢復率，給每個動作一個 ground-truth 的可逆/不可逆二元下界（避開高維互資訊估計的不可靠）。
(iii) Recipe-level 攻擊成本上界搜尋：對每個偵測器跑貪婪 + 有限 beam（width≤3、depth≤4），每個候選 recipe 套 20k 抽樣池、單次前向、量固定 FPR≤1% 下的 recall，找最便宜打穿配方。
(iv) 有界白盒 adaptive 驗證：對距離型棄權訊號跑固定 PGD-50、5,000 樣本、~10 組，驗證上界配方的穩健性（不做開放 per-sample 搜尋）。
(v) 畫攻擊成本-recall 曲線 + 懸崖/緩坡分類 + 跨偵測器設計比較。

**評估指標**：固定 FPR≤1% 的 recall、attacker-cost 上界曲線（x=攻擊投入序數、y=recall）、最便宜繞過配方、物理不可逆下界標註、可逆/不可逆成本分解比、懸崖/緩坡二分。**禁用裸 EER 為主指標**（沿用全場公約）。

**消融**：(a) 成本代理定義敏感度（三軸不同權重下上界配方是否翻轉）；(b) 哪些偵測器設計選擇讓曲線變陡（SSL 層 vs 手工特徵、是否依賴第三層存活 cue）；(c) 可逆 vs 不可逆動作對曲線的貢獻分解。

**GPU-hour 估算**：

| 實驗項 | GPU-h | 依據 |
|---|---:|---|
| 偵測器復現/驗證 + frozen 特徵快取（5 模型，多為 eval/frozen） | 25 | frozen-backend ~0.3–1/次 + 少量驗證 |
| 分層抽樣池建置 + baseline 平均劣化對照（5 模型 × C0–C5） | 30 | 抽樣池評估 0.4–0.8/格 |
| Laundering 動作空間前處理（neural codec transcode 20k × 3 codec × 2 bitrate + ffmpeg codec + resample/stretch） | 40 | 抽樣子集 transcode（非全集，省 6×） |
| 物理可逆性可控植入實驗 | 30 | 植入 → 過動作 → 量恢復，抽樣子集 |
| Recipe-level 攻擊成本上界搜尋（5 模型 × greedy+beam，每 recipe 1 格） | 180 | ~40–60 recipe/模型 × 0.6/格 |
| 有界白盒 adaptive 驗證（PGD-50 × 5,000 × ~10 組） | 90 | 落在對抗評估 200 額度內 |
| 消融（成本代理敏感度 + 設計比較，重跑子集） | 60 | 子集重評估 |
| 緩衝（15%） | 70 | |
| **總計** | **525** | |

**525 GPU-h ≤ 1,200，餘裕 > 55%**（留遠超 20% 的餘裕，吸收除錯與重跑）。原始 2,200–3,000 → 525，**一格科學內容都沒少地降了約 4–6 倍**，靠的就是三個決策：DF 分層抽樣到 20k、搜尋停在 recipe-level、砍掉需獨立工具鏈的兩類防線。

## 五、一年時程（按季，含修課）

- **Q1（月 1–3）**：復現 5 偵測器 + 建 20k 分層抽樣池 + 定義 laundering 動作空間與成本代理框架 + baseline 平均劣化對照。**→ 保底：攻擊面地基 + 「最壞情況嚴格重於平均」的對照結論，不依賴任何後續申請。**
- **Q2（月 4–6）**：物理可逆性可控植入實驗 + neural codec 資訊摧毀圖譜（RQ2 骨幹，不可爭議的資訊理論錨）。**→ 第二保底單元。**
- **Q3（月 7–9）**：Recipe-level 攻擊成本上界搜尋（RQ1）+ 有界白盒 adaptive 驗證 + 攻擊成本-recall 曲線與懸崖/緩坡分類（RQ3）。

## 六、失敗退路（核心假設不成立時，這篇論文變成什麼）

- **假設一（成本代理可辯護）不成立**：reviewer 攻「金錢/技術/時間無法通約成可比 scalar」。**退路**：主承載退到 C 的**物理可逆性下界**（資訊理論事實，可計算、可複現、不需人、不過期）——成本代理降為輔助序數排序，論文骨幹改成「可逆 vs 不可逆動作地圖」，仍成篇且更硬。
- **假設二（存在懸崖）不成立**：所有偵測器都是「緩坡」，零成本可逆動作即崩。**退路**：這本身就是**對部署方的直接警告**（「現行被動偵測全在裸奔」）——與 #2 的失效證據同級，是可發表的負面結論。輸出改為點估計而非「上界」也依然單調安全（連最便宜路徑都擋不住 = 確定被繞過）。
- **假設三（neural codec transcode 真的不可逆）不成立**：若可控植入實驗顯示 neural codec 的某些 cue 竟可恢復。**退路**：那是對 C2 的「不可逆必殺動作」宣稱的否證，同樣有發表價值（「防守方以為死透的地方其實有救」），且可控植入方法論本身是貢獻。
- **保底**：Q1 的「攻擊面地基 + 最壞情況對照」與 Q2 的「可逆性圖譜」各自是可獨立發表的單元，任一後段全砍仍有半篇。

## 七、社會意義（用文字論證，不塞進實驗設計）

本框架的社會價值是**防止機構部署製造虛假安全感的偵測器**。實驗設計裡沒有任何「受騙率」「救不救得了人」的因變數——那是方向一的張力，硬塞進紅隊評估只會引入受試者變異噪音。這裡的因變數自始至終是機器事實：偵測器在對抗 laundering 下的 recall。

論證鏈（放 introduction / discussion，不放實驗）：一個銀行、電信商或 165 若採信「EER 0.06%」的行銷數字而部署，卻不知道攻擊者用一行 ffmpeg 神經 codec transcode（零金錢、物理不可逆）就能把它打到 40%，那麼這個偵測器製造的**虛假安全感比沒有防禦更危險**——它讓機構停止投資其他防線，也讓被保護者放下戒心。本框架給部署方一面「照妖鏡」：在採購前先量攻擊成本上界曲線是懸崖還是緩坡，緩坡的偵測器不該上線。它同時是後續**防禦研究的標準壓力測試**——任何新偵測器都要先過這張成本地圖，而不是拿 in-domain EER 的成績單唬人。對阿嬤這一行，它的定位誠實且有限：**不是「救她」，是「少害她」**——確保沒有機構拿一個一戳就破的東西當她的防線。這與 survey #8 的裁定一致：真實對抗環境中沒有任何單一手段充分，本框架的職責是替「分層防禦」裡的被動偵測那一層，誠實標出它的成本邊界。
