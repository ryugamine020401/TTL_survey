# D4 削減版：詐騙現場條件的評估效度審計（繁中）
日期：2026-07-14
削減者：Reducer

> 前言（誠實話，寫在最前面）：D4 和其他方向不一樣。別的方向是「算力超支 N 倍、砍到做得完」；**D4 從來不超支算力**——它不訓練大模型，只拿現成 checkpoint 對自建小語料做前向。它的病在別處：(1) 第二輪把它接了三條臍帶（接方向一模擬鏈、接方向二真實通道 rig、當「全場共用考卷」），其中「接方向二 rig」直接違反收斂規則第 5 條；(2) 被質疑「份量較輕」。本文件的裁定是：**剪掉臍帶後，D4 反而變成一篇乾淨、自足、方法單一的評估效度審計論文——它撐得起一篇，而且撐起的方式正是「不再當別人的模組」。**

## 二、砍

D4 的削減不是「砍算力」，是「剪臍帶、收邊界、把份量從『廣度』換成『深度』」。逐項做「拿掉它論文還成立嗎」測試。

- **#1 詐騙現場語料建構 → 【留】核心。** 拿掉就沒有論文了——這是整篇的地基與唯一的獨佔資產。
- **#3 四象限主實驗落差矩陣 → 【留】核心。** 這是 RQ1 的答案（總量樂觀偏差），拿掉論文不成立。
- **#4 四因子歸因消融（含交互）→ 【留】核心。** 這是 D4 相對五篇單軸前作的**唯一 novelty**（F：前作證明主效應存在，我只剩交互項待量）。拿掉就退化成第六篇單軸論文，撞題死。**交互項是靈魂，不准砍。**
- **#5 情緒/品質解耦 → 【留】核心。** 這是回答「是偵測器爛還是生成器爛」的混淆控制，也是 RQ3。拿掉，整份審計會被 reviewer 一句「你量的是情緒 TTS 品質差」推翻。它從 v2 的「附註」升格為方法論貢獻。
- **#8 話術語意作為自變數 → 【留】核心。** 這是 novelty (a)，D4 不被五篇前作吃掉的**唯一理由**。把它當論文的智識中心，不是第四個軸而已。

- **#6 通道疊加「接方向二真實通道 rig」的選項 → 【砍】另一篇論文（違反規則 5）。** 一句話理由：真實電信 rig 是方向二的整篇碩論（架設、法律、calendar 殺手），D4 依賴它就同時違反規則 5（依賴他方向產出）與規則 1（一個問題）。**改用 offline codec 模擬管線（#3 已公開、自足），通道降為「四個軸之一」而非「借別人的設備」。** 若日後要真實通道版本，那是方向二 × D4 的合作論文，不是這篇。
- **#9「全場共用考卷」的定位 → 【砍】為增加而增加（對本篇而言）。** 一句話理由：D4 的語料**能**被別人複用是好事（正外部性），但「必須同時接進方向一/二」是 F 為了那兩個方向的證據鏈加的政治條件，對 D4 自身的論文完整性零貢獻——它只增加耦合、擴大邊界、稀釋主軸。**砍成 discussion 一段「本資源可作為後續 shift-aware / 真實通道研究的輸入」，不寫進實驗設計。** D4 自己站得住，不需要靠「我服務了誰」來撐份量。
- **句長「10s+ 超長句」層 → 【砍】為增加而增加。** 一句話理由：詐騙現場的定義就是「3–5 秒」（哭腔一句、急迫命令一句），10s+ 只是回歸標準 benchmark 條件，做它是稀釋對比、模糊「短」這個軸的訊號。**保留 3s / 5s 兩層＋「標準長句」當對照上界即可**，砍掉中間的 10s+ 分層。
- **閉源 TTS/VC「3–5 家」的上限 → 【砍一半】買不起（金錢，非 GPU）＋ guardrail 風險。** 一句話理由：閉源商用 TTS 對「詐騙話術文本」的 guardrail 可能拒生成，且每家都是 API 金錢成本；**收斂為「2 家開源（情緒可控）＋ 1 家閉源（品質天花板對照）」**，多樣性夠證明落差不是單一生成器 artifact，又不把預算與 feasibility 賭在閉源 guardrail 上。

**砍完帳單：deliverable 從 9 項 → 留 5 項核心（#1、#3、#4、#5、#8），砍 4 項（#6-rig 選項、#9 共用考卷定位、10s+ 層、閉源家數上限）。** 砍後 GPU-h ≈ **85**（含緩衝），一項未動核心科學。

> 註：這裡沒有「【砍】買不起（算力）」的條目——因為 D4 誠實地沒有任何算力超支項。美化成「我砍了 3,000 GPU-h」是說謊。D4 的真相是：**它的稀缺資源是註冊了幾個生成器、跑了幾季的日曆，不是 4090。**

## 三、砍完之後：這篇論文

### 1. 一句話問題
**現行語音深偽偵測 benchmark 用朗讀長句量出的偵測率，對「詐騙現場實際到達受害者耳朵的三秒音訊」系統性高估了多少，這個高估來自哪個條件軸？**
（一個 deliverable：一份評估效度審計。無頓號串接多個交付物。）

### 2. 暫定題目
- **中**：《到達耳朵的那三秒：詐騙現場條件下語音深偽偵測的評估效度審計》
- **英**：*The Three Seconds That Reach the Ear: An Evaluation-Validity Audit of Audio Deepfake Detection under Scam-Scene Conditions*

（相對 v2 標題砍掉了副標裡「話術語意 × 短句長 × 情緒韻律 × 通道」的四軸頓號串接——那四軸是 RQ2 的**內容**，不是標題要並列的四個交付物。標題只講一件事：審計。）

### 3. 三個 RQ
- **RQ1（總量）**：把偵測器從「標準 benchmark 素材」搬到「詐騙現場素材」，在固定 FPR ≤1% 下的 recall 落差有多大？現行評估對詐騙場景整體樂觀多少？
- **RQ2（分解）**：這個落差由四個條件軸——**話術語意**、短句長、情緒韻律、通道——各自貢獻多少主效應？更關鍵的，它們的**交互效應**多大（前作全是單軸，交互項無人量過）？
- **RQ3（效度）**：這個落差在多大程度上是「偵測器對現場條件失效」，而非「情緒/短句 TTS 本身品質較差被偵測器抓到」？品質配對後的**淨落差**還剩多少？

### 4. 同一種解決方式（收斂規則第 2 條——最容易違反的一條）

**這一套框架就是：在一份「四軸分層 × 品質協變量標註」的自建詐騙現場語料上，量現成 frozen 偵測器的 fixed-FPR recall，並用同一批測量做因子分解與品質配對。** 一句話：**受控析因的評估落差量測**。

逐一論證三個 RQ 如何**全部由它回答**（沒有任何 RQ 需要換方法）：
- **RQ1** = 這套框架的**邊際彙總**：把「標準 vs 現場」兩個 cell 的 recall 相減。
- **RQ2** = 這套框架的**析因切片**：話術語意/句長/情緒/通道是**同一批樣本上的分層標籤**，交互效應＝對同一批 recall 測量做析因分析（ANOVA-style / 落差矩陣的交叉項）。**不換方法，只換切法。**
- **RQ3** = 這套框架的**協變量配對**：UTMOS + speaker similarity 是**同一批樣本上的品質標註**，淨落差＝在品質配對子集上重算同一個 recall 落差。**不換方法，只加控制變因。**

三個 RQ 共用**同一份語料、同一批前向、同一個 fixed-FPR recall 指標**——差別只在「彙總 / 分層 / 配對」三種讀法。這是收斂規則第 2 條最乾淨的一種滿足：**框架本身就是評估行為，三個問題是它的三個投影。** 沒有任何一個 RQ 突然變成「訓練新模型」或「建人類模型」——那些是方向一/三的方法，D4 一律不碰。

### 5. 貢獻（3 點）
1. **第一份詐騙現場條件的 ADD 測試語料**：繁中/台灣話術、四軸分層、品質協變量標註、負責任發布（守門下載 + 生成配方 + checksum）。填 #2（生成器軸）、#3（通道軸）都沒碰的正交空白：**素材生態效度**。
2. **量化「素材真實性樂觀偏差」及其四因子（含交互）分解**，其中「**話術語意/語用是否讓 TTS 露餡**」是五篇單軸前作全未觸及的自變數——這是本篇不被前作吃掉的智識核心。
3. **一個可審計的品質配對協定**，把「偵測器對現場失效」與「現場 TTS 品質較差」解耦，給整個領域一個「宣稱能防詐前先過這關」的評估效度標準。

## 四、實驗規劃（收斂版）

### 資料集（具體、自建、可得）
- **話術腳本來源**：165 反詐宣導/刑事局公開詐騙話術腳本（公開資料，無 IRB）→ 去識別化改寫（guardrail 主要卡 voice cloning 而非文本朗讀，改寫進一步降風險）。配對**中性文本**（同長度、同句法複雜度，語意中性）作為「話術語意」軸的對照臂。
- **bona fide（real 類）**：公開繁中語料（如 Common Voice zh-TW、AISHELL、公開廣播）+ ASVspoof/In-the-Wild real 類，切成 3s/5s 短段。
- **fake 生成**：**2 家開源情緒可控 TTS/VC（如 情緒可控 VITS 系 / OpenVoice 類）+ 1 家閉源 API（品質天花板對照）**。情緒 3 層（中性/哭腔/急迫）× 句長 2 層（3s/5s）+ 標準長句對照。
- **通道**：offline codec 模擬管線（#3 公開）——傳統可逆（AMR-WB/EVS/Opus）+ 神經不可逆（EnCodec/DAC transcode）。**自足，不接任何 rig。**
- **品質協變量**：每樣本標 UTMOS 類 MOS 代理 + speaker similarity（ECAPA/Resemblyzer），機器計算，無人工聽測。
- 語料規模估 ~2–3 萬筆（自建，遠小於 ASVspoof21 DF 全集，這是它便宜的根本原因）。

### Baseline
- **偵測器（frozen，現成 checkpoint，不訓練）**：AASIST、wav2vec2-XLS-R backend、RawNet2 三套。
- **對照條件**：三者在「標準 benchmark 條件」的官方 recall vs 本語料「詐騙現場條件」的 recall。

### 方法步驟與 GPU-h
| 步驟 | 內容 | GPU-h |
|---|---|---|
| S0 | Feasibility spike：閉源 guardrail 實測、情緒 TTS 選型、發布協定（go/no-go） | 5 |
| S1 | 語料生成（開源 TTS × 情緒 × 句長；閉源 API 為金錢成本） | 30 |
| S2 | 通道疊加（傳統 codec≈CPU + 神經 codec transcode 自建語料 3 種） | 15 |
| S3 | 品質協變量標註（UTMOS + speaker similarity 掃全語料 × 條件） | 10 |
| S4 | 主實驗 + 四因子析因消融（3 偵測器 frozen，快取 logits 共用前向；語意/句長/情緒為 metadata 切片，交互項邊際成本≈0） | 12 |
| — | 緩衝 20% | 14 |
| **核心合計** | | **≈ 86** |
| S5（選配 stretch） | 對 1 個偵測器做 scam-scene augmentation 微調，測落差是「可修復的 shift」還是「不可逆」——**可砍，砍了論文仍成立（歸 future work）** | +40 |
| **含選配合計** | | **≈ 130** |

**總計 ≤ 130 GPU-h ≪ 1,200（留餘裕遠超 20%）。** 算力不是這篇的瓶頸，一次都不用碰紅線。

### 評估指標
- 固定 FPR ≤1% 下的 recall（**禁用裸 EER 為主指標**，全場公約）。
- 標準 vs 現場的 recall 落差（RQ1）。
- 四因子主效應量 + **交互效應量**（RQ2）。
- 品質配對後的淨落差（RQ3）。

### 消融
- 話術語意 vs 中性文本的落差差（核心 novelty 驗證）。
- 短句 × 情緒 的交互（詐騙現場最真實的組合）。
- 通道對前三軸交互效應的調節。
- 品質配對前後落差的變化（RQ3 的穩健性）。

## 五、一年時程（按季，含修課）

- **月 0–1（Q1 起手）**：Feasibility spike（S0）——閉源 guardrail、情緒 TTS 選型、負責任發布協定定案（go/no-go 關卡）。同步復現 3 個 frozen 偵測器的 inference pipeline。**修課負擔最重的一季，工作量刻意最輕。**
- **月 2–4（Q1 末–Q2）**：語料建構（S1 + S2 + S3）——生成、通道疊加、品質協變量標註。**此季結束即有「一份可發布的詐騙現場 ADD 語料」保底產出。**
- **月 5–7（Q3）**：主實驗（S4）——四象限 fixed-FPR recall 落差矩陣（回答 RQ1）。**此季結束有半篇 audit。**
- **月 8–10（Q3 末–Q4）**：四因子歸因消融 + 情緒/品質解耦（回答 RQ2、RQ3）。（選配 S5 若時間允許放這裡。）
- **月 10–12（Q4）**：負責任發布（守門下載 + 生成配方）、寫作、投稿。

主體投 INTERSPEECH/ICASSP（benchmark/resource track）。

## 六、失敗退路（核心假設不成立時，這篇變成什麼）

- **假設崩法 A：落差很小（H0，現行 benchmark 其實夠代表詐騙場景）。** → 論文轉為「**現行 ADD benchmark 對詐騙場景的代表性驗證**」——一個可發表的否證，替社群省掉「素材不真實」這個焦慮，並公開繁中資源。VoiceWukong 式高品質負結果有先例。**仍成篇。**
- **假設崩法 B：話術語意軸無效（TTS 不因話術文本露餡），但句長/情緒/通道有效。** → 退回「四因子中三軸有效、一軸證偽」的乾淨析因結論。F 已論證：句長/情緒/通道的**主效應**由五篇單軸前作幾乎保證存在，本篇風險只在交互項大小，**主效應不會全滅**。**仍成篇。**
- **假設崩法 C：閉源 TTS guardrail 全拒生成。** → 月 0–1 spike 就會發現；改用去識別化改寫 + 純開源情緒 TTS，閉源降為「若可得則納入」。多樣性靠 2 家開源即足以證明落差非單一 artifact。**仍成篇。**
- **共通保底**：月 4 就有一份自足的公開語料（resource paper 最低標），月 7 有半篇 audit。**任何時點崩，手上都已有可提交的實體。**

核心假設（詐騙現場素材 ≠ 標準素材，且落差非零）幾乎不可能全滅——因為 #1/#2/#3 已量到 in-domain vs out-of-domain、壓縮通道的顯著劣化，本篇只是把「out-of-domain」的定義收窄到「詐騙現場」並拆解它。

## 七、社會意義（文字論證，不塞進實驗設計——本次裁定）

D4 不做真人、不量受騙率、不擋任何一通詐騙電話。它的社會價值是**評估誠實性**：今天任何廠商或研究者宣稱「我的偵測器能防語音詐騙」，用的成績單幾乎都來自十秒朗讀句、中性韻律、錄音棚出身的素材——而詐騙真正到達受害者耳朵的，是三秒的哭腔、一句急迫的命令、走過電話通道的話術。這兩者之間若有系統性落差，那張漂亮的成績單就是一種**制度性的虛假安全感**：它讓平台、銀行、165 以為問題已被解決，而受害者仍在那條沒被測過的縫裡受騙。

D4 把這條縫的寬度**量出來、拆開來、公開出去**，並附上一份繁中/台灣情境的公開考卷。它的貢獻用技術語言誠實陳述就是一句話：**「以後宣稱能防詐的偵測器，得先過『到達耳朵的那三秒』這關，不能拿十秒朗讀句的成績來唬人。」** 這是對問題陳述「侵蝕信任」的一種間接但結構性的回應——不是救人，是**讓所有宣稱救人的方案先接受一次誠實的體檢**。這層意義寫在 introduction 與 discussion，不變成任何一個實驗變數（依 00-constraints 第 30–34 行的裁定）。

## 回傳摘要（純文字）

- **砍掉幾項**：4 項（① 通道「接方向二真實 rig」選項＝違反規則 5＋屬方向二另一篇論文；② 「全場共用考卷」的耦合定位＝為本篇增加而增加，降為 discussion；③ 10s+ 超長句層＝稀釋「短」軸；④ 閉源 TTS 家數上限 3–5→1＝金錢與 guardrail 風險）。
- **留下幾項**：5 項核心（詐騙現場語料建構、四象限落差主實驗、四因子含交互歸因消融、情緒/品質解耦協定、話術語意作為自變數）。
- **砍後 GPU-hour 總計**：核心 ≈ 86 GPU-h；含選配 stretch ≈ 130 GPU-h。**遠低於 1,200 預算（用不到 11%）——D4 的瓶頸從來是日曆與論文邊界，不是算力。**
- **一句話問題**：現行 ADD benchmark 用朗讀長句量出的偵測率，對「詐騙現場實際到達受害者耳朵的三秒音訊」系統性高估了多少、高估來自哪個條件軸？
- **三個 RQ（一行版）**：
  - RQ1：標準素材→詐騙現場素材，fixed-FPR recall 落差多大（總量樂觀偏差）？
  - RQ2：話術語意/短句長/情緒韻律/通道四軸各自主效應與**交互效應**多大（前作只做單軸、交互無人量）？
  - RQ3：品質配對後淨落差還剩多少（是偵測器失效還是生成品質差的解耦）？
- **裁定**：D4 撐得起一篇——條件是剪掉三條跨方向臍帶、把「話術語意軸＋四因子交互＋品質解耦」當智識核心，用**單一的「受控析因評估落差量測」框架**回答全部三個 RQ（無方法切換，滿足規則 2）。
