## 三、砍完之後：這篇論文

### 1. 一句話問題

> **當語音深偽偵測器遇到訓練時沒見過的生成器與通道，它的棄權訊號還能不能可靠地認出「自己這次會答錯」？**

（一個問題、一個因變數：棄權訊號的可靠性。沒有頓號串接。）

### 2. 暫定題目

- **中**：《不知道就別答——分布偏移下語音深偽偵測的選擇性預測基準》
- **英**：*Abstain When Unsure: A Shift-Aware Selective-Prediction Benchmark for Audio Deepfake Detection*

一個 deliverable：**一個 shift-aware 的選擇性預測基準**。（原題目的三個頓號串接 deliverable 全部消失。）

### 3. 三個 RQ

| | 研究問題 |
|---|---|
| **RQ1（劣化）** | 在 generator-shift 與 channel-shift 之下，各棄權訊號的**判別力還剩多少**？固定 FPR ≤1% 時的 selective recall、risk–coverage 曲線與 ECE 如何劣化？是否存在「偵測 AUC≈0.5，但棄權仍有效」的格？（→ **負領土地圖**：哪些格連棄權都救不了。） |
| **RQ2（分岔）** | **density-based**（只建模 bona fide 分布，如 Mahalanobis-on-SSL、energy）與 **discriminative-derived**（依賴 fake 端決策邊界，如 MSP、temperature、evidential）兩族棄權分數，在同一個 shift 格上**是否分道揚鑣**？失效模式是否可預測？ |
| **RQ3（對抗）** | 攻擊者以 recipe-level laundering 或白盒擾動介入時，把各棄權訊號推進 **confident-real 區**（`max P(confident-real \| fake)`）的**最低成本**是多少？RQ1/RQ2 得到的機制排序，**在對抗欄位下是否翻轉**？ |

### 4. 同一種解決方式（收斂規則 2 的正面論證）

**這一套框架＝「棄權分數函數 × shift 網格 × risk–coverage 讀數」的單一量測介面。**

形式上只有三個物件：

```
s : x → ℝ          任何一個棄權機制，都只是一個信心分數函數
g : (source, channel, adversary) → cell    任何一種偏移，都只是網格上的一格
R–C(s | cell)      任何一個 RQ，都只是在同一組快取分數上讀不同的切片
```

工程上只有一條管線：**固定 4 個 checkpoint → 每格跑一次前向 → 快取 logits + pooled embedding → 全部 7 種機制、全部 3 個 RQ 都在這份快取上離線計算**（預算表 S1/S2/S4/S6）。

三個 RQ 如何**全部由它回答**：

- **RQ1** ＝ 沿 `cell` 的 generator 軸與 channel 軸讀 `R–C(s | cell)` 的**邊際劣化**。零額外方法。
- **RQ2** ＝ 把同一批 `s` 依「是否只用 bona fide 統計量」**分成兩族**，比較兩族在同一格的 R–C 曲線。**它不是新方法，是對同一組曲線的一次分割**。（唯一的額外運算是 speaker-identity 投影消融，跑一次 frozen ECAPA 前向，仍是同一條管線。）
- **RQ3** ＝ 在網格上**加一組 adversarial 欄位**（laundering recipe / PGD 擾動後的樣本），對同一批 `s` 重讀同一種 R–C 曲線，只是換一個讀數（`max P(confident-real|fake)` 是 R–C 曲線在「高信心 real」端的一個點）。**攻擊是網格的第三根軸，不是第二種方法論。**

**被換掉的 RQ**：原規劃的「哪種棄權/警告 policy 對人較優」需要人類模型族與 dominance 偏序——**那是另一套方法論**，所以它被 RQ3（對抗下的排序穩健性）取代。排序穩健性的問題還在，只是問的對象從「人的變異」換成「攻擊者的介入」——後者可以用同一條管線量，前者不行。

### 5. 貢獻（3 點）

1. **第一個 shift-aware 的 ADD 選擇性預測基準**：7 種棄權機制 × 12 格（generator × channel）的 risk–coverage、固定 FPR selective recall 與校準誤差，附**負領土地圖**——明確標出「連棄權都救不了、任何人都不該部署」的格。
2. **density-vs-discriminative failure-mode 的實證判決**：在偵測 AUC≈0.5 的失效格，只建模 bona fide 的分數是否倖存。這決定未來 ADD 不確定性研究該往哪一族投資——**是本論文唯一的假說，也是唯一的正面科學宣稱。**
3. **confident-real 攻擊面的形式化與量測**：`max P(confident-real | fake)` 與**無綠燈原則**（輸出狀態空間中不存在對 fake 的正向信任訊號）作為可重複、可比較的評估軸，證明或否證「棄權機制本身可被零成本繞過」。

### 4.2 Baseline

**4 個偵測器 checkpoint（全論文共用，預算表 S4）**：AASIST（從頭）、RawNet2（從頭）、**XLS-R 300M frozen + AASIST backend**（S6：文獻證據顯示資料受限時 frozen 可能更好）、XLS-R 300M full fine-tune（對照臂）。

### 4.3 方法步驟

1. 建評估池（分層抽樣、打包成 webdataset shard——Windows 上讀 61 萬個小 flac 是 I/O 地獄，預算表 S9）與 3 個通道副本。
2. 訓練 4 個 base checkpoint + evidential 變體 + ensemble seed。
3. **每格跑一次前向，快取 logits + pooled embedding（全 25 層，pooled 不 frame-level，預算表 S3）**。
4. RQ1：在快取上離線算 7 種機制 × 12 格的 R–C / ECE / selective recall。
5. RQ2：分族比較 + speaker-identity 投影消融。
6. RQ3：recipe-level laundering beam search（B=5, D=4, A=8）+ 白盒 PGD-50（僅可微路徑）+ 小規模黑盒 sanity；重讀同一組 R–C 曲線的 confident-real 端。

### 4.4 評估指標

固定 FPR ≤1% 下的 **selective recall**、**risk–coverage 曲線與 AURC**、**ECE / reliability diagram**、**`max P(confident-real | fake)` 與其攻擊成本上界**、**多 base rate 下的期望成本**。
**禁用裸 EER 為主指標**（沿用第二輪全場公約）。

### 4.5 消融

density vs discriminative 在 AUC≈0.5 格的命運分岔；speaker-identity 投影移除後的殘差子空間；MC-dropout 的 T 敏感度（T=5/10/25，單模型單格）；Mahalanobis 的 SSL 層選擇；temperature 校準集的選擇；`C_neural` 的 bitrate 梯度（可逆性邊界）。

## 六、失敗退路

**核心假設**：至少某些棄權訊號，在 unseen-generator / unseen-channel 下仍保有可用的判別力（即：偵測器答錯的樣本，其信心分數系統性地低於答對的樣本）。

**這篇論文的結構性優勢：三個 RQ 的 null 結果，每一個都是可發表的結論。**

| 假設破裂的情境 | 論文變成什麼 |
|---|---|
| **主假設全滅**：在 AUC≈0.5 格，7 種棄權訊號的 R–C 曲線全部退化成隨機 | 論文變成 **「選擇性預測在 ADD 上的嚴謹否證 + confident-real 攻擊面 taxonomy」**。這是對整條 uncertainty-for-ADD 路線的**可發表負面結果**——先例是 VoiceWukong（高品質負面結果進 USENIX Security 2025）。而且 Q2 的 benchmark 已經獨立成篇，畢業無虞。 |
| **RQ2 是 null**：density 與 discriminative 兩族沒有分岔 | 答案是「不必再為 one-class 賽道的不確定性方法投資」——一樣是結論，且省掉整個社群的資源。 |
| **RQ3 兩邊都能寫**：攻擊打得動 → 這是對部署方的警告（虛假安全感）；攻擊打不動 → 這是正面的部署證據 | **RQ3 沒有失敗模式**，只有兩種結論。 |
| **最壞情況**：連 benchmark 都做不出有意義的差異（所有機制在所有格都一樣爛） | 那本身就是「現有不確定性方法在 ADD 上完全無法區分」的判決，配上完整的 12 格資料與公開的快取，仍是一份社群可用的資源型貢獻。 |

**沒有任何一條退路需要新的方法論、新的資料、或新的一年。**

## 七、社會意義（文字論證，不進實驗設計）

> 這一節按 `00-constraints.md` 的裁定寫：**放棄「受騙率當因變數」**，社會價值用文字論證，不硬塞進實驗。

**偵測器最危險的失效不是漏抓，是自信地說「這是真人」。** 一個把 deepfake 判成 bona fide 且信心 0.99 的系統，比一個沒有系統更糟——它替攻擊者背書。第二輪的紅隊（Agent D）之所以罕見地推薦一個防禦方向，理由正是這一條：「它沒有在擋不住的地方發出確定的綠燈，我就沒有背書可偷。」本論文把這句話變成一個可量測的量：`max P(confident-real | fake)`，以及一條可檢查的設計不變量——**無綠燈原則：系統只有「警示」與「沉默」兩態，沉默不是背書。**

**這篇論文不宣稱救得了任何人，而且它明確地說出這件事。** 它不量受騙率、不做因果宣稱、不模擬人類受試者（Qwen2-Audio 在 deepfake 上 F1=0 是現成的反例，LLM 模擬受試者已被實證判為不可靠）。它量的是**機器的自知之明**。受騙率是下一篇論文的事，而那需要 IRB、需要真人、需要一個本論文明確拒絕假裝擁有的東西。

**它的社會用途是「開 pilot 的門檻證據」。** 平台、銀行、165 這些部署方不缺 A/B test 能力，缺的是「值得為這個偵測器開一次 pilot 嗎」的證據。本論文交付的是一張操作點準則表：**在哪些條件下這個偵測器的沉默可以被當成訊號、在哪些格子它連棄權都不該被信任（負領土地圖）**。這是一份誠實的、可被否證的、可以直接放在部署會議桌上的東西——比一個 EER 0.06% 卻在一次 neural codec transcode 後崩到 40% 的排行榜數字，對真實世界有用得多。

**誠實邊界（寫進第一頁）**：本論文量的是偵測器在偏移與對抗下的棄權可靠性。它不涵蓋：人類會不會服從警告、攻擊者能否用社工繞過整個系統、多回合信任建立、threat displacement。這些不在框架內——不是因為它們不重要，而是因為**假裝一年一張 4090 能回答它們，才是真正的不誠實。**
