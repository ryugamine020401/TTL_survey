**接受並執行的三刀（全部照砍）：**

1. **【砍】XLS-R full fine-tune 對照臂 → 只保留 frozen XLS-R + AASIST backend。**
   這是鷹派的首選刀，三條理由我逐條同意：(a) 它是最大的日曆殺手——SSL full fine-tune 復現對 lr/warmup/layer-drop 極度敏感，「跑得動」到「復現出論文 EER」差 3–4 人週；(b) 它在 GPU 帳上被乘最多次（base + evidential 版 + ensemble seed，是「10h × 多次」的來源），砍掉連帶消除訓練重跑 ×2.5 的風險；(c) **科學上可辯護不是撤退**——預算表 S6 白紙黑字：資料受限時 frozen XLS-R 可能更好（ASVspoof5 上 frozen EER 8.76%）。砍掉通過「拿掉它論文還成立嗎」測試——benchmark 仍是 3 個偵測器（AASIST / RawNet2 / **XLS-R frozen+AASIST**，涵蓋 spectral-graph / raw-waveform / SSL 三種表徵族），三個 RQ 一個都沒少。full-FT vs frozen 的對照寫進 future work。

## 三、三個 RQ 與貫穿它們的同一種方法

### 核心方法（一套）

**「棄權分數函數 × shift 網格 × risk–coverage 讀數」的單一量測介面。**

形式上只有三個物件，三個 RQ 全部在它們之上定義：

```
s : x → ℝ                              任何棄權機制 = 一個信心分數函數
g : (source, channel, adversary) → cell   任何偏移 = 網格上的一格
R–C(s | cell)                          任何 RQ = 在同一組快取分數上讀不同切片
```

工程上只有一條管線：**固定 3 個 checkpoint → 每格跑一次前向 → 快取 logits + pooled embedding → 全部 6 種機制、全部 3 個 RQ 都在這份快取上離線計算。**

**方法章第一頁的明文設計原則（回應法官修正 1）：** RQ3 的對抗攻擊產生器不是新方法論，而是「為 grid 第三根軸（adversary 軸）生成 cell 內容的 sampler」。它產生的樣本走**與 RQ1/RQ2 逐 bit 相同的量測介面**——同一批 checkpoint、同一次前向快取、同一種 R–C 曲線讀數。攻擊改變的是網格裡某一格「裝了什麼樣本」，不改變「怎麼讀這一格」。三個 RQ 因此共用單一介面，不是三個並列實驗。

### 三個 RQ

- **RQ1（劣化）**：在 generator-shift 與 channel-shift 之下，各棄權訊號的判別力還剩多少？固定 FPR ≤1% 時的 selective recall、risk–coverage 曲線與 ECE 如何劣化？是否存在「偵測 AUC≈0.5，但棄權仍有效」的格？
  → **由核心方法回答**：沿 `cell` 的 generator 軸與 channel 軸讀 `R–C(s|cell)` 的邊際劣化。零額外方法。輸出負領土地圖：哪些格連棄權都救不了。

- **RQ2（分岔）**：density-based（只建模 bona fide，如 Mahalanobis-on-SSL、energy）與 discriminative-derived（依賴 fake 端決策邊界，如 MSP、temperature、MC-dropout、deep ensemble）兩族棄權分數，在同一 shift 格上是否分道揚鑣？失效模式是否可預測？
  → **由核心方法回答**：把同一批 `s` 依「是否只用 bona fide 統計量」分成兩族，比較兩族在同格的 R–C 曲線。這是對同一組曲線的一次**分割**，不是新方法。唯一額外運算是 speaker-identity 投影消融（一次 frozen ECAPA 前向，仍同一條管線）。

- **RQ3（對抗）**：攻擊者以 recipe-level laundering 或白盒擾動介入時，把各棄權訊號推進 confident-real 區（`max P(confident-real|fake)`）的最低成本是多少？RQ1/RQ2 得到的機制排序，在對抗欄位下是否翻轉？
  → **由核心方法回答**：在網格上加一組 adversarial cell，對同一批 `s` 重讀同一種 R–C 曲線的 confident-real 端。攻擊是網格的第三根軸，不是第二種方法論。

### 為什麼是同一個框架的三個面向，而不是三件事

三個 RQ 共用同一組物件 `s / g / R–C`、同一批 checkpoint、同一份快取、同一種曲線讀數。RQ1 沿既有兩軸讀邊際；RQ2 對讀出的曲線做一次分族切割；RQ3 為第三軸生成 cell 內容後**用完全相同的方式**再讀一次。工程上是「一次前向 → 快取 → 全部離線」的單一基礎設施——換言之，把 RQ2 或 RQ3 拿掉，管線一行都不用改，只是少讀幾個切片。這正是「同一套方法」的操作定義：**deliverable 的差異只在讀哪個切片，不在用哪套機器。** 原案 RQ 裡真正換方法論的那一項（人類模型族 + dominance 偏序的適用域分治 θ\*）已在第一次削減整條移除，本稿無殘留。

## 四、貢獻（3 點）

1. **第一個 shift-aware 的 ADD 選擇性預測基準**：6 種棄權機制 × 12 格（4 source × 3 channel）的 risk–coverage、固定 FPR selective recall 與校準誤差，附**負領土地圖**——明確標出「連棄權都救不了、任何人都不該部署」的格。
2. **density-vs-discriminative failure-mode 的實證判決**：在偵測 AUC≈0.5 的失效格，只建模 bona fide 的分數是否倖存。這決定未來 ADD 不確定性研究該往哪一族投資——本論文唯一的假說與唯一的正面科學宣稱。
3. **confident-real 攻擊面的形式化與量測**：`max P(confident-real|fake)` 與**無綠燈原則**（輸出狀態空間中不存在對 fake 的正向信任訊號）作為可重複、可比較的評估軸，量測「棄權機制本身能否被低成本繞過」。

### 5.3 方法步驟

1. 建評估池（分層抽樣、打包成 webdataset shard——Windows 上讀 61 萬個小 flac 是 I/O 地獄）與 3 個通道副本。
2. 訓練 3 個 base checkpoint + ensemble seed（E=3）。
3. **每格跑一次前向，快取 logits + pooled embedding（全 25 層 pooled，非 frame-level）**。
4. RQ1：在快取上離線算 6 機制 × 12 格的 R–C / ECE / selective recall。
5. RQ2：分族比較 + speaker-identity 投影消融。
6. RQ3：recipe-level laundering beam search（B=5, D=4, A=8）+ 白盒 PGD-50（僅可微路徑）；重讀同一組 R–C 曲線的 confident-real 端。（黑盒 sanity 已移出主軸。）

### 5.4 評估指標

固定 FPR ≤1% 下的 **selective recall**、**risk–coverage 曲線與 AURC**、**ECE / reliability diagram**、**`max P(confident-real|fake)` 與其攻擊成本上界**、**多 base rate 下的期望成本**。**禁用裸 EER 為主指標**（沿用第二輪全場公約）。

### 5.5 消融

density vs discriminative 在 AUC≈0.5 格的命運分岔；speaker-identity 投影移除後的殘差子空間；MC-dropout 的 T 敏感度（T=5/10/25，單模型單格）；Mahalanobis 的 SSL 層選擇；temperature 校準集的選擇；`C_neural` 的 bitrate 梯度（3–4 bitrate，可逆性邊界——鷹派要求補列）。

## 七、失敗退路

**核心假設**：至少某些棄權訊號，在 unseen-generator / unseen-channel 下仍保有可用判別力（偵測器答錯的樣本，其信心分數系統性低於答對的樣本）。

**三個 RQ 的 null 結果，每一個都可發表：**

| 假設破裂情境 | 論文變成什麼 |
|---|---|
| **主假設全滅**：AUC≈0.5 格，6 種棄權訊號 R–C 全退化成隨機 | 變成「選擇性預測在 ADD 上的嚴謹否證 + confident-real 攻擊面 taxonomy」——對整條 uncertainty-for-ADD 路線的可發表負面結果（先例：VoiceWukong 高品質負面結果進 USENIX Security 2025）。Q2 benchmark 已獨立成篇，畢業無虞。 |
| **RQ2 是 null**：兩族不分岔 | 答案是「不必再為 one-class 賽道的不確定性方法投資」——一樣是結論。 |
| **RQ3 兩邊都能寫** | 攻擊打得動 → 對部署方的警告（虛假安全感）；打不動 → 正面部署證據。**無失敗模式。** |
| **最壞**：連 benchmark 都無有意義差異 | 那本身即「現有不確定性方法在 ADD 上無法區分」的判決，配 12 格資料 + 公開快取，仍是資源型貢獻。 |

**沒有任何退路需要新方法論、新資料或新的一年。**

**前提假設（鷹派提醒，寫入計畫）**：本設計假設 RTX 4090 機器已到位；若需現購（~NT$60,000+）為計畫外資本支出，須指導教授先確認。消費級 4090 + Windows 的隱形稅（無人值守夜跑被 update 中斷、散熱降頻、機器不能同時做別的）會讓「連續夜跑」在真實日曆上拉長——這也是本稿把 GPU 壓到 ~500h、留大量餘裕的另一個理由。

## 八、社會意義（文字論證，不進實驗設計）

**偵測器最危險的失效不是漏抓，是自信地說「這是真人」。** 一個把 deepfake 判成 bona fide 且信心 0.99 的系統，比沒有系統更糟——它替攻擊者背書。本論文把這句話變成可量測的量 `max P(confident-real|fake)`，與可檢查的設計不變量——**無綠燈原則：系統只有「警示」與「沉默」兩態，沉默不是背書。**

**這篇論文不宣稱救得了任何人，並明確說出這件事。** 它不量受騙率、不做因果宣稱、不模擬人類受試者（Qwen2-Audio 在 deepfake 上 F1=0 是現成反例，LLM 模擬受試者已被實證判為不可靠）。它量的是**機器的自知之明**。受騙率是下一篇論文的事，那需要 IRB、真人、一個本論文明確拒絕假裝擁有的東西。

**社會用途是「開 pilot 的門檻證據」。** 平台、銀行、165 不缺 A/B test 能力，缺的是「值得為這個偵測器開一次 pilot 嗎」的證據。本論文交付一張操作點準則表：在哪些條件下這個偵測器的沉默可被當訊號、在哪些格它連棄權都不該被信任（負領土地圖）——比一個 EER 0.06% 卻在一次 neural codec transcode 後崩到 40% 的排行榜數字，對真實世界有用得多。

**誠實邊界（寫進第一頁）**：本論文量的是偵測器在偏移與對抗下的棄權可靠性。它不涵蓋：人類是否服從警告、攻擊者能否用社工繞過整個系統、多回合信任建立、threat displacement。這些不在框架內——不是因為不重要，而是因為**假裝一年一張 4090 能回答它們，才是真正的不誠實。**
