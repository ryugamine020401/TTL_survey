# Round 1 提案：紅隊/攻擊者（Agent D）
日期：2026-07-13

> 口頭禪：**攻擊者只要贏一次。** 防禦者必須對「所有現在與未來的生成器、所有 laundering 管線、所有社交情境」都成立；我只要找到一條你沒堵住的路。所以我評估任何方案的唯一問題是：**繞過它最便宜的方式要花多少？** 如果答案是「零成本」或「我本來就會做的事」，這個方案在真實對抗環境下等於沒有。

---

## 1. 我看到的問題本質

從攻擊者視角重新陳述這個問題，我認為前面的問題陳述有三個被低估的面向：

**(A) 這是一場不對稱戰爭，而且不對稱性一面倒地有利於攻擊者。**
文獻已經幫我把證據攤開了。VoiceWukong（#2）證明：只要我用一個「不在你訓練集裡」的閉源商用工具，SOTA 偵測器 EER 就從 <1% 暴增到 13.5–50%，而且學術界最愛的補救手段（targeted augmentation、multi-domain training）幾乎無效，multi-domain training 甚至讓 AASIST2 退化到接近隨機（EER 48–50%）。**這代表我連 adaptive attack 都不用做**——「換一個你沒看過的生成器」是零技術門檻、零成本的繞過。詐騙集團每個月都有新的商用 TTS 可以買。防禦者要泛化到「未來」，我只要活在「當下你的盲區」。

**(B) 幾乎所有防禦方案都偷偷假設「攻擊者會合作」，但真實詐騙者永遠 opt-out。**
C2PA（#4–#6）是 opt-in 的溯源方案，watermarking 依賴生成端合作（#1 明講）。這些技術保護的是「證明真的是真的」（honest content 的可驗證性），**對「不附任何 credential 的惡意 deepfake 完全零覆蓋」**（#6 白紙黑字寫了）。我做詐騙電話時，當然不會幫我的假音訊簽 C2PA、也不會嵌浮水印。所以只要有人把「provenance/watermark」當成「偵測 deepfake 的手段」來提案，我第一句話就是：它防的不是我，它防的是那些老實人。

**(C) 真正的戰場是「laundering 過的、即時的、有社交壓力的互動」，不是 benchmark 上的乾淨檔案。**
民眾受騙的典型情境是：一通電話（已經過電信 codec 壓縮 + 封包遺失）、一則轉發的語音訊息（過 LINE/WhatsApp 私有轉檔管線）、加上「你兒子出事了快匯錢」的情緒壓力。Loughborough（#3）證明光是 codec 壓縮就讓 EER 平均劣化 5.30%，而且對未知 codec 無解。關鍵是：**laundering 對我來說不是敵人，是免費的盟友**——我要傳到受害者耳裡本來就得經過這些通道，通道順便幫我洗掉了偵測依據。而 #3 的解法假設「已知目標通道的 codec 與 PLR 分布」——那我就用你沒模擬的 tandem codec 串接。

小結：**別人容易忽略的是「攻擊成本」這個軸。** 大家討論 EER、AUC、準確率，但沒人問「攻擊者花多少錢/多少技術就能讓這個數字失效」。一個 EER 0.06% 但被一次換 generator 就崩到 40% 的偵測器，它的「攻擊成本」是零，它給民眾的是**虛假的安全感**——這比沒有防禦更危險，因為它讓人放下戒心。

## 2. 思辨過程（自我質疑的獨白）

我先把「攻擊者會怎麼贏」的招式列出來，再反過來想哪些防禦真的貴。

### 候選想法 1：對 SOTA 偵測器做 white-box adversarial perturbation attack
**初始動機**：最經典的紅隊操作。對 AASIST/RawNet2 做 gradient-based 對抗擾動，證明加一點聽不見的噪音就能讓偵測器翻盤。

**自我質疑（致命弱點）**：
- *威脅模型不真實*。White-box 假設我能拿到偵測器的梯度。但真實詐騙集團不會這樣打——他們根本不需要。當「換一個閉源 generator」就零成本繞過時，我為什麼要費力做 gradient attack？**這是拿高射炮打蚊子，而且假設了不存在的條件。**
- *對民眾沒有直接貢獻*。證明「白盒可攻破」只是重複影像領域十年前的結論，對「降低受騙機率」沒有可操作的產出。
- *學術上也不新*。audio adversarial examples 已經一堆論文。

**結論**：淘汰為主提案。但我保留一個有用的洞見——**laundering 本身就是一種「黑盒、零知識、我本來就要做」的對抗攻擊**。這個洞見升級成提案一。

### 候選想法 2：把 #7 的「Integrity Clash / metadata washing」desync 攻擊移植到 audio
**初始動機**：#7 在影像上展示了「密碼學有效的 C2PA manifest 宣稱人類創作 + 像素帶 AI 浮水印」可以共存，而且用 metadata washing（只省略規格允許省略的單一 assertion 欄位）就能造出「經認證的假內容」，完全不用破解密碼學。這超漂亮，audio 上還沒人做。

**自我質疑**：
- *又踩到「攻擊者不合作」的陷阱*。desync 攻擊的前提是「有人會去簽 C2PA / 嵌浮水印」。詐騙 deepfake 根本不簽。所以這個攻擊打擊的是「honest content 的整合驗證」，對「攔截惡意 deepfake」的民眾保護價值是間接的。
- *可行性風險*。audio 的 C2PA 工具鏈（soft binding、watermark assertion）比影像不成熟，碩士一年要自己補齊 tooling，時程有風險。
- *會跟 B 大量重疊*。這本質是 provenance 研究者的地盤。

**結論**：淘汰為獨立主提案，但**這是我要留給 B 的關鍵問題**（見第 4 節）。我會逼 B 回答：在 audio 上，你的整合驗證對「什麼都不簽的我」到底有什麼用？

### 候選想法 3：generator-in-the-loop 的 adaptive 生成器微調（訓練我的 TTS 去躲你的偵測器）
**初始動機**：既然防禦者會發布偵測器，我就把偵測器當 discriminator，微調我的生成器直到躲過它。這是最強的 adaptive attack。

**自我質疑**：
- *碩士一年做不完*。訓練/微調生成器需要重運算資源，而且結論可預測（偵測器會輸）。投入產出比太低。
- *結論不驚喜*。arms race 的必然結果，寫出來 novelty 有限。

**結論**：淘汰。不過它強化了我的核心論點：**任何「公開發布的靜態偵測器」在 adaptive 攻擊下都有天花板**——這推動我去想「哪裡的防禦不是靜態的、攻擊者無法離線預先破解」，於是導向提案二的 **互動層（interaction-layer）challenge-response**。

### 候選想法 4：laundering-first 的「攻擊成本曲線」壓力測試框架
**初始動機**：現有 benchmark（VoiceWukong 的 38 個變體、Loughborough 的 C0–C5）把 laundering 當「隨機後處理 / distribution shift」。但我這個攻擊者不是隨機施加 laundering——我是**刻意挑選最能破壞你偵測器的那條 laundering 管線**。沒有人系統性地從「攻擊者最佳化」的角度量化：對每個偵測器，最便宜的繞過要幾步、花多少。

**自我質疑**：
- *會不會只是重做 VoiceWukong？* 不會。VoiceWukong 測的是「平均劣化」，我測的是「攻擊者最佳化後的最壞情況 + 達成它的成本」。框架的核心產出是 **attacker-cost curve**（x 軸＝攻擊者投入的 laundering 步驟數/工具成本，y 軸＝偵測器 EER），這是評估防禦「值不值得部署」的新指標，現有文獻沒有。
- *可行性*？高。這是評估/benchmark 型工作，不需要訓練大模型，只需要組合現成生成器 + 現成 codec/VC 工具 + 現成 SOTA 偵測器 checkpoint。碩士一年可行。
- *社會價值*？高。它直接告訴部署方（銀行、電信、平台）：「你買的這個偵測器，攻擊者花 3 分鐘就能繞過，別拿它給民眾虛假安全感」。

**結論**：**採用為正式提案一。**

### 候選想法 5：把防禦搬到「攻擊者無法離線預先破解」的地方——即時互動的 liveness challenge-response
**初始動機**：既然對「內容 artifact」的被動偵測是輸的（提案一會量化這件事），而 provenance 只保護合作者，那防禦的槓桿在哪？我反過來想：**攻擊者的真正瓶頸是什麼？** 是「即時、低延遲、對任意未預期內容、帶正確 prosody 的語音合成/轉換」。現在的詐騙多用預錄或半腳本音訊；一旦逼他即時回答一個隨機、不可預測的挑戰，他的成本就從「離線精修」跳到「即時 arbitrary-content voice conversion」，這是量級的差距。

**自我質疑（我對自己最狠的一段）**：
- *這不是也能被 real-time VC 繞過嗎？* 能。我誠實承認：即時 voice conversion 工具存在。但關鍵是**成本上升是真的**——即時、低延遲、對「隨機新句子」保持目標音色與自然 prosody，遠比離線做一段假錄音貴且容易露餡（延遲、prosody 崩壞、對突發追問失準）。這正是我作為紅隊要誠實指出的「真的會提高攻擊成本」的方案。
- *可用性風險（F 的地盤）*。要長輩在情緒壓力下完成 challenge-response，可能反而被社交工程繞過（「不要理那個驗證，快匯錢」）。這是真實弱點，我留給 F。
- *會不會變成純協定設計、缺 ML novelty？* 所以我把研究重心放在**紅隊視角的攻擊成本刻畫**：系統性地分類「哪些 challenge 便宜可破（預錄、on-the-fly TTS）vs. 哪些昂貴（需即時 novel-content VC + 正確 prosody）」，並用現成即時 VC 工具實測破解成本。這既有 novelty 也有防禦設計指導價值。

**結論**：**採用為正式提案二。** 這是我唯一相信「真的提高攻擊成本」的方向。

## 3. 正式提案

### 提案一：Adaptive-Laundering 攻擊成本曲線——把 laundering 從「雜訊」重新定義為「攻擊者的最佳化武器」

**核心 idea**：建立一個以「攻擊者成本」為軸的紅隊評估框架。對每個 SOTA audio deepfake 偵測器，不問「平均 robustness」，而問：**攻擊者要讓你的 EER 突破可用門檻（例如 >20%，形同無效），最便宜的 laundering 路徑是什麼、需要幾步、用到什麼等級的工具？** 產出每個偵測器的 **attacker-cost curve** 與「最便宜繞過配方（cheapest-bypass recipe）」。

**為什麼有機會成立（引文獻）**：
- VoiceWukong（#2）已證明換閉源 generator 就能讓 EER 崩到 13.5–50%，且 augmentation/multi-domain 補救無效——這給了「零成本繞過」的起點。但它測的是**隨機平均**，沒有把攻擊者當成會最佳化的對手。
- Loughborough（#3）證明 codec 壓縮就顯著劣化、對未知 codec 無解，且其 DA 解法**明確假設已知目標通道分布**——這正是我要攻擊的假設：我用你沒模擬的 **tandem codec 串接 + 平台私有轉檔**。#3 自己也承認「未見過 codec、社群平台轉檔的泛化」是殘留 gap。
- #1 指出訓練資料多為 lossless（FLAC）、真實多經 lossy compression——train/test 落差本身就是免費攻擊面。
- **novelty**：現有 benchmark 把 laundering 當 distribution shift（防禦者視角）；我把它形式化為 **adversarial laundering search（攻擊者最佳化視角）**，並提出攻擊成本作為評估指標。這個「成本軸」在 audio ADD 文獻中不存在。

**技術路線（碩士一年可行）**：
1. 定義「攻擊者動作空間」：{ 換 generator（開源/閉源）、re-synthesis laundering（把音訊過一遍 VC/vocoder 重合成以洗掉指紋）、codec tandem（多重 codec 串接）、平台真實轉檔（LINE/WhatsApp/Messenger 實際上傳下載）、resample/time-stretch/replay 等 }。每個動作標註一個「成本」代理指標（工具取得難度、金錢、處理時間、需要的技術等級）。
2. 對 3–5 個公開 SOTA 偵測器（AASIST2、RawNet2、Wav2Vec2/XLS-R backend 等）跑 **貪婪/beam search**，找每個偵測器的最短/最便宜繞過路徑。
3. 畫出 attacker-cost curve，並歸納「跨偵測器共通的便宜弱點」（我猜測：re-synthesis laundering + 一次平台真實轉檔會是共通殺招——這是猜測，需實測）。
4. 反向產出：哪些防禦設計選擇能讓曲線變陡（提高攻擊成本）——例如是否某些 SSL 特徵對 re-synthesis 特別 robust。

**預期貢獻**：
- 給部署方一把「照妖鏡」：量化每個偵測器的真實攻擊成本，戳破虛假安全感，直接服務「降低民眾受騙」——因為它能阻止機構部署形同無效卻讓人鬆懈的偵測器。
- 一個可重複、可擴充的紅隊評估協定（攻擊成本曲線），可成為後續防禦研究的標準壓力測試。
- 誠實的正面產出：如果某類特徵/設計真的讓曲線變陡，那就是有價值的防禦線索。

### 提案二：互動層 Liveness Challenge-Response 的攻擊成本刻畫——把防線移到攻擊者無法離線預破解之處

**核心 idea**：承認「對內容 artifact 的被動偵測」在 adaptive 攻擊下必輸（提案一量化）、「provenance/watermark」對不合作攻擊者零覆蓋（#6）。因此把高風險語音互動（銀行客服、家人急難匯款、企業指令）的防線移到**即時互動**：用一個「latency-bounded、內容不可預測的 challenge-response」逼攻擊者即時合成/轉換「他預料不到的新內容」。研究重心（紅隊視角）：**系統性刻畫哪些 challenge 便宜可破、哪些真的昂貴**，據此設計出攻擊成本最高的 challenge 家族。

**為什麼有機會成立（引文獻 + 誠實評估）**：
- #6 明確指出 provenance「對不附 credential 的惡意 deepfake 完全無覆蓋」、#1 指出 watermark「依賴生成端合作」——這證明對不合作攻擊者，靜態方案無效，必須換戰場。
- #8 結論：真實對抗環境下**沒有任何單一手段充分**，最實際是「溯源+浮水印+內容偵測+人工監督」的分層防禦，並把「可信的使用者體驗」列為優先方向。互動層 challenge-response 正好是「人工監督/使用者體驗」這一層目前缺的、可操作的技術元件。
- VoiceWukong（#2）的 user study 顯示人機互補：人類對低品質 deepfake（如即時 VC 常出現的 artifact）反而優於偵測器。互動挑戰正是把攻擊逼進「即時、易露餡」的低品質區間，放大人類與系統的優勢。
- **誠實指出成本上升是真的**：即時、低延遲、對隨機新句子維持目標音色 + 自然 prosody + 應對突發追問，遠比離線精修一段假錄音昂貴。這是我作為紅隊少數認為「真的提高攻擊成本」的機制——因為它攻擊攻擊者的真正瓶頸（real-time arbitrary-content synthesis），而不是攻擊事後可洗掉的痕跡。

**技術路線（碩士一年可行）**：
1. 建立 challenge taxonomy：{ 隨機句子複誦、需要語意即時生成的問答、帶特定 prosody 指令（「用疑問句念這串數字」）、超短反應時限、疊加不可預測背景約束 等 }。
2. 用**現成即時 VC / streaming TTS 工具**扮演攻擊者，實測每種 challenge 的破解成功率與成本（延遲、prosody 自然度、對追問的失準率）。
3. 產出攻擊成本排序，選出「便宜可破 → 昂貴」的分界，設計最小可行的 high-cost challenge 協定原型。
4. 與 F（民眾代表）協作評估可用性 vs. 安全的 trade-off，並分析社交工程繞過（攻擊者叫受害者「別驗證」）的殘留風險與緩解（例如把 challenge 綁進機構端流程而非依賴受害者自覺）。

**預期貢獻**：
- 一個**攻擊者無法離線預先破解**的防線設計，且其安全性有紅隊實測的攻擊成本背書——這是對「靜態偵測必輸」困局的正面出路。
- challenge 攻擊成本的分類學，可指導銀行/電信設計實際的高風險驗證流程，直接降低「家人急難」「假客服」這類高損失詐騙的成功率。
- 誠實劃定邊界：明確說出它擋不住什麼（社交工程叫人放棄驗證、頂級即時 VC），避免製造新的虛假安全感。

## 4. 我留給其他討論者的問題

**Q1 給 A（Detection 研究者）**：
你的偵測器面對的不是隨機 augmentation，而是**一個會最佳化的攻擊者刻意挑選的 laundering 管線**（提案一）。VoiceWukong 已證明 multi-domain training 甚至有害。請問你打算怎麼證明對「未來未見 generator + 攻擊者最佳化 laundering」的泛化？你能不能給出一個**攻擊成本下界**（「要繞過我，攻擊者至少得付出 X」），而不只是報一個 in-domain EER？如果給不出下界，我們憑什麼相信你的偵測器不是又一個零成本可繞過、只會製造虛假安全感的方案？

**Q2 給 B（密碼學/Provenance 研究者）**：
