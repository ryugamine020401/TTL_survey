# Round 1 提案：訊號處理研究者（Agent C）
日期：2026-07-13

---

## 1. 我看到的問題本質

我從傳輸鏈（transmission chain）的角度重新陳述這個問題：**deepfake audio detection 不是在乾淨的 waveform 上做分類，而是在一條有損、非線性、且攻擊者可自由選擇的物理通道的「出口端」做分類。** 詐騙電話的受害者聽到的聲音，至少經過了：生成器輸出 → （可能的後處理/laundering）→ 編碼（AMR-NB/EVS/Opus）→ 封包網路（jitter、loss、PLC 補償）→ 解碼 → 播放。如果是 LINE 語音訊息再被轉傳，還會疊加多次 transcode。每一段都在不可逆地丟棄資訊。

我認為其他討論者容易忽略的三個面向：

**（a）特徵的「物理存活性」是有層級的，不是全有全無。** 文獻 #3（Loughborough）證明 codec 壓縮讓 GMM/LCNN/AASIST 從 C0 到 C1 平均劣化 EER 5.30%，但它把 detection 模型當黑盒子，沒有回答「到底是哪些 cue 死掉了」。從訊號處理常識可以先驗地排序：
- **第一層（最脆弱）：相位與微觀波形結構。** AMR/EVS 這類 CELP 系 codec 是參數式編碼（LP 係數 + excitation codebook），解碼後的波形相位與原始訊號幾乎無關。所有依賴 phase spectrum、waveform-level artifact 的特徵（RawNet2 這類 raw-waveform 模型學到的許多 cue）在這一層就物理性死亡。
- **第二層：高頻頻譜細節。** AMR-NB 是 8 kHz 取樣、300–3400 Hz 通帶——4 kHz 以上什麼都不剩。而 neural vocoder 的許多招牌 artifact（高頻 checkerboard、harmonic 缺陷）恰好集中在高頻。傳統電話通道等於免費幫攻擊者做了一次完美 laundering。
- **第三層（最強韌）：頻譜包絡的長時統計、韻律（F0 軌跡、節奏、停頓）、呼吸聲與口腔噪音的分佈、語者層級的一致性。** 這些是任何以「讓人聽得懂」為目標的 codec 都必須保留的資訊——**codec 的感知目標函數本身就是這些特徵的存活保證書。**

**（b）文獻 #3 的解法有一個隱藏的樂觀假設。** 它用通道模擬 data augmentation 把劣化壓到 EER 波動 < 0.1%，並下結論「退化主因是 distribution shift 而非資訊被不可逆摧毀」。但這是在**已知 codec 家族、已知 PLR 分佈**下測的。真實世界的社群平台轉檔管線是私有的、會改版的、而且常常是多段串接（例如：手機錄音 AAC → LINE 上傳 transcode → 對方下載再轉傳）。「模擬 6 種 codec 就能泛化到第 7 種」目前沒有任何證據；而且它也沒測「通道劣化 × unseen generator」的交互作用——VoiceWukong（#2）已經證明後者單獨就能把 EER 打到 13.5–50%，兩者疊加很可能是乘法性的災難。

**（c）通道不只是敵人，也是可利用的先驗。** 詐騙情境的通道其實高度集中：台灣的語音詐騙大宗就是「電話（PSTN/VoLTE：AMR-NB/AMR-WB/EVS）」和「LINE 通話與語音訊息（Opus 系）」兩條。這是一個有限、可枚舉、可實測的集合——不是 open set。如果偵測系統知道（或能推斷）音訊走過哪條通道，它就能把一個絕望的 open-set 問題收斂成幾個可各個擊破的 conditional 問題。

## 2. 思辨過程

以下是我實際淘汰與修正想法的過程。

### 候選 1：把 Loughborough 的通道模擬 DA 推廣到「未知 codec」——通用通道擾動模型

**初始想法**：#3 已證明已知通道下 DA 有效。那我做一個「codec-agnostic」的通道模擬器：不模擬特定 codec，而是模擬 codec 的共通操作原語（帶限、參數式重合成、bit allocation 造成的頻譜量化、PLC 的波形外插），用隨機化的原語組合做 augmentation，賭它能涵蓋未見過的真實 codec。

**自我質疑**：
- 致命點一：這在方法論上是 #3 的增量延伸，novelty 主要在「原語分解」這一步，但審稿人會問：你怎麼證明你的原語空間涵蓋了真實 codec？如果答案是「拿真實 codec 驗證」，那我其實還是在有限 codec 集合上做 leave-one-out，說服力有限。
- 致命點二：VoiceWukong（#2）給了一個不祥的訊號——「multi-domain training 讓 AASIST2 退化到 EER 48–50%（接近隨機）」。把 augmentation 空間撐得太大，模型可能學不到任何穩定的決策邊界。我的隨機化原語組合正是在撐大 augmentation 空間，很可能重蹈覆轍。
- 致命點三：就算成功，它治標不治本——它讓模型「習慣」通道失真，但沒有回答哪些資訊真的還在。如果第一層、第二層特徵已物理性死亡，DA 只是逼模型去依賴第三層特徵，那不如**直接、顯式地**研究第三層特徵。

**處置**：不作為主軸。但「leave-one-codec-out 泛化評估協定」這個實驗設計值得保留，併入提案一的評估方法。

### 候選 2：把 codec 變成偵測器——analysis-by-synthesis 殘差探測（codec probing）

**初始想法**：CELP 系 codec 的設計前提是「輸入是人類聲道產生的訊號」（LP 模型即聲道模型）。合成語音的 excitation 統計與真人不同（neural vocoder 的殘差週期性、雜訊底的結構都不一樣），所以把可疑音訊**主動再過一次已知 codec**，量測 rate-distortion 行為或重編碼殘差的統計，真假語音可能有系統性差異。這很「訊號處理」、很優雅，而且不需要訓練大模型。

**自我質疑**：
- 質疑一：如果音訊已經過了一次 AMR（詐騙電話場景必然如此），那我收到的訊號已經是「codec 認可的輸出」——它的 excitation 已經被投影到 codebook 空間裡了。再編碼一次的殘差可能主要反映「第一次編碼的量化史」而不是「生成器的痕跡」。也就是說，**這個方法最有用的場景（電話）恰好是它的訊號來源被抹除的場景**。這是個結構性矛盾。
- 質疑二：這本質上是 handcrafted feature 路線。#1 的 survey 明確指出 SSL 特徵 + augmentation 是目前最有效的路線，handcrafted 特徵在 unseen attack 上的 generalization 歷史紀錄不佳。我提出它可能只是因為它訊號處理品味好，不是因為證據支持。這是我要警惕的職業偏見。
- 質疑三（但也是轉機）：反過來想，「量測第一次編碼的量化史」本身有價值——它可以推斷音訊走過哪條通道（double compression detection 在影像 forensics 是成熟領域）。這不能判真假，但能判「這段自稱是電話錄音的音訊，頻譜上根本沒有 AMR 的痕跡」——**通道宣稱與通道證據的一致性檢查**。這跟 #7 的 Integrity Clash 思路（多訊號一致性）在 audio 上不謀而合。

**處置**：作為「真假二分類器」淘汰；轉化為「通道指紋 / 通道一致性」模組，併入提案二。

### 候選 3：對抗 re-recording 的極限研究——「重錄之後還剩什麼」

**初始想法**：re-recording（喇叭播放 + 麥克風重錄）是最強的 laundering，疊加了房間脈衝響應、換能器非線性、環境噪音。VoiceWukong 的 38 種 manipulation 裡也含 replay。做一個系統性研究：重錄之後哪些 deepfake 痕跡還可量測？

**自我質疑**：
- 質疑一：答案很可能是「幾乎什麼都不剩，只剩韻律與語言層特徵」——一個否定性結論。否定性結論有科學價值，但作為碩士論文單獨成立很危險：如果實驗做完發現「全都不行」，我沒有 fallback 的正面貢獻。
- 質疑二：重錄實驗的變因空間巨大（喇叭 × 麥克風 × 房間 × 距離），一年內做出有統計效力的覆蓋很吃力，而且設備與場地成本不是碩士生等級。
- 質疑三：從威脅模型看，詐騙者其實**不需要**重錄——直接把生成音訊灌進通話軟體（virtual audio cable）更簡單、品質更好。重錄比較常出現在「假證據音檔」情境而非即時詐騙。針對降低民眾受騙率的目標，優先級應該給電話/LINE 通道。

**處置**：淘汰作為主軸。但把 re-recording 作為提案一「存活圖譜」中的一個最惡劣通道條件納入（小規模、控制變因），讓圖譜有一個「下界」錨點。

### 候選 4：能在電話通道存活的主動式 audio watermark

**初始想法**：既然被動特徵大量死亡，那就主動注入設計成能存活 AMR-NB 的 watermark（塞在 300–3400 Hz、對 CELP 重合成強韌的調變方式）。

**自我質疑**：
- 質疑一：這依賴生成端合作（#1 明確指出主動式方案的這個限制），詐騙者用的閉源或自架生成器根本不會蓋 watermark。它保護的是「守法生成內容的可識別性」，對「惡意生成內容的偵測」貢獻趨近於零——和降低受騙率的目標錯位。
- 質疑二：#7 已示範 watermark 與 provenance 可被去同步攻擊；watermark 的強韌性與可移除性是同一枚硬幣（能存活通道的 watermark 頻段能量集中，也更容易被針對性濾除）。
- 質疑三：這個題目和 Agent B（provenance/watermarking）的地盤高度重疊，我的比較優勢（通道建模）只是其中一個環節。

**處置**：淘汰。留給 Agent B，但我會在 Round 2 對他的方案提通道存活性的質詢。

### 收斂

淘汰與轉化之後，留下兩條互補的主軸：
- 候選 1 的評估協定 + 候選 3 的通道條件 + 「特徵存活層級」的先驗 → **提案一：特徵存活圖譜與存活特徵偵測器**（回答「還剩什麼、怎麼用剩下的」）。
- 候選 2 轉化出的通道指紋 + 面向（c）的「通道是有限集合」觀察 → **提案二：真實傳輸鏈資料集與通道感知偵測**（回答「音訊走過哪條路、以及宣稱與證據是否一致」）。

## 3. 正式提案

### 提案一：Deepfake 痕跡的傳輸鏈存活圖譜（Artifact Survival Atlas）與「只用存活特徵」的強韌偵測器

**核心 idea**：不把 detection 模型當黑盒子量 EER，而是系統性地量測「每一類 detection cue 在每一種真實通道下還剩多少可分辨資訊」，產出一張 cue × channel 的存活圖譜；然後刻意設計一個**只依賴高存活層特徵**（頻譜包絡長時統計、韻律、F0 動態、停頓/呼吸結構）的偵測器，犧牲乾淨條件下的 SOTA 成績，換取對未知通道的泛化。

**為什麼有機會成立**：
- #3 證明退化主因是 distribution shift、資訊未被完全摧毀（DA 重訓後 EER 波動 < 0.1%）——代表存活特徵確實存在，只是現有模型沒有顯式地依賴它們。
- #1 指出訓練資料多為 lossless 而真實場景是 lossy，且 SSL 特徵是目前最強 frontend——SSL 模型（Wav2Vec2/WavLM）的分層表徵剛好提供現成的探針：用 layer-wise probing 量各層表徵在各通道下的存活度，方法論上站在成熟工具上。
- 訊號處理先驗給了明確的可檢驗假說（相位先死、高頻次之、韻律最後死），實驗有清楚的預期與解釋框架，不是盲目掃參數。
- #2 顯示人類對高品質 deepfake 的 FAR > 82% 但對低品質優於機器——存活圖譜也能解釋「人耳依賴的 cue 是哪一層」，為人機互補提供機制性解釋。

**技術路線**（一年時程）：
1. 月 1–3：建立通道矩陣（AMR-NB/AMR-WB/EVS/Opus 各典型 bitrate、含 PLC、小規模 re-recording 下界錨點），以 ASVspoof 2019/2021 + In-the-Wild + VoiceWukong 子集為素材；定義 cue 家族（phase 類、高頻頻譜類、包絡類、韻律類）與每家族的可量測代理（probing classifier 的 AUC、mutual information 估計）。
2. 月 4–6：跑存活圖譜；用 SSL layer-wise probing 對照 handcrafted 特徵；驗證「存活層級假說」。
3. 月 7–10：設計存活特徵偵測器（例如：WavLM 中層表徵 + 韻律 stream 的雙分支，或對輸入先做「最惡劣通道正規化」——主動把所有輸入降到 AMR-NB 等效帶寬再偵測，讓 train/test 通道差異被下限化）；以 leave-one-codec-out 協定評估 unseen codec 泛化，並與 #3 的 DA 基線比較。
4. 月 11–12：加測「unseen generator × 通道」交互（用 VoiceWukong 的閉源生成樣本過通道），寫作。

**預期貢獻**：（i）第一份 audio deepfake cue 的通道存活量化圖譜，回答 #3 留下的「到底什麼被摧毀了」；（ii）一個以物理先驗為設計原則、對 unseen codec 泛化的偵測器；（iii）「最惡劣通道正規化」這個反直覺 trick 的驗證（把資訊主動丟掉以換取分佈對齊——與 DA 撐大分佈的路線相反，且不會踩到 #2 觀察到的 multi-domain training 崩潰）。就算偵測器成績不驚豔，圖譜本身就是獨立成立的貢獻，風險有下界。

### 提案二：真實 laundering 傳輸鏈資料集（以台灣詐騙通道為錨）＋通道指紋一致性檢查

**核心 idea**：現有 benchmark 全是**模擬**通道（#3 用 codec 軟體離線編解碼；#2 用訊號處理後製）。我實際把音訊灌過真實管線——實體 SIM 撥打電話（AMR/EVS over VoLTE）、LINE 通話、LINE 語音訊息、Messenger、轉傳鏈（A 傳 B、B 再傳 C）——收一個真實傳輸鏈資料集；並訓練一個**通道指紋模型**：從音訊推斷它走過的通道路徑，輸出兩個東西：（a）給下游偵測器做 channel-conditioned inference 的條件向量；（b）「通道宣稱 vs 通道證據」的一致性判定——「這通自稱是銀行來電的錄音，卻沒有任何電話 codec 痕跡」本身就是強烈的詐騙訊號。

**為什麼有機會成立**：
- #3 的作者自己標明了 gap：「對未知 codec（如社群平台私有轉檔管線）的泛化未驗證」——真實管線資料集直接填這個洞，而且模擬 vs 真實的差距本身就是一個可發表的量測結果（我的猜測：真實管線因 jitter buffer、AGC、雙重 transcode 而顯著比離線模擬更惡劣，此為猜測、待驗證）。
- 通道指紋在技術上有堅實基礎：codec 的 bit allocation、帶寬截止、PLC 波形特徵都留下可分類的痕跡（影像 forensics 的 double-JPEG detection 是先例），這是 closed-set 分類問題（詐騙通道集合有限、可枚舉），比 open-set 的真假判定容易得多，碩士生一年可完成度高。
- 一致性檢查思路有 #7 撐腰：單一訊號可被繞過，但「多訊號矛盾」是攻擊者難以同時擺平的——#7 在影像上用跨層稽核達 100% 分類準確率，audio 領域「尚缺乏對應的系統性研究」（Research Gap 地圖第 3 點原文）。
- 社會效益直接：資料集錨定台灣真實詐騙通道（電話、LINE），產出可直接支援反詐工具的評測；且資料集會被後續研究引用，影響力持久。

**技術路線**（一年時程）：
1. 月 1–4：搭建實體收集管線（兩支手機 + SIM + 自動撥號播放腳本；LINE/Messenger 自動化傳送），以既有資料集的 real/fake 樣本為源，收 5–8 條真實通道 × 轉傳深度 1–3 的語料（規模抓 5–10 萬條，遠小於 #3 的 183 萬但真實）。
2. 月 5–7：量測「真實 vs 模擬」差距——用 #3 的模擬條件訓練的模型在我的真實資料上測，量化模擬的樂觀偏差；訓練通道指紋分類器（輸入 log-mel + 頻譜統計，輕量 CNN 即可）。
3. 月 8–10：兩個下游應用實驗——（a）channel-conditioned detection：偵測器以指紋向量為條件，對照無條件基線；（b）宣稱-證據一致性檢查在模擬詐騙情境（「假冒電話錄音」）上的檢出率。
4. 月 11–12：釋出資料集與收集工具（可重現的自動化管線），寫作。

**預期貢獻**：（i）第一個真實（非模擬）多平台音訊 laundering 資料集，含轉傳鏈深度維度；（ii）「模擬通道 benchmark 的樂觀偏差」的量化證據；（iii）通道指紋作為 audio 版跨訊號一致性檢查的第一個實作，把 #7 的思路從影像遷移到 audio。

**兩案關係**：提案一問「通道殺死了什麼、剩下的夠不夠用」，提案二問「音訊走過哪條通道、宣稱與證據是否一致」。可獨立成立，也可串接（提案二的資料集是提案一圖譜的真實驗證場）。若指導教授只准一題，我押提案二——資料集貢獻的風險下界最穩，且填的是文獻明文標出的 gap。

## 4. 我留給其他討論者的問題

**問 Agent A（Detection 研究者）**：Wav2Vec2/WavLM 是在 16 kHz 寬頻語料上預訓練的。當輸入被 AMR-NB 砍到 4 kHz 以下再升採樣回 16 kHz 時，SSL 表徵的哪幾層還有意義？你是否知道（或猜測）SSL 特徵在窄帶輸入下的行為——是優雅退化，還是進入分佈外的垃圾區？這決定我提案一該用 SSL probing 還是回頭用窄帶原生特徵。
