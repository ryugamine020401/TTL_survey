# TTS 評測向度

## 分層原則

- 單一樣本 vs 輸出分佈 → A vs B
- 需要參考／條件嗎 → A 內的子軸
- 評音訊 vs 評系統 vs 評社會後果 → A/B vs C vs D
- **原清單八項不同層級，平行列會誤導**
- 報告形式：**A×B 矩陣**，C 標在表頭當預算，D 獨立成節

## A 輸出品質（單樣本可評）

### A1 可懂度／文字忠實度

- 問：說對字了嗎
- 子項
  - 音素正確性 · 破音字
  - 數字縮寫正規化 TN
  - 混語／外來語
  - 幻覺插入 · 漏字
- 指標
  - ASR 轉寫 WER／CER
  - 音素錯誤率
  - intelligibility MOS
  - TN／G2P 準確率
- 陷阱
  - ASR 本身有偏誤，非人類可懂度
  - 低 WER 可能＝過度標準化

### A2 自然度／訊號品質

- 問：像真人在真環境錄的嗎
- 子項
  - 韻律自然度 · 音段品質
  - 偽影：金屬聲 · 嗡鳴 · 斷點
  - 頻寬／取樣率
- 指標
  - 主觀：MOS · CMOS
  - 無參考自動：UTMOS · NISQA · DNSMOS
  - 有參考：PESQ · ViSQOL（僅重建任務）
- 陷阱
  - MOS 跨論文不可比，只能同批 test 內比
  - 自動 MOS 預測器出分佈即失效
  - 受試者會把「自然」與「像參考」混為一談 → MOS/SMOS 分開設題

### A3 條件符合度

- **關鍵合併：相似度與可控性是同一軸的兩形態**
  - 都在問「是否符合被指定的條件」
  - 差別只在條件表示法：參考音訊 vs 數值標籤
  - 共用同一 conditioning 機制，常此消彼長

#### A3a 參考驅動（相似度／隱式條件）

- 子項
  - 說話者音色 · 口音
  - 情緒 · 韻律風格
  - **錄音／通道環境**
- 指標
  - SMOS
  - SECS 說話者嵌入餘弦（WavLM／ECAPA）
  - 口音／情緒分類正確率
  - F0 RMSE／相關 · 時長相關 · DTW
  - 通道匹配：RT60 誤差 · SNR 匹配
- 陷阱
  - 高度依賴 encoder，換 encoder 排序會反轉
  - SECS 高 ≠ 人耳覺得像
  - 環境相似度常被忽略，卻決定「像不像同一段錄音」

#### A3b 標籤驅動（可控性／顯式條件）

- 子項
  - 總時長 · 語速
  - F0 平移／範圍
  - 停頓位置與長度 · 強調
  - 風格／情緒強度
- 指標
  - 控制誤差：目標 vs 實測
  - **控制範圍**（可達區間）
  - **解耦度**（改一項時其他項的漂移）
- 陷阱
  - 只報「能控制」不報範圍與解耦＝高估
  - 極端控制值下自然度塌陷 → 要報 quality-vs-control 曲線

## B 可靠性（分佈層級）

- **不是新性質，是 A 的不同讀數**

### B1 穩定性 ＝ A 的尾端

- 問：最差多差 · 多久壞一次
- 失敗模式
  - 漏字 · 重複 · 提前截斷
  - 長句漂移 · 無限延長
  - 隨機種子敏感
  - 對抗輸入：超長句 · 純數字 · 標點異常 · 混語 · 空白
- 指標
  - 失敗率（每 N 句）
  - **WER 的 P95／P99，不是平均**
  - 長篇品質漂移曲線
  - 跨種子變異數
- 陷阱
  - 絕不可用平均代表穩定性
  - 乾淨短句測試集＝數字無意義
  - AR 與 NAR 失敗模式不同，需分別設計探測輸入

### B2 泛化／資料效率 ＝ A 的域外

- 子項
  - 未見說話者 · 未見語言／口音
  - 跨領域：朗讀 vs 自發口語
  - 跨錄音條件 · 低資源語言
  - few-shot 所需秒數
- 指標
  - 同一組 A 指標，分域內／域外兩欄
  - 資料量-效能曲線
  - enrollment 秒數-相似度曲線
- 陷阱
  - 同語料庫的 unseen speaker 仍是域內，**跨資料集才算**
  - 「只要 3 秒」單點不可比，要報曲線

## C 系統成本（與音訊內容無關）

### C1 效率與部署

- 子項
  - 首包延遲 TTFB · 即時率 RTF
  - 串流吞吐量
  - 參數量 · 記憶體峰值
  - 量化後表現
  - 裝置端功耗與熱
- 指標
  - 數值 ＋ **明確硬體與批次設定**
  - 量化前後的 A 軸對照
- 陷阱
  - 效率不綁品質即無意義 → 報「X 延遲預算下的 A」
  - 串流與離線品質不同，不可互引

## D 社會技術（方向與 A–C 相反）

### D1 安全／濫用／可偵測性

- 子項
  - 未經同意的聲音冒用
  - 語音詐騙 · 社交工程
  - 繞過聲紋驗證 ASV spoofing
  - 合成語音偵測
  - 來源證明與浮水印
  - 同意與授權機制
- 指標
  - 偵測器 EER／min-tDCF，**未見生成器條件下**
  - ASV 攻擊成功率
  - 浮水印存活率（壓縮／重錄／變速）＋ 不可感知性
  - 對抗性洗白後殘存偵測率
- 陷阱
  - **與 A–C 反向，不可加總成單一分數**
  - 已見生成器上的偵測表現嚴重高估
  - 浮水印保證來源 ≠ 被動偵測保證真偽，不可互相替代

## 權衡（不可獨立最佳化）

- A1 ↔ A2：低 WER → 平板韻律；高表現力 → 誤讀增加
- A3a ↔ A2：複製含雜訊參考時，要像就得複製雜訊
- A3b ↔ A2：控制值越極端，自然度越差
- A3a ↔ A3b：強參考條件壓縮顯式控制範圍（解耦不足）
- B1 ↔ A2：高熵取樣抬高自然度上限，也抬高尾端失敗率
- C1 ↔ 全部：蒸餾／量化先犧牲 A3b 與 B1，其次 A2
- D1 ↔ A2/A3a/B2：**能力即風險**

## 最小報告集

- A1／A2／A3 各一主觀＋一客觀，MOS 與 SMOS 分開設題
- B1：失敗率＋P95 WER，測試集含刻意困難輸入
- B2：至少一組**跨資料集**未見說話者，與域內並列
- C1：硬體／批次／串流設定 ＋ 該預算下的 A 值
- D1：資料同意狀態 · 是否加浮水印 · 公開偵測器上的可偵測性
- **明列未測項目，而非留白**

## 接點：音訊深偽（本專案）

- **分類反轉：A–C ＝ 對手能力，D ＝ 防禦方評測面**
- A2／A3a → 攻擊可信度上限（人是否上當）
- B1 → 攻擊可用率
  - 失敗樣本不會被送出
  - **野外樣本是被對手篩選過的分佈** ← 被低估的偵測線索
- B2 ＋ C1 → 攻擊規模與成本（即時？裝置端？需多少目標音訊）
- D1 → 必須在未見生成器／未見通道／經壓縮洗白下報告
- 結論：威脅模型要先指出對手在 A–C 的位置，D 的評測條件才有意義
