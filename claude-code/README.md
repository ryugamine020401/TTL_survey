## 主張摘要 / Core claim

原始的八項 TTS 評測清單不在同一抽象層級，應重組為 **4 層 / 6 軸**：

- **A 輸出品質**（單樣本）：A1 可懂度／忠實度、A2 自然度／音質、A3 條件符合度（A3a 參考驅動＝相似度、A3b 標籤驅動＝可控性）
- **B 可靠性**（分佈層級，是 A 的不同讀數）：B1 穩定性＝A 的尾端、B2 泛化／資料效率＝A 的域外
- **C 系統成本**：C1 效率與部署
- **D 社會技術**（方向與 A–C 相反）：D1 安全／濫用／可偵測性

報告形式應為 **A×B 矩陣**，C 標在表頭作為預算，D 獨立成節且不可與其他軸加總。
